# 釐清問題

「發文者已分享訓練成果」與「發文者已發布貼文」是否為同一事實的兩種說法？兩者的獎勵是否可同時取得？

# 定位

流程：發文與互動流程
元素：Event：發文者已分享訓練成果、發文者已發布貼文；對應獎勵：分享獎勵已發放、發文獎勵已發放
細節：兩個名稱不同實則指涉同一事實的 Event（A2）；成就門檻的分類（F2）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 分享訓練成果是帶訓練紀錄的貼文，屬於發布貼文的子類型，兩者獎勵擇一不可疊加 |
| B | 兩者為完全不同的行為：分享是轉發至站外，發文是站內貼文，獎勵可各自取得 |
| C | 分享訓練成果是特殊貼文類型，兩個 Event 皆發生且兩種獎勵可疊加 |
| D | 兩者應合併為單一「發文者已發布貼文」Event，貼文類型為其攜帶資訊，獎勵依類型決定 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響發文與互動流程的 Event 數量與命名、貼文 Aggregate 是否需要類型欄位、兩種獎勵的疊加規則、累計互動成就門檻的四種分類計數、以及師徒功能解鎖條件中「已分享」與「已發文」的對應。
