# 釐清問題

訓練中斷流程的「連練天數已中斷」與訓練紀錄流程的「使用者訓練已中斷」語意不同但名稱相近，應如何重新命名以消除歧義？

# 定位

流程：訓練中斷流程、訓練紀錄流程（循環：使用者已記錄重量 > 組間休息已結束）
元素：Event：連練天數已中斷（訓練中斷流程）、使用者訓練已中斷（訓練紀錄流程）
細節：同名異義與術語衝突（F2）；Event 名稱是否無歧義（A2）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 維持現名，兩者語意已足夠清楚 |
| B | 將「使用者訓練已中斷」改名為「單次訓練已逾時中斷」以區分 |
| C | 將「連練天數已中斷」改名為「連續訓練天數已歸零」以區分 |
| D | 兩者同時改名：「本次訓練已逾時中斷」與「連續訓練天數已中斷」 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響兩條流程的 Event 命名、統一語言詞彙表、以及後續 Command 與 Aggregate 欄位的命名一致性。屬於術語品質問題，答案會實際改動 Event 名稱。
