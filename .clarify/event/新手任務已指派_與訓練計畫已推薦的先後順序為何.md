# 釐清問題

「訓練計畫已推薦」與「新手任務已指派」兩個 Event 是否有先後依賴，或可並行發生？

# 定位

流程：註冊流程
元素：Event：訓練計畫已推薦、新手任務已指派
細節：Event 先後順序與並行交錯（A3）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 嚴格順序：先推薦計畫，再指派新手任務 |
| B | 可並行，兩者互不依賴，皆由「使用者已完成註冊」觸發 |
| C | 新手任務先指派，訓練計畫在新手任務完成後才推薦 |
| D | 兩者合併為單一 Event「新手引導已啟動」 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響註冊流程的 Event 時序、新手任務流程的起點 Precondition、以及「使用者已完成註冊」的 Postcondition 列出哪些連帶 Event。
