# 釐清問題

「管理員已審視檢舉」若判定檢舉不成立，會發生什麼 Event？惡意檢舉者是否受罰？

# 定位

流程：管理員管理社群流程
元素：Event：管理員已審視檢舉、管理員已下架違規內容（無不成立分支）
細節：分支路徑（成立 / 不成立）是否都有對應 Event（A3）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 補上「檢舉已駁回」Event，不對檢舉者做任何處置 |
| B | 補上「檢舉已駁回」Event，並對重複惡意檢舉者記點，達門檻後處罰 |
| C | 補上「檢舉已駁回」與「檢舉結果通知已發送」兩個 Event |
| D | 不成立時無聲結案，不建模 Event |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響管理員管理社群流程的分支 Event、檢舉 Aggregate 的狀態機終止狀態、檢舉者是否收到結果通知、以及惡意檢舉的防範規則。
