# 釐清問題

受處罰的使用者是否可申訴？限期處罰到期後是否有解除 Event？

# 定位

流程：管理員管理社群流程
元素：Event：使用者已受處罰（缺少後續路徑）
細節：隱含發生但未寫出的 Event（A1）；可逆操作的 Event 定義（C4）；終止狀態（D5）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 補上「處罰已到期解除」Event，不提供申訴管道 |
| B | 補上「使用者已申訴」「管理員已審視申訴」「處罰已撤銷」與「處罰已到期解除」四個 Event |
| C | 僅補上「處罰已到期解除」與「管理員已提前解除處罰」兩個 Event |
| D | 處罰不可逆亦無到期解除，皆為永久處罰 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響管理員管理社群流程的 Event 清單、使用者 Aggregate 處罰狀態的解除機制、是否需要申訴 Aggregate、以及與「處罰種類與級距」問題的依賴關係（需先確定是否有限期處罰）。
