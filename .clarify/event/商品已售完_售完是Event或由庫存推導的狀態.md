# 釐清問題

「商品已售完」是一個獨立 Event，還是商品庫存歸零後由系統推導的狀態？售完後是否自動下架？

# 定位

流程：管理員商品上架流程
元素：Event：商品已售完
細節：是否為誤列為 Event 的技術動作（A1）；Event 與 Aggregate 欄位的一致性（E3）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 為獨立 Event，由庫存扣減至 0 時系統自動產生，但不自動下架 |
| B | 為獨立 Event 且自動下架，需連帶產生「商品已下架」Event |
| C | 非 Event，僅為商品 Aggregate 的推導狀態，應從流程中移除 |
| D | 為獨立 Event，且分尺寸售完與全商品售完需區分為兩個 Event |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響管理員商品上架流程的 Event 清單、商品 Aggregate 的狀態機、售完與下架的關係、以及商品列表 Read Model 的顯示規則。
