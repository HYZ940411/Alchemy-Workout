# 釐清問題

虛擬商品購買時餘額不足、商品已下架或已售完，會發生什麼 Event？

# 定位

流程：虛擬商品購買流程
元素：Event：使用者已確認購買、使用者已購買虛擬商品（無失敗分支）
細節：分支路徑（成功 / 失敗）是否都有對應 Event（A3）；失敗與例外路徑（C5）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 補上「虛擬商品購買已失敗」單一 Event，失敗原因為其攜帶資訊 |
| B | 補上「餘額不足購買已拒絕」與「商品已不可購買」兩個 Event |
| C | 不產生 Event，由 Read Model 在購買前即阻擋（餘額不足時按鈕不可用） |
| D | 補上「虛擬商品購買已失敗」，並引導至儲值流程 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響虛擬商品購買流程的分支 Event、確認購買 Command 的 Precondition、購買頁 Read Model 是否需提供餘額與可購買性欄位、以及與實體商品購買流程失敗處理的一致性。
