# 釐清問題

教官申請流程中初審未通過、測驗未通過、管理員審核未通過三種失敗情況，對應的 Event 為何？模型中全數缺失。

# 定位

流程：教官申請流程
元素：Event：教官資格已初審通過、管理員已審核教官測驗、教官資格已通過（皆無失敗分支）
細節：分支路徑（通過 / 未通過）是否都有對應 Event（A3）；失敗與例外路徑（C5）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 補上「教官資格已駁回」單一 Event，駁回階段為其攜帶資訊 |
| B | 補上「教官資格初審未通過」「教官測驗未通過」「教官資格審核未通過」三個 Event |
| C | 補上三個失敗 Event，且每個皆需附駁回原因與可否重新申請的標記 |
| D | 僅補上「教官測驗未通過」，初審與審核未通過視為無聲失敗不建模 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響教官申請流程的分支 Event、教官申請 Aggregate 的狀態機終止狀態、可否重新申請的 Precondition、以及駁回原因欄位的定義。
