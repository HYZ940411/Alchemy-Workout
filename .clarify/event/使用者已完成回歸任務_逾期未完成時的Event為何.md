# 釐清問題

回歸任務逾期未完成時會發生什麼 Event？是否可重新指派？

# 定位

流程：回歸任務流程
元素：Event：使用者已完成回歸任務（模型中無失敗分支）
細節：分支路徑（完成 / 逾期）是否都有對應 Event（A3）；隱含未寫出的逾時 Event（A1）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 補上「回歸任務已逾期」Event，逾期後任務消失，滿足門檻時可再次指派 |
| B | 補上「回歸任務已逾期」Event，且需間隔 N 天才可再次指派，避免重複打擾 |
| C | 不設逾期，任務永久有效直到完成 |
| D | 補上「回歸任務已逾期」Event，逾期後改為降低獎勵的普通版本繼續有效 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響回歸任務流程的分支 Event、回歸任務 Aggregate 的狀態機終止狀態、回歸任務獎勵已發放的 Precondition、以及重複指派的冷卻期規則。
