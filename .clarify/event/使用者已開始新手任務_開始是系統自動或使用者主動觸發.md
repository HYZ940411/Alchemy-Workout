# 釐清問題

「使用者已開始新手任務」是由系統在指派後自動觸發，還是需要使用者主動點擊開始？

# 定位

流程：新手任務流程
元素：Event：使用者已開始新手任務；上游 Event：新手任務已指派（註冊流程）
細節：觸發源是否明確（B5）、Event 因果順序（A3）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 指派後自動開始，「新手任務已指派」與「使用者已開始新手任務」應合併為一個 Event |
| B | 使用者主動點擊才開始，Actor 為使用者，兩個 Event 分別存在 |
| C | 使用者完成第一項子任務時才視為已開始，由系統推導 |
| D | 首次登入首頁時自動開始 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響新手任務流程起點 Event 是否成立、對應 Command 的 Actor 與觸發源、以及新手任務 Aggregate 的狀態機起始狀態。
