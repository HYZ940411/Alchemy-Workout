# 釐清問題

「使用者已結束訓練」是否同時涵蓋「全部動作已完成」與「使用者提前主動結束」兩種情況？兩者應否區分為不同 Event？

# 定位

流程：訓練紀錄流程（循環：使用者已記錄重量 > 組間休息已結束）
元素：Event：使用者已結束訓練（終點 Event）
細節：終點 Event 是否明確（A1）；分支路徑（成功 / 提前結束 / 中斷）是否都有對應 Event（A3）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 合併為一個 Event，是否完成全部動作為其攜帶資訊 |
| B | 拆為「使用者已完成訓練」與「使用者已提前結束訓練」兩個 Event，兩者獎勵不同 |
| C | 拆為兩個 Event，且提前結束時不進入訓練結算流程 |
| D | 僅保留「使用者已結束訓練」，提前結束改由「使用者訓練已中斷」承接 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響訓練紀錄流程的終點 Event 定義、訓練結算流程「訓練已結算」的 Precondition、連續訓練天數是否計入、以及訓練獎勵的發放條件。
