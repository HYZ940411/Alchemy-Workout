# 釐清問題

回歸任務指派與訓練中斷流程的退步預告 / 能力值退步在時間上可能同時發生，兩條流程的 Event 交錯順序與通知如何協調？

# 定位

流程：回歸任務流程、訓練中斷流程
元素：Event：回歸任務已指派、退步預告已發送、能力值已退步
細節：可並行發生的 Event 交錯順序（A3）；組合邊界與規則衝突（C3）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 兩條流程完全獨立並行，各自發送通知，不做協調 |
| B | 回歸任務指派時抑制訓練中斷流程的退步預告通知，合併為單一通知 |
| C | 完成回歸任務可豁免能力值退步，兩流程需建立依賴關係 |
| D | 訓練中斷流程的能力值退步發生後才指派回歸任務，嚴格序列化 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響兩條流程的 Event 時序與依賴、能力值已退步的 Precondition 是否受回歸任務狀態影響、以及使用者收到的通知數量與體驗。
