# 釐清問題

使用者當日已簽到後再次執行簽到，系統的行為與對應 Event 為何？

# 定位

流程：每日簽到流程
元素：Event：使用者已簽到
細節：狀態邊界：重複執行（C3）；失敗路徑 Event 缺失（A3、C5）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 直接拒絕，不產生任何 Event，僅回傳「今日已簽到」訊息 |
| B | 產生「簽到已拒絕」失敗 Event 供分析使用 |
| C | 按鈕在已簽到後即不可點擊，由 Read Model 阻擋，不需定義失敗行為 |
| D | 視為冪等操作，回傳當日既有的簽到結果，不重複發放獎勵也不產生新 Event |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響是否需新增失敗 Event、使用者已簽到的 Precondition 與例外路徑定義、以及簽到頁 Read Model 是否需提供「當日是否已簽到」欄位。
