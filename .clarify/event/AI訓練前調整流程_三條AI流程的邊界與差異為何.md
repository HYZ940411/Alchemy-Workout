# 釐清問題

AI 訓練前調整、AI 訓練中調整、AI 自動優化訓練三條流程的觸發時機、調整對象與作用範圍差異為何？是否應合併？

# 定位

流程：AI 訓練前調整流程、AI 訓練中調整流程（插入訓練紀錄流程循環）、AI 自動優化訓練流程
元素：Event：AI 已微調訓練強度、AI 已調整訓練、AI 已優化訓練強度
細節：兩個名稱不同實則同一事實的 Event（A2）；流程邊界（A4）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 三者獨立：訓練前調整本次課表、訓練中調整剩餘動作、自動優化調整長期課表範本，三個 Event 語意不同 |
| B | 訓練前與訓練中合併為「AI 已調整本次訓練」；自動優化獨立 |
| C | 三者合併為單一「AI 已調整訓練」Event，觸發時機為其攜帶資訊 |
| D | 三者獨立，但需統一命名為「AI 已調整訓練強度（訓練前 / 訓練中 / 長期）」 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響三條流程是否合併、三個 AI 調整 Event 的命名與語意界線、調整作用對象（本次訓練紀錄或訓練課表範本）、以及統一語言詞彙表。
