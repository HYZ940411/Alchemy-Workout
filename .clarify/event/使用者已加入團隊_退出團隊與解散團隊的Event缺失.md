# 釐清問題

模型中缺少退出團隊、踢除成員、解散團隊等 Event，這些操作是否存在？對應 Event 為何？

# 定位

流程：團隊組隊任務流程
元素：Event：使用者已建立團隊、使用者已加入團隊（缺少反向操作 Event）
細節：隱含發生但未寫出的 Event（A1）；可逆操作是否已定義對應 Event（C4）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 補上「使用者已退出團隊」與「團隊已解散」兩個 Event |
| B | 補上「使用者已退出團隊」「隊長已踢除成員」「團隊已解散」三個 Event |
| C | 補上上述三個，另加「隊長已轉讓」Event |
| D | 團隊一旦建立不可退出不可解散，無需補充 Event |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響團隊組隊任務流程的 Event 清單、團隊 Aggregate 的狀態機（是否有已解散終止狀態）、團隊與成員的關聯生命週期（D4）、以及成員退出時團隊分數的處理。
