# 釐清問題

「商品已出貨」之後的物流追蹤、送達、簽收、退換貨等 Event 是否需要建模？還是留在系統邊界之外？

# 定位

流程：實體商品購買流程
元素：Event：商品已出貨（流程終點）
細節：軟體邊界判斷（A4）；終點 Event 是否明確（A1）；跨系統邊界 Event 來源（A4）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 出貨即為系統終點，物流追蹤由外部物流商負責，僅記錄物流單號，不建模後續 Event |
| B | 補上「商品已送達」Event，由物流商回呼觸發，標示為外部系統來源 |
| C | 補上「商品已送達」與「訂單已完成」，訂單完成後才不可退貨 |
| D | 補上送達、簽收、退貨申請、退貨完成四個 Event，完整建模 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響實體商品購買流程的終點 Event 與軟體邊界、訂單 Aggregate 的狀態機終止狀態、外部物流系統的邊界標示、以及退貨時限的計算起點。
