# 釐清問題

「個人排行榜分數已增加」在每日任務流程出現兩次、訓練結算流程出現一次，三處是否為同一個 Event？

# 定位

流程：每日任務流程、訓練結算流程
元素：Event：個人排行榜分數已增加（共出現三次）
細節：兩個名稱相同實則需區分的 Event（A2）；跨流程串聯一致性（E1、E3）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 為同一個 Event，分數來源為其攜帶資訊，三處引用同一定義 |
| B | 應依來源拆為三個 Event：訓練得分 / 任務進度得分 / 任務全完成加碼得分 |
| C | 為同一 Event，但每日任務流程中的兩次應合併為一次（全部完成時一併計算） |
| D | 為同一 Event，且應獨立為「個人排行榜分數流程」由各流程觸發 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響個人排行榜分數已增加的 Event 定義與數量、個人排行榜分數 Aggregate 的來源明細是否需拆分記錄、以及排行榜週期結算流程的重置範圍。
