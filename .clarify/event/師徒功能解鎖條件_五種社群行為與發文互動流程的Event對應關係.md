# 釐清問題

師徒功能解鎖條件的五種社群行為（已追蹤 / 已發文 / 已按讚 / 已留言 / 已分享）與發文互動流程、關注流程中既有 Event 的對應關係為何？兩處命名不一致。

# 定位

流程：師徒功能解鎖流程、發文與互動流程、關注流程
元素：Rule / Policy：師徒功能解鎖條件 集滿五種社群行為各一次；對應 Event：使用者已關注帳號、發文者已發布貼文、互動者已按讚貼文、互動者已留言、發文者已分享訓練成果
細節：同義詞混用（F2）；統一語言一致性（F1）；跨流程串聯（E1）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 五種行為即對應上述五個既有 Event，僅需將 Policy 文字改用既有 Event 名稱 |
| B | 「已分享」指分享至站外，與「發文者已分享訓練成果」不同，需另定義 Event |
| C | 「已追蹤」對應「使用者已關注帳號」，但需統一術語為「關注」或「追蹤」擇一 |
| D | 五種行為需重新定義為獨立的社群行為計數 Event，與發文流程的獎勵 Event 分離 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響師徒功能解鎖條件的 Precondition 表述、統一語言詞彙表（追蹤 vs 關注、分享的兩種語意）、以及使用者已解鎖師徒功能的判定資料來源。與「發文者已分享訓練成果與已發布貼文是否為同一事實」問題相關。
