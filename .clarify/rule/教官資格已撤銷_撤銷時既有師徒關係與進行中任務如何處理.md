# 釐清問題

「教官資格已撤銷」發生時，該教官既有的師徒關係與進行中的師徒任務如何處理？

# 定位

流程：教官申請流程、師徒互動流程
元素：Rule：Event「教官資格已撤銷」的 Postcondition
細節：後置條件完整性（C2）；Aggregate 關聯的生命週期（D4）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 既有師徒關係全數自動解除（觸發「師徒關係已解除」），未完成任務作廢；學徒不適用 3 天冷卻，可立即另尋教官 |
| B | 同 A，但學徒仍適用解除後 3 天冷卻期 |
| C | 既有師徒關係保留至自然結束，僅禁止再接受新申請 |
| D | 既有師徒關係凍結（不可互動但不解除），待申訴結果決定 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響「教官資格已撤銷」的 Postcondition、是否連帶觸發「師徒關係已解除」、師徒任務的作廢規則、
以及帶徒名額與教官身分旗標的清理。
承接 G9；相關已解決項目：`resolved/event/使用者已成為教官_教官資格撤銷的Event缺失.md`（選項 A）。
