# 釐清問題

AI 調整訓練強度時，單次調整幅度的安全上下限為何？是否有絕對值上限以避免受傷風險？

# 定位

流程：AI 訓練前調整流程、AI 訓練中調整流程（插入訓練紀錄流程循環）、AI 自動優化訓練流程
元素：Rule：AI 已調整訓練 / AI 已微調訓練強度 / AI 已優化訓練強度的 Postcondition
細節：數值邊界與臨界值（C3）；Postcondition 可驗收性（C2）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 單次調整重量幅度不超過 ±10%，組數次數不超過 ±20%，且不得超過使用者歷史最大重量 |
| B | 單次調整不超過 ±15%，且新重量不得超過歷史最大重量的 105% |
| C | 無硬性上限，完全交由 AI 判斷，僅要求使用者確認 |
| D | 調整幅度依使用者健身經驗分級設定不同上限（新手較保守） |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響三條 AI 流程所有調整 Event 的 Postcondition 與驗收標準、訓練課表 Aggregate 的欄位範圍不變條件、以及是否需記錄使用者歷史最大重量供 AI 參考。這是安全性相關的核心規則。
