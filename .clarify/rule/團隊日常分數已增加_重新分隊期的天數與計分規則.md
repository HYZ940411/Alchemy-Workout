# 釐清問題

使用者提出「每週期應有一～三天讓使用者重新分隊，該期間不計分」。
此重新分隊期的天數、位於週期的哪一段、不計分的範圍為何？

# 定位

流程：團隊任務流程、排行榜週期結算流程
元素：Rule：Event「團隊日常分數已增加」與「排行榜已重置」的邊界條件
細節：C3 時間邊界。

**來源**：第 53 題，使用者於裁決「中途加入者僅能貢獻加入後產生的分數」時主動提出。
該裁決本身已回寫，本項目僅處理新提出的重新分隊期。

**為何需要此機制**：既然分數不隨人走，使用者若想換隊就必然損失當期已累積的貢獻。
重新分隊期給出一個「換隊不吃虧」的窗口。

**尚未收斂之處**：使用者給的是「一～三天」的區間而非單一值；
且未說明位於週期起點或終點、不計分的範圍是否含個人排行榜分數。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 週期**起點**起算 2 天為重新分隊期；期間團隊日常分數與團隊限時分數皆不累加，個人排行榜分數照常累積 |
| B | 週期**終點**前 2 天為重新分隊期；其餘同 A |
| C | 週期起點起算 2 天；期間團隊分數與個人排行榜分數**皆不累加** |
| D | 不設固定窗口，改以「換隊冷卻期內不計分」表達：退隊後 12 小時內的訓練不計入任何團隊分數 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響「團隊日常分數已增加」「團隊限時分數已增加」的 Precondition、
團隊排行榜週期的有效計分天數（每月 30 天扣除窗口後為 27–29 天）、
換隊冷卻期 12 小時與無懲罰退出窗口 3 小時的交互作用、
以及團隊限時任務為每日指派，窗口期間是否仍指派。

相依：`resolved/rule/團隊日常分數已增加_成員中途加入或退出時分數如何計算.md`（本項目的前置）、
`resolved/rule/使用者已建立團隊_一位使用者可否同時加入多個團隊.md`（換隊冷卻期）。
