# 釐清問題

「使用者已解鎖 自訂訓練功能」的解鎖條件為何？模型中未寫明對應的 Policy。

# 定位

流程：訓練結算流程
元素：Rule：使用者已解鎖 自訂訓練功能的 Precondition；Event 位於訓練結算流程末端
細節：Precondition 完整性（C1）；孤兒 Event（E1）；模型中缺少對應 Policy。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 完成第一次訓練結算即解鎖 |
| B | 累積完成 N 次訓練後解鎖（N 待定，需一併確認數值） |
| C | 達到指定階級後解鎖，與階級提升流程連動 |
| D | 完成新手任務即解鎖，應改掛在新手任務流程而非訓練結算流程 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響使用者已解鎖 自訂訓練功能的 Precondition 與所屬流程、使用者 Aggregate 的功能解鎖旗標、自訂訓練流程「使用者已開始設計訓練」的 Precondition。若選 D 則需將該 Event 移出訓練結算流程。
