# 釐清問題

同一人重複註冊、或解除安裝後重裝，如何確保「註冊獎勵已發放」只發生一次？

# 定位

流程：註冊流程
元素：Rule：註冊獎勵已發放的 Precondition / Postcondition
細節：同一 Event 重複發生時的冪等性（A3）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 以帳號為單位，每個新帳號都發放一次，不做去重 |
| B | 以已驗證的 Email / 手機為唯一鍵去重，同一識別碼僅發放一次 |
| C | 以裝置識別碼去重，同一裝置僅發放一次 |
| D | 以 Email / 手機 加 裝置識別碼 雙重去重 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響註冊獎勵已發放的 Precondition、使用者 Aggregate 的唯一性規則（D3 主鍵與唯一性）、以及獎勵 Aggregate 的發放紀錄設計。
