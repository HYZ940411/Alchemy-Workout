# 釐清問題

「訓練成就門檻」中連續門檻標示為「天」、累積門檻標示為「天」，累積成就實際計算的是訓練天數還是訓練次數？同一天訓練多次如何計算？

# 定位

流程：訓練結算流程
元素：Rule / Policy：訓練成就門檻（連續 1/3/5/7/10/15/20/25/30 天；累積 3/5/7/10/15/25/50/75/100 天）；Event：累積訓練成就已解鎖
細節：模糊描述與單位不明（F4）；數值邊界（C3）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 累積計算的是「有訓練的日數」，同一天訓練多次僅計一天 |
| B | 累積計算的是「訓練次數」，同一天訓練多次分別計數，門檻文字應改為「次」 |
| C | 累積計算日數，但同一天第二次以後的訓練仍計入排行榜分數 |
| D | 連續與累積皆以次數計算 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響累積訓練成就已解鎖的 Precondition、連續訓練 Aggregate 的計數欄位定義、以及同一天多次訓練時連續訓練天數是否重複增加。
