# 釐清問題

同一內容被再次檢舉時，應併入既有案件或另開新案？（模型現以〔推導〕標記「併入既有待審視案件；已結案則另開新案」，未經使用者確認）

# 定位

流程：管理員管理社群流程
元素：Rule：Aggregate「檢舉」的合併規則
細節：狀態邊界 — 終止狀態下的再次操作（C3）；待決事項（F3）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 確認現有推導：併入既有待審視案件；該對象已結案（成立或駁回）則另開新案 |
| B | 一律另開新案，管理員自行判斷是否重複 |
| C | 併入既有待審視案件；已成立者不再受理新檢舉，已駁回者可另開新案 |
| D | 同 A，且同一使用者對同一對象重複檢舉時直接拒絕，不新增檢舉者紀錄 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響檢舉 Aggregate 的檢舉者集合累加規則、檢舉狀態機的入口條件、以及管理員待審視清單 Read Model 的筆數。
