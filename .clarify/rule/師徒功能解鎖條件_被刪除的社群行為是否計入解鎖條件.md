# 釐清問題

使用者若在達成五種社群行為後刪除貼文、取消按讚或取消關注，是否影響師徒功能解鎖？已解鎖是否撤銷？

# 定位

流程：師徒功能解鎖流程
元素：Rule：使用者已解鎖師徒功能的 Precondition
細節：單調遞增與不可逆性（C4）；狀態邊界（C3）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 以歷史行為計數，行為刪除不影響計數，已解鎖永久保留 |
| B | 以當前有效行為計數，刪除後計數遞減，但已解鎖不撤銷 |
| C | 以當前有效行為計數，刪除後若低於門檻則撤銷解鎖 |
| D | 解鎖後永久保留，但管理員處罰時可停權 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響使用者已解鎖師徒功能的 Precondition 與單調性、使用者 Aggregate 的社群行為計數欄位定義、以及與發文互動流程「取消互動時成就計數是否遞減」問題的一致性。
