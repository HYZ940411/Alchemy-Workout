# 釐清問題

團隊限時分數的「每位成員完成一次限時任務」固定分為多少？全員完成的加成幅度為何？團隊人數不足 5 人時「全員完成」如何認定？

# 定位

流程：團隊任務流程
元素：Rule：Event「團隊限時分數已增加」的 Postcondition
細節：衍生欄位公式（D3）；數值邊界與組合邊界（C3）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 每人 10 分；全員完成額外加 50 分（固定分數）；全員＝當前實際成員數皆完成 |
| B | 每人 10 分；全員完成給 1.5 倍加成（百分比倍率）；全員＝當前實際成員數皆完成 |
| C | 同 A，但全員完成須團隊滿 5 人才認定，未滿員不予加成 |
| D | 三者皆為平台級可調參數，由管理員設定；全員＝當前實際成員數皆完成 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響「團隊限時分數已增加」的 Postcondition 驗收、團隊限時排行榜的公平性（小隊 vs 滿員隊）、以及團隊限時排行獎勵的分佈。
