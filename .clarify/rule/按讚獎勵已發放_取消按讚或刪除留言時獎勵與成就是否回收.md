# 釐清問題

使用者取消按讚、刪除留言或刪除貼文時，先前發放的獎勵是否回收？累計互動成就的計數是否遞減？

# 定位

流程：發文與互動流程
元素：Rule：分享獎勵 / 發文獎勵 / 按讚獎勵 / 留言獎勵已發放的可逆性；Policy：累計互動成就門檻
細節：單調遞增與不可逆性（C4）；可逆操作的 Event 定義（C4）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 獎勵不回收，成就計數不遞減（單調遞增），但同一貼文重複按讚取消不重複發獎 |
| B | 獎勵回收且成就計數遞減，需補上取消相關 Event |
| C | 獎勵不回收但成就計數遞減，已解鎖的成就不撤銷 |
| D | 獎勵於行為發生 24 小時後才發放，期間內取消則不發放（延遲確認） |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響四種互動獎勵的 Precondition 與可逆性、成就 Aggregate 的計數欄位單調性、是否需新增「已取消按讚 / 已刪除留言」Event、以及防刷規則設計。
