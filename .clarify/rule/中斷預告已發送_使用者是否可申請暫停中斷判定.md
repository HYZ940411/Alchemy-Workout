# 釐清問題

使用者因受傷、旅行等原因無法訓練時，是否可申請暫停「連續訓練中斷判定」以保住連續天數？

# 定位

流程：訓練中斷流程
元素：Rule：連續訓練中斷判定的 Precondition（例外豁免）
細節：組合邊界與規則衝突（C3）；例外路徑（C5）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 無暫停機制，一律依時間判定 |
| B | 可申請請假模式，需補上「訓練休假已啟用 / 已結束」Event，休假期間不判定中斷 |
| C | 可使用道具（類似補簽券）保住連續天數，需補上「連練保護券已使用」Event |
| D | 會員訂閱者每月享有固定次數的自動保護，非會員無此機制 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響是否需新增休假 / 保護相關 Event 與 Aggregate、連續訓練中斷判定 Policy 的 Precondition 例外條件、會員權益內容、以及虛擬商品品項。
