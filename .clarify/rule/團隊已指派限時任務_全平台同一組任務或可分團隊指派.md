# 釐清問題

「團隊已指派限時任務」是全平台所有團隊皆指派同一組任務，或可分團隊指派不同任務？

# 定位

流程：團隊任務流程
元素：Rule：Event「團隊已指派限時任務」的 Precondition / Postcondition；Command「設定限時任務」的輸入
細節：Command 輸入（B3）；組合邊界（C3）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 全平台統一：一個指派日只有一組限時任務，所有團隊相同 |
| B | 可分團隊：管理員依團隊人數分組指派不同任務 |
| C | 可分團隊：自任務池隨機抽取，各團隊可能不同 |
| D | 全平台統一同 A，但管理員可另行對指定團隊覆寫 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響「管理員已設定限時任務」的輸入參數、「團隊已指派限時任務」的 Postcondition、以及團隊限時排行榜的公平性基礎。
承接 G15。**注意**：`resolved/command/管理員已設定限時任務_此管理員是平台管理員或團隊隊長.md`（選項 D）僅確認設定者為平台管理員，未表態指派範圍，不得推定為全平台統一。
與 `rule/週期開始指派管理員設定的限時任務_週期的長度與起訖時點為何.md` 為同一組 Policy 的另一面，宜併題處理。
