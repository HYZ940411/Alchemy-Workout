# 釐清問題

AI 訓練中調整後「訓練進度條已重算」，若調整後總組數增加導致進度百分比下降，是否違反進度單調遞增原則？應如何處理？

# 定位

流程：AI 訓練中調整流程（插入訓練紀錄流程循環）、訓練紀錄流程（循環：使用者已記錄重量 > 組間休息已結束）
元素：Rule：訓練進度條已重算的 Postcondition；Aggregate：訓練進度條
細節：單調遞增與不可逆性（C4）；跨流程一致性（E3）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 允許進度下降，進度反映當前實際完成比例，不套用單調遞增 |
| B | 進度不可下降，新增的組數以擴充分母但鎖定已達進度的方式處理 |
| C | 改以絕對值顯示（已完成 N 組 / 共 M 組），不使用百分比，迴避單調遞增問題 |
| D | 訓練中僅允許 AI 減少而不允許增加訓練量，確保進度單調遞增 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響訓練進度條的計算公式與不變條件、訓練進度條已重算的 Postcondition、AI 訓練中調整的 Precondition（可調整範圍），並依賴「訓練進度條計算公式」問題的答案。
