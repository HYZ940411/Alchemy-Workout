# 釐清問題

「能力值已退步」之後，使用者是否可透過恢復訓練將能力值補回？回復速度與退步速度是否對稱？

# 定位

流程：訓練中斷流程
元素：Rule：能力值已退步的 Postcondition；可逆性
細節：單調遞增與可逆性（C4）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 不可直接補回，只能透過正常訓練重新累積能力值 |
| B | 回歸任務完成後一次性補回退步的能力值，需補上對應 Event |
| C | 恢復連續訓練 N 天後自動補回，需補上「能力值已回復」Event |
| D | 退步不可逆，且不影響歷史最高能力值紀錄 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響能力值 Aggregate 是否需記錄歷史最高值、是否需新增「能力值已回復」Event、與回歸任務流程「回歸任務獎勵已發放」的內容關係、以及階級提升流程的階級穩定性。
