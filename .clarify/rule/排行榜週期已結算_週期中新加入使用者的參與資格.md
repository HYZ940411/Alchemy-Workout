# 釐清問題

週期中途註冊的使用者或中途建立的團隊，是否參與該週期的排行榜結算？是否有最低參與門檻？

# 定位

流程：排行榜週期結算流程
元素：Rule：排行榜週期已結算的 Precondition
細節：類別邊界與特殊值（C3）；Precondition 完整性（C1）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 一律參與，無門檻，分數為 0 者不列入排名 |
| B | 需達最低分數門檻才列入排名並具領獎資格 |
| C | 需在週期開始前即已註冊 / 建立才參與，中途加入者從下一週期起算 |
| D | 一律參與，且分數為 0 者仍列入排名末位 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響排行榜週期已結算的 Precondition、三種獎勵發放的資格判定、排行榜 Read Model 的篩選規則、以及新使用者的體驗設計。
