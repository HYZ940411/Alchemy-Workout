# 釐清問題

一位使用者可否同時建立或加入多個團隊？換隊是否有冷卻期？

# 定位

流程：團隊組隊任務流程
元素：Rule：使用者已建立團隊 / 使用者已加入團隊的 Precondition
細節：Precondition 完整性與數量限制（C1）；組合邊界（C3）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 同時僅能屬於一個團隊，需先退出才能加入新團隊，無冷卻期 |
| B | 同時僅能屬於一個團隊，換隊後 7 天內不可再換（防刷分） |
| C | 可同時加入多個團隊，但分數僅計入指定的主要團隊 |
| D | 可同時加入多個團隊，分數同時計入所有團隊 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響兩個加入 / 建立 Command 的 Precondition、使用者與團隊的關聯關係（一對一或一對多）、團隊分數的計算與防刷規則。與「成員中途加入退出分數計算」問題可一併處理。
