# 釐清問題

註冊推薦 Policy 依「經驗 / 目標 / 器材」比對，健身目標最多 2 項（動機類 1 ＋ 常見目標 1）。多目標組合如何產出唯一的推薦結果？

# 定位

流程：註冊流程
元素：Rule：Policy「依經驗 / 目標 / 器材 從既有計畫中推薦」→ Event「訓練計畫已推薦」的 Precondition
細節：前置條件完整性（C1）；組合邊界與套用順序（C3）；Read Model → Command 支撐（E4）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 動機類不參與比對（僅供顯示 / 激勵文案）；比對優先序為 器材 → 經驗 → 常見目標；同分時取建立時間最早者 |
| B | 動機類不參與比對；三者皆為必要條件（AND），無完全符合者則放寬常見目標；同分時隨機取一 |
| C | 動機類參與比對並具最高權重；以加權計分取最高分者 |
| D | 不做自動比對，改為推薦固定的入門計畫，待使用者累積訓練後才依資料推薦 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響「訓練計畫已推薦」的唯一性驗收（推薦為單向指派、使用者不可拒絕，故結果必須唯一）、
訓練計畫 Aggregate 的「適用條件」欄位結構、以及動機類目標的存在意義。
承接 G16；相關已解決項目：`resolved/command/使用者已填入健身目標_健身目標與健身器材可否複選.md`（選項 D）、`resolved/event/訓練計畫已推薦_使用者拒絕推薦計畫時的Event為何.md`。
依賴 `command/使用者已填入健身目標_動機類與常見目標類的完整值域清單為何.md` 的值域定案。
