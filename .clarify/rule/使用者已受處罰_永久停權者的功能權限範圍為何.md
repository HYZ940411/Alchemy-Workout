# 釐清問題

永久停權的使用者是否仍可繼續訓練？若可，哪些累積（階級、能力值、
個人排行榜分數、成就、金幣）應停止？各處罰級距可用與不可用的功能清單為何？

# 定位

流程：管理員管理社群流程
元素：Rule：Event「使用者已受處罰」的 Postcondition
細節：C3 狀態邊界、B5 Actor 權限。

**來源**：第 56 題，使用者裁決「僅帳號停權與永久停權暫停計時」後主動提出：
「我不知道讓永久停權使用者也能繼續訓練，但不能累積階級、能力值等，是否可以？」

**與既有裁決的張力**：第 56 題已定案「帳號停權期間暫停所有計時」，
其理由為「使用者根本無法登入」。若永久停權者仍可訓練，
則該前提對永久停權不成立，第 56 題的規則需依處罰種類再細分。

**四級處罰現況**：警告 / 社群功能停權（限期）/ 帳號停權（限期）/ 永久停權。
模型目前僅定義處罰狀態欄位，未定義任一級距的具體功能限制清單。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 永久停權者無法登入，比照帳號停權；模型不提供「可訓練但不累積」的狀態 |
| B | 永久停權者可登入並訓練，但階級、能力值、個人排行榜分數、成就、金幣一律不累積；社群功能全面關閉 |
| C | 同 B，但能力值仍可累積（能力值為身體能力的紀錄，非平台獎勵） |
| D | 永久停權者可登入但僅可讀取自身歷史資料，不可訓練亦不可互動 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響「使用者已受處罰」的 Postcondition、四級處罰各自的功能限制清單、
第 56 題「帳號停權暫停計時」規則是否需依級距再細分、
永久停權者的訓練紀錄是否進入 AI 訓練品質評分與排行榜、
以及帳號生命週期（永久停權與帳號刪除為兩個不同的終止狀態）。

相依：`resolved/rule/使用者已受處罰_停權期間的訓練與能力值退步與連續天數如何處理.md`（第 56 題）。
