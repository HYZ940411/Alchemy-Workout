# 釐清問題

因逾時而「使用者訓練已中斷」的訓練，是否仍進行結算並發放訓練獎勵？是否計入連續訓練天數？

# 定位

流程：訓練結算流程、訓練紀錄流程（循環：使用者已記錄重量 > 組間休息已結束）
元素：Rule：訓練已結算的 Precondition
細節：狀態邊界與例外路徑（C3、C5）；跨流程串聯一致性（E1）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 中斷的訓練不結算、不發獎、不計入連續訓練天數 |
| B | 中斷的訓練照常結算並依已完成組數按比例發獎，計入連續訓練天數 |
| C | 中斷的訓練結算並發獎，但不計入連續訓練天數與成就門檻 |
| D | 達到最低完成門檻（如 50% 進度）才結算發獎，否則作廢 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響訓練已結算的 Precondition、連續訓練已紀錄的判定、訓練獎勵已發放與能力值 / 經驗值提升的條件、以及訓練中斷流程連續訓練中斷判定的計時是否重設。
