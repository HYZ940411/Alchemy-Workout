# 釐清問題

AI 服務回應逾時、失敗或產出不合理方案時，系統的行為與對應 Event 為何？

# 定位

流程：AI 訓練前調整流程、AI 訓練中調整流程（插入訓練紀錄流程循環）、AI 自動優化訓練流程
元素：Rule：AI 調整相關 Command 的例外路徑
細節：失敗與例外路徑（C5）；跨系統邊界（A4）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 補上「AI 調整已失敗」Event，維持原訓練內容並提示使用者稍後再試 |
| B | 補上「AI 調整已失敗」Event，並自動改用規則式預設調整方案 |
| C | 不產生 Event，僅在前端顯示錯誤，訓練不受影響 |
| D | 補上「AI 調整已失敗」Event，且訓練中調整時直接沿用原課表繼續訓練 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響三條 AI 流程的例外路徑 Event、訓練課表 Aggregate 在失敗時的狀態一致性（是否需回復）、以及訓練中調整失敗時訓練紀錄流程能否繼續。
