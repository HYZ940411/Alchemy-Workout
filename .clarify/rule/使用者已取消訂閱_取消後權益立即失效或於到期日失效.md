# 釐清問題

「使用者已取消訂閱」（於 App Store 設定中操作）發生後，會員權益立即失效，或維持至當期到期日才失效？

# 定位

流程：會員訂閱流程
元素：Rule：Event「使用者已取消訂閱」→「會員權益已失效」的時序與 Precondition
細節：時間邊界（C3）；狀態邊界（C3）；生命週期與狀態機（D5）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 維持至當期到期日才失效：取消僅停止續約，「會員權益已失效」於到期時點才發生 |
| B | 立即失效：收到 App Store 取消通知即觸發「會員權益已失效」 |
| C | 同 A，且須補「會員訂閱已到期」Event 承接到期時點，與取消區分 |
| D | 同 A，並新增會員權益生效狀態值「已取消待到期」 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響會員權益 Aggregate 的生效狀態值域與到期時點欄位、「會員權益已失效」的觸發來源（取消 vs 到期 vs 扣款失敗）、
以及各流程會員 Precondition 在取消後至到期前的判定結果。
本項為新掃描發現，非承接 `pending-gaps.md`。流程檔現以「使用者已取消訂閱 → 會員權益已失效」相鄰列出，隱含立即失效，與 App Store 實務不符。
與 `rule/會員權益已生效_訂閱到期後既有資料與權益如何處理.md` 及 `event/會員訂閱已續訂_AppStore扣款失敗與寬限期是否納入軟體邊界.md`（G4）宜併題處理。
