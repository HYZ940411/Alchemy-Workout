# 釐清問題

能力值提升端採遞減報酬（隨現值收斂至理論上限 1,000），退步端為固定 2.5% / 120 小時，兩者會在某個現值形成動態平衡點。該平衡點是否落在合理區間？若過低（如僅 200–300），理論上限 1,000 將永無意義。

# 定位

流程：訓練結算流程、訓練中斷流程
元素：Rule：能力值提升公式的遞減報酬係數；能力值退步參數
細節：C3 數值邊界、D3 Aggregate 內部不變條件。
需驗算的情境：以每週 3 練、各肌群輪流訓練的典型頻率，推算各維的收斂值；並確認規律訓練者（該維 120 小時內必再訓練）是否確實永不退步 —— 若是，則平衡點僅對不規律者存在。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 先驗算典型頻率下的收斂值，再依結果決定是否調整理論上限或基準提升點數；本題答案為「驗算後再定」 |
| B | 維持現行參數：理論上限 1,000 本即為漸近線，收斂值低於上限屬預期，不調整 |
| C | 調高基準提升點數（10 點 → 更高）使收斂值上移，讓 1,000 的上限具備實際意義 |
| D | 調低理論上限至典型收斂值附近（如 400–500），使六維雷達圖的滿格更貼近可達水準 |
| Short | 提供其他簡短答案（<=5 字） |
