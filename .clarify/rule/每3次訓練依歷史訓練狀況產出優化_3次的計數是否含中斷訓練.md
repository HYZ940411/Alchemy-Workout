# 釐清問題

「每 3 次訓練依歷史訓練狀況產出優化」的計數，是否包含中斷的訓練與提前結束的訓練？計數在使用者拒絕優化後是否重置？

# 定位

流程：AI 自動優化訓練流程
元素：Rule / Policy：每 3 次訓練依歷史訓練狀況產出優化
細節：數值邊界與計數定義（C3）；跨流程一致性（E3）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 僅計入完整完成並已結算的訓練；拒絕優化後計數歸零重新累積 |
| B | 所有已結算的訓練皆計入（含中斷）；拒絕優化後計數歸零 |
| C | 僅計入完整完成的訓練；拒絕優化後計數不歸零，下次訓練即再次提出 |
| D | 以自然週期（每 3 個訓練日）計算，與訓練完整度無關 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響 AI 自動優化訓練流程的觸發 Precondition、訓練紀錄 Aggregate 是否需要「已計入優化計數」旗標、以及與訓練結算流程「中斷的訓練是否結算」問題的依賴關係（需先確定該題）。
