# 釐清問題

隊長執行「退出團隊」時，是否必須先轉讓隊長？若隊長為最後一名成員，退出是否等同解散團隊？

# 定位

流程：團隊組隊流程
元素：Rule：Event「使用者已退出團隊」的 Precondition / Postcondition
細節：前置條件（C1）；狀態邊界（C3）；Aggregate 關聯的生命週期（D4）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 隊長須先轉讓隊長方可退出；若無其他成員，退出即觸發「團隊已解散」 |
| B | 隊長退出時系統自動將隊長轉讓給最早加入的成員；無其他成員則自動解散 |
| C | 隊長不得退出，只能解散團隊或轉讓後退出（轉讓為獨立操作，不自動） |
| D | 隊長可直接退出，團隊進入無隊長狀態，由成員自行推選 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響「使用者已退出團隊」的 Precondition、「隊長已轉讓」與「團隊已解散」的觸發關係、以及團隊 Aggregate 的隊長欄位不變條件（隊長必為成員之一）。
