# 釐清問題

訓練進行中或結束後，已記錄的組數（重量 / 次數）可否修改或刪除？

# 定位

流程：訓練紀錄流程（循環：使用者已記錄重量 > 組間休息已結束）
元素：Rule：訓練紀錄的可逆性；Event：使用者已紀錄該組重量、使用者已紀錄該組次數
細節：單調遞增與不可逆性（C4）；可逆操作是否已定義對應 Event（C4）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 訓練進行中可修改，一旦「使用者已結束訓練」即凍結不可改（單調遞增） |
| B | 隨時可修改，但需補上「訓練紀錄已修改」Event，且修改後需重新結算 |
| C | 完全不可修改，記錄即定案，錯誤只能作廢整筆訓練 |
| D | 訓練進行中可修改當前動作的組數，已完成的動作不可回頭修改 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響訓練紀錄 Aggregate 的狀態機與可寫入時間窗、是否需新增「訓練紀錄已修改 / 已刪除」Event、訓練進度條的單調遞增限制、以及訓練結算流程「訓練已結算」後的資料一致性。
