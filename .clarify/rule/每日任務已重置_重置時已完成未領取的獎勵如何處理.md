# 釐清問題

「每日任務已重置」時，已完成但尚未領取的任務獎勵如何處理？未完成的進度是否完全歸零？

# 定位

流程：每日任務流程
元素：Rule：每日任務已重置的 Postcondition
細節：Postcondition 原子化與涵蓋所有被改變的欄位（C2）；狀態邊界（C3）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 獎勵在任務完成時即自動發放，不存在未領取狀態；進度完全歸零 |
| B | 需使用者主動領取，未領取者於重置時作廢；進度完全歸零 |
| C | 需使用者主動領取，未領取者保留至領取為止；進度完全歸零 |
| D | 獎勵自動發放；進度歸零但已完成的任務計入累計成就不受影響 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響每日任務獎勵已發放的觸發時機與 Actor、每日任務已重置的 Postcondition、是否需新增「每日任務獎勵已領取」Event、以及獎勵 Aggregate 的待領取狀態設計。
