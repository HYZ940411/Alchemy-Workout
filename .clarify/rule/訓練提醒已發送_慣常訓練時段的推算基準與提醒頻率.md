# 釐清問題

「訓練提醒已發送」的兩段式發送中，有訓練紀錄者的「慣常訓練時段」以什麼基準推算、粒度為何？提醒頻率為何（每日？僅偏好時段當天未訓練時？連續未訓練是否升頻或降頻）？

# 定位

流程：訓練紀錄流程（事前提醒路徑）
元素：Rule：Event「訓練提醒已發送」的 Precondition 與發送策略
細節：C1 前置條件完整性、F4 模糊描述。訓練紀錄流程檔第 70 行以 `[待決策 Partial]` 標記本題。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 推算基準＝最近 10 次訓練開始時戳的**眾數小時**（粒度 1 小時）；頻率＝每日，於推算時段前 30 分鐘發送，當日已訓練則不發 |
| B | 推算基準＝最近 10 次訓練開始時戳的**中位數**（粒度 30 分鐘）；頻率同 A |
| C | 推算基準同 A，但頻率改為僅依註冊填入的「每週健身天數」發送（如每週 3 天者一週僅提醒 3 次），避免每日打擾 |
| D | 推算基準同 A；頻率為每日，且連續未訓練時**降頻**（未訓練達 3 日後改為隔日提醒），避免無效推播疲乏 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響「訓練提醒已發送」的 Precondition 可驗收性（該 Event 已標記為「不需精準追蹤」，但發送條件仍須可判定）、與另外 4 個通知類 Event 的同日重疊策略、以及訓練紀錄查詢是否需支援「最近 N 次的開始時戳」。
