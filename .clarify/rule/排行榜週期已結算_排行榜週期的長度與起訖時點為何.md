# 釐清問題

排行榜週期的長度與起訖時點為何？（每週 / 每月？自何時起算、於何時結算？）

# 定位

流程：排行榜週期結算流程、訓練結算流程、每日任務流程
元素：Rule：Event「排行榜週期已結算」「排行榜已重置」的 Precondition
細節：時間邊界（C3）；模糊描述量化（F4）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 每週：當地時間週一 00:00 起算，週日 23:59 結束，結算後即時重置 |
| B | 每月：當地時間每月 1 日 00:00 起算，月底結束 |
| C | 每週同 A，但起訖與結算一律以平台統一時區為準，不依使用者當地時區 |
| D | 週期長度為平台級可調參數，由管理員設定，預設每週 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響三個排行榜的結算時點、個人排行榜分數的重置時點、週期中新加入使用者的參與資格
（`rule/排行榜週期已結算_週期中新加入使用者的參與資格.md`），以及跨時區使用者的結算一致性。
本項為新掃描發現，非承接 `pending-gaps.md`。
註：`rule/週期開始指派管理員設定的限時任務_週期的長度與起訖時點為何.md` 原涵蓋限時任務週期，但限時任務已定為「每日指派」，故排行榜週期的長度仍為缺口。
與 `00_全域規範.md` 的時區判定基準應一併處理。
