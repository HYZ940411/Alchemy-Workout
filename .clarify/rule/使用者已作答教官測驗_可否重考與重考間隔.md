# 釐清問題

教官測驗未通過後可否重考？重考次數上限與間隔為何？簡答題人工審核的時限為何？

# 定位

流程：教官申請流程
元素：Rule：使用者已作答教官測驗的 Precondition；Policy：教官測驗判定（選擇題系統即時判定，簡答題管理員人工審核）
細節：時間邊界與數量限制（C1、C3）；例外路徑（C5）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 可重考，間隔 7 天，無次數上限；人工審核無時限 |
| B | 可重考，間隔 30 天，最多 3 次；人工審核需於 7 個工作天內完成 |
| C | 可重考，間隔 7 天，最多 3 次；人工審核逾 7 天未處理則自動通過 |
| D | 不可重考，一次未通過即永久喪失申請資格 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響使用者已作答教官測驗的 Precondition、教官申請 Aggregate 的重考次數與冷卻欄位、管理員已審核教官測驗的時限規則、以及審核逾時的例外處理。
