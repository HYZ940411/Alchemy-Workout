# 釐清問題

「連續訓練中斷判定」中 24 / 36 / 96 / 120 小時的計時起點為何？是上次訓練的開始時間、結束時間，還是上次訓練日的日界？

# 定位

流程：訓練中斷流程
元素：Rule / Policy：連續訓練中斷判定（超過 24 小時未訓練 → 中斷預告；36 小時 → 連練天數中斷、失去加成、中斷通知；96 小時 → 退步預告；120 小時 → 能力值退步）
細節：時間邊界與計時起點（C3）；與每日簽到流程連簽中斷判定的一致性。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 以上次訓練的結束時戳起算 |
| B | 以上次訓練的開始時戳起算 |
| C | 以上次訓練日的日界起算，與簽到換日時點一致 |
| D | 以上次「訓練已結算」的時戳起算，中斷的訓練不重設計時 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響中斷預告已發送、連練天數已中斷、使用者已失去獎勵加成、連練中斷通知已發送、退步預告已發送、能力值已退步六個 Event 的觸發時點，以及訓練紀錄 Aggregate 需記錄哪個時戳。
