# 釐清問題

「限時回歸訓練」的時限長度為何？時限起算點為指派時刻還是使用者首次查看時刻？

# 定位

流程：回歸任務流程
元素：Rule：回歸任務已指派的 Postcondition；Event：使用者已完成回歸任務
細節：模糊描述未量化（F4）；時間邊界與計時起點（C3）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 指派後 3 天內完成，自指派時刻起算 |
| B | 指派後 7 天內完成，自指派時刻起算 |
| C | 指派後 7 天內完成，自使用者首次登入查看時起算 |
| D | 無固定時限，直到使用者完成一次訓練為止 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響回歸任務已指派的 Postcondition（到期時戳欄位）、回歸任務 Aggregate 的狀態機、以及逾期未完成 Event 的觸發時點。
