# 釐清問題

自建動作不計入能力值計算，其「所屬肌群」欄位是否仍為必填？「所需器材」是否必填？

# 定位

流程：自訂訓練流程
元素：Rule：Event「使用者已建立自訂動作」的 Precondition
細節：前置條件完整性（C1）；欄位定義與空值處理（D2 / C3）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 所屬肌群與所需器材皆必填，與平台動作庫欄位一致 |
| B | 兩者皆選填，可留空；訓練紀錄與 Read Model 顯示為「未分類」 |
| C | 所屬肌群必填（供 Read Model 分類與統計），所需器材選填 |
| D | 兩者皆選填，且自建動作不進入任何依肌群分類的 Read Model |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響「使用者已建立自訂動作」的 Precondition、動作 Aggregate 的欄位可空性、以及依肌群分類的訓練統計 Read Model。
承接 G20；相關已解決項目：`resolved/aggregate/動作_動作清單的來源與欄位定義.md`（選項 B，已定自建動作不計入能力值）。
