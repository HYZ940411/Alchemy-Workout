# 釐清問題

自訂訓練已發布或已通過公開審核後，原作者可否修改或刪除？已有他人使用中的課表如何處理？

# 定位

流程：自訂訓練流程（循環 1：使用者已選擇動作 > 使用者已設定該動作的組數、循環 2：使用者已設定該組的重量 & 次數）
元素：Rule：使用者已發布自訂訓練的可逆性；Aggregate：自訂訓練與訓練紀錄的關聯
細節：可逆操作是否已定義對應 Event（C4）；關聯的生命週期（D4）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 可隨時修改與刪除，使用中的他人課表沿用刪除前的快照版本 |
| B | 可修改但需重新審核；刪除則僅下架，既有使用者仍可繼續使用 |
| C | 已公開者不可修改不可刪除，只能下架並發布新版本 |
| D | 可自由修改，他人使用中的課表即時同步變更 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響是否需新增「自訂訓練已修改 / 已下架」Event、自訂訓練 Aggregate 是否需要版本欄位、訓練紀錄 Aggregate 與自訂訓練的關聯生命週期、以及重新審核的 Precondition。
