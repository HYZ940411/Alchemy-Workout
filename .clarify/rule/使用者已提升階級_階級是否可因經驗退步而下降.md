# 釐清問題

階級是否只能提升不能下降？訓練中斷流程的「能力值已退步」是否會連帶造成經驗值下降與降階？

# 定位

流程：階級提升流程、訓練中斷流程
元素：Rule：使用者已提升階級的 Postcondition；單調遞增限制
細節：單調遞增與不可逆性（C4）；跨流程一致性（E3）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 階級單調遞增，永不下降；能力值退步不影響經驗值與階級 |
| B | 經驗值可因中斷而下降，階級隨之下降，需補上「使用者已降低階級」Event |
| C | 經驗值可下降但階級不下降（階級記錄歷史最高），僅顯示當前經驗值 |
| D | 階級不下降，但已解鎖的進階訓練計畫在經驗值低於門檻時暫時鎖定 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響階級 Aggregate 的單調遞增不變條件、是否需新增降階 Event、能力值與經驗值是否為獨立數值、以及進階訓練計畫已解鎖的可逆性。
