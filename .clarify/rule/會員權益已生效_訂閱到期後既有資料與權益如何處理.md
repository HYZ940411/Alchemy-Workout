# 釐清問題

會員訂閱到期或取消後，訂閱期間取得的資料與權益（如進階訓練計畫、超額補簽券）如何處理？

# 定位

流程：會員訂閱流程
元素：Rule：會員權益已生效的可逆性；Aggregate：會員權益的生命週期
細節：狀態邊界與終止狀態（C3）；關聯的生命週期（D4）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 權益立即失效，進階計畫鎖定但資料保留，已取得的補簽券仍可使用 |
| B | 權益立即失效，進階計畫與未使用的補簽券一併作廢 |
| C | 權益於當期結束時失效，已取得的所有資源永久保留 |
| D | 權益立即失效，但保留 30 天寬限期供使用者續訂恢復 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響會員權益已生效 / 已失效的 Postcondition、進階訓練計畫已解鎖的可逆性、補簽券 Aggregate 的有效期規則、以及使用者 Aggregate 的會員狀態欄位設計。
