# 釐清問題

新手任務是否有完成期限？逾期未完成時會發生什麼？

# 定位

流程：新手任務流程
元素：Rule：使用者已完成新手任務的 Precondition；缺失的逾時 Event
細節：隱含未寫出的逾時 Event（A1）、時間邊界（C3）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 無期限，永久有效直到完成 |
| B | 有期限（如註冊後 7 天），逾期產生「新手任務已逾期」Event，獎勵不再發放 |
| C | 有期限但逾期僅降低獎勵，仍可完成，產生「新手任務已逾期」Event |
| D | 有期限，逾期後自動轉為回歸任務 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響是否需新增逾時 Event、新手任務 Aggregate 的狀態機（是否有「已逾期」終止狀態）、以及「新手任務獎勵已發放」的 Precondition。
