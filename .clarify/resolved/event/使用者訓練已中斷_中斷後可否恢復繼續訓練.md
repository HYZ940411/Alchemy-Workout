# 釐清問題

「使用者訓練已中斷」之後，該筆訓練是否可以恢復並繼續？

# 定位

流程：訓練紀錄流程（循環：使用者已記錄重量 > 組間休息已結束）
元素：Event：使用者訓練已中斷
細節：可逆操作是否為合法路徑並定義其 Event（C4）；終止狀態下可否再次執行（C3）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 中斷即為終止狀態，不可恢復，已記錄的組數保留並進入結算 |
| B | 可在 24 小時內恢復，需補上「訓練已恢復」Event，恢復後進度延續 |
| C | 中斷即終止且已記錄資料作廢，不進入結算 |
| D | 不可恢復，但可以已中斷的紀錄為範本快速開始一筆新訓練 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響訓練紀錄 Aggregate 的狀態機（是否有「已中斷」終止狀態）、是否需新增恢復 Event、訓練結算流程是否處理中斷的訓練、以及連續訓練天數的計算。

# 優先級

High

# 解決結果

A — 中斷即為終止狀態，不可恢復。已記錄的組數保留，並進入訓練結算流程。不新增「訓練已恢復」Event。
