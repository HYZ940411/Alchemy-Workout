# 釐清問題

「使用者已紀錄該組重量」與「使用者已紀錄該組次數」是否應合併為單一 Event「使用者已記錄該組成績」？

# 定位

流程：訓練紀錄流程（循環：使用者已記錄重量 > 組間休息已結束）
元素：Event：使用者已紀錄該組重量、使用者已紀錄該組次數、使用者已完成該組
細節：事件顆粒度與是否為畫面操作（A1）；三個 Event 的因果關係（A3）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 合併為單一 Event「使用者已記錄該組成績」，重量與次數為其攜帶資訊 |
| B | 維持兩個獨立 Event，因為兩者可分開輸入且可分別修改 |
| C | 三個 Event（重量、次數、完成該組）合併為一個「使用者已完成該組」 |
| D | 重量與次數合併，但保留獨立的「使用者已完成該組」作為循環結束標記 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響訓練紀錄流程的循環結構定義、訓練紀錄 Aggregate 的寫入時機、訓練進度條已增加的觸發點、以及逾時中斷判定「每完成一組中斷計時歸零」的判定依據。

# 優先級

High

# 解決結果

A — 「使用者已紀錄該組重量」與「使用者已紀錄該組次數」合併為單一 Event「使用者已記錄該組成績」，重量與次數為其攜帶資訊。「使用者已完成該組」維持獨立，作為循環結束標記。
