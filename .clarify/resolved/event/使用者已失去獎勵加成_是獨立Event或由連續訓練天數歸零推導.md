# 釐清問題

「使用者已失去獎勵加成」是獨立 Event，或為「連續訓練天數已歸零」的衍生狀態？加成恢復時是否需要對稱的 Event？

# 定位

流程：訓練中斷流程、訓練結算流程
元素：Event「使用者已失去獎勵加成」「使用者已獲得獎勵加成」「連續訓練天數已歸零」
細節：事件識別完整性（A1）；Event → Aggregate 一致性（E3）；可逆性（C4）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 為獨立 Event，與「連續訓練天數已歸零」同時發生但語意不同（一為計數歸零、一為權益喪失） |
| B | 非獨立 Event，加成為連續訓練天數的衍生值（每連續一天 +1%，上限 30%），刪除本 Event |
| C | 維持獨立 Event，並補上對稱的「使用者已恢復獎勵加成」Event |
| D | 併入「連續訓練天數已歸零」的 Postcondition，不另立 Event |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響訓練中斷流程的 Event 清單、加成值的 Aggregate 歸屬（連續訓練 Aggregate 的衍生欄位或獨立欄位）、
以及加成套用對象的定案（`rule/連續訓練獎勵加成_加成的套用對象為何.md`）。
本項為新掃描發現，非承接 `pending-gaps.md`。
比照先例：`resolved/event/商品已售完_售完是Event或由庫存推導的狀態.md`。

# 優先級

Medium

# 解決結果

**選項 A**：為獨立 Event，與「連續訓練天數已歸零」同時發生但語意不同（一為計數歸零、一為權益喪失）。

- 比照 `resolved/event/商品已售完_售完是Event或由庫存推導的狀態.md` 的先例：可推導不等於不成立為 Event。
- Precondition：「連續訓練天數已歸零」已發生。
- Postcondition：獎勵加成歸零。
- 加成為連續訓練天數的衍生值（每連續一天 +1%，上限 30%）。
- 不另立「使用者已恢復獎勵加成」：加成的重新累積由訓練結算流程的「使用者已獲得獎勵加成」承接。
