# 釐清問題

教官資格是否可能被撤銷（如聲望過低、違規受罰）？模型中缺少對應 Event。

# 定位

流程：教官申請流程、師徒互動流程、管理員管理社群流程
元素：Event：使用者已成為教官（缺少撤銷 Event）
細節：隱含發生但未寫出的 Event（A1）；單調遞增與可逆性（C4）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 補上「教官資格已撤銷」Event，由管理員因違規而執行 |
| B | 補上「教官資格已撤銷」Event，可因違規撤銷或因聲望低於門檻自動撤銷 |
| C | 補上「教官資格已撤銷」與「教官資格已暫停」兩個 Event，暫停為可回復狀態 |
| D | 教官資格終身有效，不可撤銷 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響教官申請流程的 Event 清單、使用者 Aggregate 的教官身分狀態機、既有師徒關係在撤銷時的處理（D4 關聯生命週期）、以及與管理員管理社群流程「使用者已受處罰」的關係。

# 優先級

Medium

# 解決結果

A — 補上「教官資格已撤銷」Event，Actor 為管理員，僅因違規而執行。
不建模「教官資格已暫停」；聲望低於門檻不觸發自動撤銷。

# 連帶影響

- `aggregate/教官聲望_聲望的計算公式與可否下降.md`：聲望不再需要承擔「自動撤銷資格」的職責，該題只需定義計算與升降。
- 撤銷時既有師徒關係如何處理未定義，記錄於 `.clarify/pending-gaps.md` G9。
