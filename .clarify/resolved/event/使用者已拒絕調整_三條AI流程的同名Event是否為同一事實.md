# 釐清問題

「使用者已拒絕調整」「使用者已確認使用新訓練強度」「使用者已提出調整要求」「AI 已再次確認需求」「使用者已確認需求」等 Event 跨三條 AI 流程重複出現，是否為同一事實？

# 定位

流程：AI 訓練前調整流程、AI 訓練中調整流程、AI 自動優化訓練流程
元素：Event「使用者已拒絕調整」「使用者已確認使用新訓練強度」「使用者已提出調整要求」「AI 已再次確認需求」「使用者已確認需求」
細節：事件命名與語意（A2）；跨流程同名 Event 的定義歸屬；Event → Aggregate 一致性（E3）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 皆為同一事實，比照經驗值 / 能力值原則以攜帶資訊（來源＝訓練前 / 訓練中 / 自動優化）區分，納入 `00_全域規範.md` 跨流程同名 Event 表 |
| B | 三條流程的作用範圍不同（本次訓練 / 剩餘動作 / 課表範本），應各自拆為獨立命名的 Event |
| C | 訓練前與訓練中為同一組（皆作用於本次訓練）視為同一事實；自動優化因作用於課表範本，另行命名 |
| D | 維持現狀各流程各自列出，不做同名歸併，亦不納入跨流程同名表 |
| Short | 提供其他簡短答案（<=5 字） |

# 解決結果

**選項 A**：五個 Event 皆為同一事實，以攜帶資訊區分來源，納入 `00_全域規範.md` 的跨流程同名 Event 表。

- 來源值域為三值：訓練前調整 / 訓練中調整 / 自動優化。
- 三條 AI 流程的作用範圍差異（本次訓練 / 剩餘動作 / 課表範本）以來源值表達，不另拆 Event。
- 未歸併項：「使用者已確認使用新訓練強度」與「使用者已確認調整」維持為兩個不同 Event（本題未涵蓋，不代答）。
