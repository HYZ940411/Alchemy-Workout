# 釐清問題

AI 僅產出建議、套用由系統執行，但三條 AI 流程中沒有任何 Event 承接「系統已套用調整」這個事實。是否補上該 Event？

# 定位

流程：AI 訓練前調整流程、AI 訓練中調整流程、AI 自動優化訓練流程
元素：Event「使用者已確認使用新訓練強度」「使用者已確認調整」之後的缺口
細節：Actor → Command → Event 串聯（E1）；Event 識別完整性（A1）；失敗路徑（C5）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 補單一「訓練課表已套用新強度」Event（Actor：系統），三條流程共用，以攜帶資訊區分作用範圍（本次訓練 / 課表範本） |
| B | 補兩個 Event：「本次訓練課表已套用新強度」與「課表範本已套用新強度」，分別對應不同作用範圍 |
| C | 不補 Event，套用視為「使用者已確認…」的 Postcondition，系統為隱含執行者 |
| D | 補 A 的 Event，並同時補「訓練課表套用已失敗」失敗路徑 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響系統 Actor 是否有可指派的 Event（目前 Actor 已定但無 Event）、三條 AI 流程的終點 Event、
以及本次訓練課表 / 課表範本 Aggregate 的實際改寫時點。
承接 G13。**注意**：`resolved/command/AI已調整訓練_AI是否視為獨立Actor.md`（選項 D″）只授權定義 Actor，未授權新增 Event。
與 `aggregate/訓練課表_本次訓練課表是否為獨立Aggregate與其快照機制.md` 宜併題處理。

# 優先級

High

# 解決結果

**選項 A**：補單一「訓練課表已套用新強度」Event，三條 AI 流程共用，以攜帶資訊「作用範圍」區分改動標的。

- Actor：系統（AI 僅產出建議，不執行套用）。
- 作用範圍值域為二值：本次訓練 / 課表範本。訓練前調整與訓練中調整皆為「本次訓練」，自動優化為「課表範本」。
- Precondition：「使用者已確認使用新訓練強度」/「使用者已確認調整」已發生。
- 不補失敗路徑：套用為本機資料寫入，失敗屬技術性交易回滾，非業務事實。
- 與第 1 題（選項 A）一致：同一事實不依來源拆分，以攜帶資訊區分。
