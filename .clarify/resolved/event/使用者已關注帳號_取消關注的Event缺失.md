# 釐清問題

模型中缺少「取消關注」Event，此操作是否存在？取消後對方粉絲數如何變化？

# 定位

流程：關注流程
元素：Event：使用者已關注帳號、對方帳號粉絲數已增加
細節：隱含發生但未寫出的 Event（A1）；可逆操作的 Event 定義（C4）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 補上「使用者已取消關注」與「對方帳號粉絲數已減少」兩個 Event |
| B | 補上「使用者已取消關注」，粉絲數變化合併為「對方帳號粉絲數已變動」單一 Event |
| C | 補上取消關注與粉絲數減少，另加封鎖相關 Event（封鎖時強制解除關注） |
| D | 不支援取消關注，關注為不可逆操作 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響關注流程的 Event 清單、粉絲數欄位的單調性、粉絲成就已解鎖的可逆性、以及師徒功能解鎖條件中「已追蹤」的計數基準。

# 優先級

High

# 解決結果

A — 補上「使用者已取消關注」與「對方帳號粉絲數已減少」兩個獨立 Event。粉絲數不具單調遞增性，可增可減。不納入封鎖相關 Event（維持本題範圍）。
