# 釐清問題

全模型 28 條流程中的所有 Event 皆未定義「發生時必須記錄哪些資訊」與「時間戳的時區與精度」，應如何統一規範？

# 定位

流程：全流程
元素：所有 Event（A5 檢查項於全模型皆為 Missing）
細節：事件攜帶的資訊（A5）；發生時間點、時區與精度（A5）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 統一規範：每個 Event 必含 事件ID / 發生時戳（UTC，毫秒精度）/ 觸發 Actor / 關聯 Aggregate ID，另加各 Event 專屬欄位 |
| B | 同上但時戳同時記錄 UTC 與使用者當地時區，供跨時區規則判定 |
| C | 僅需記錄發生時戳與 Actor，其餘依各 Event 個別定義 |
| D | 不統一規範，逐一在各 Event 定義時再決定 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響全模型所有 Event 的資訊欄位定義、跨時區規則（簽到換日、每日任務重置、中斷判定）的實作基礎、以及事件溯源與稽核能力。屬於全域性規範，建議優先定案以免逐一補寫。

# 優先級

High

# 解決結果

B — 統一規範：每個 Event 必含 事件ID / 發生時戳（UTC，毫秒精度）/ 觸發 Actor / 關聯 Aggregate ID，另加各 Event 專屬欄位；時戳同時記錄 UTC 與使用者當地時區，供跨時區規則判定。
