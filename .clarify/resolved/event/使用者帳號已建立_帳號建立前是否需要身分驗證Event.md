# 釐清問題

「使用者帳號已建立」之前，是否存在尚未寫出的身分驗證 Event（如 Email 驗證、手機驗證、第三方登入授權）？

# 定位

流程：註冊流程
元素：Event：使用者帳號已建立（流程起點 Event）
細節：起點 Event 是否明確（A1）；跨系統邊界 Event 是否標示來源（A4）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 不需驗證，填寫帳密即建立帳號，無額外 Event |
| B | 需 Email 驗證，補上「使用者信箱已驗證」Event，且為帳號可用的前提 |
| C | 需手機簡訊驗證，補上「使用者手機已驗證」Event |
| D | 支援第三方登入（Google / Apple），補上「第三方帳號授權已完成」Event，來源為外部系統 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響註冊流程起點 Event、使用者 Aggregate 是否需要「驗證狀態」欄位與狀態機，以及「使用者已完成註冊」的 Precondition。若選 D，需標示外部系統為 Actor。

# 優先級

High

# 解決結果

C + D — 同時支援兩種註冊入口：
- C：需手機簡訊驗證，補上「使用者手機已驗證」Event。
- D：支援第三方登入（Google / Apple），補上「第三方帳號授權已完成」Event，來源標示為外部系統。

兩者為二選一的入口路徑，完成其一後才發生「使用者帳號已建立」。
