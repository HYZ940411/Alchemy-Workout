# 釐清問題

「使用者已解鎖 社群互動功能」解鎖的具體是哪些功能？解鎖後是否可能被撤銷（如受處罰時）？

# 定位

流程：新手任務流程
元素：Event：使用者已解鎖 社群互動功能
細節：Event 語意是否無歧義（A2）、可逆性與單調遞增（C4）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 解鎖發文 / 按讚 / 留言 / 分享 / 關注全部社群功能，且永久不可撤銷（單調遞增） |
| B | 解鎖上述功能，但管理員處罰時可暫時停權，需補上「社群互動功能已停權」Event |
| C | 分階段解鎖，不同任務解鎖不同社群功能，需拆成多個 Event |
| D | 解鎖範圍僅含發文與留言，關注功能無需解鎖 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響「使用者已解鎖 社群互動功能」的 Postcondition、使用者 Aggregate 的功能解鎖旗標欄位、發文與互動流程各 Command 的 Precondition、以及與管理員管理社群流程「使用者已受處罰」的關係。

# 優先級

Medium

# 解決結果

A — 解鎖範圍為發文 / 按讚 / 留言 / 分享 / 關注五項社群功能，且永久不可撤銷（單調遞增）。
不新增「社群互動功能已停權」Event。

# 連帶影響

`rule/使用者已受處罰_處罰的種類與級距為何.md`：處罰不得以「撤銷社群互動功能解鎖」的形式實作，
因該解鎖已定為單調遞增。處罰若需限制社群行為，須以獨立於解鎖旗標的機制表達。
