# 釐清問題

「訓練計畫已推薦」之後，使用者若不接受推薦的計畫，會發生什麼 Event？

# 定位

流程：註冊流程
元素：Event：訓練計畫已推薦
細節：分支路徑（成功 / 拒絕）是否都有對應 Event（A3）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 推薦為單向指派，使用者不可拒絕，無需額外 Event |
| B | 補上「使用者已接受推薦計畫」與「使用者已更換訓練計畫」兩個 Event |
| C | 一次推薦多個計畫供選擇，補上「使用者已選擇訓練計畫」Event |
| D | 可拒絕並跳過，補上「使用者已略過推薦計畫」Event，改由自訂訓練流程進入 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響註冊流程分支 Event、訓練計畫 Aggregate 與使用者的關聯（一對一或一對多）、以及訓練紀錄流程「使用者已選擇訓練課表」的資料來源。

# 優先級

Medium

# 解決結果

A — 推薦為單向指派，使用者不可拒絕，無需額外 Event。註冊流程中「訓練計畫已推薦」無拒絕分支。
