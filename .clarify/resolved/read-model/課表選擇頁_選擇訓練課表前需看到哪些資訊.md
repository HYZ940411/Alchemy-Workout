# 釐清問題

使用者執行 Command「選擇訓練課表」前必須看到什麼？可選課表的來源涵蓋哪些（推薦的訓練計畫、已解鎖的進階計畫、自己的自訂訓練、他人已公開的課表、空白課表），每一筆需呈現哪些欄位？

# 定位

流程：訓練紀錄流程、AI 訓練前調整流程
元素：Read Model（尚未定義）；支撐 Command「選擇訓練課表」
細節：D6 Read Model 識別、E4 Read Model → Command 支撐。
判準依據：〈Read Model 建立原則〉「僅為 Actor 下某個 Command 之前必須看見的資訊建立 Read Model」。選擇課表為每次訓練的起點，且該 Command 的 Postcondition 會產生本次訓練課表快照，屬實質決策。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 分四區並存：當前訓練計畫（推薦或已解鎖的進階計畫）/ 我的自訂訓練 / 公開課表 / 空白課表；每筆呈現名稱、動作數、總組數、預估時長、上次執行日期 |
| B | 同 A 的四區，但欄位精簡為名稱與動作數；預估時長與上次執行日期屬回顧型資訊，不影響選擇決策 |
| C | 僅呈現「當前訓練計畫 ＋ 我的自訂訓練 ＋ 空白課表」三區；公開課表另立瀏覽入口，不在訓練起點呈現 |
| D | 單一清單不分區，以「上次執行日期」排序；每筆標明來源類型與各動作所屬肌群（供使用者避開近期已練部位） |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響 Read Model 清單、訓練計畫 / 自訂訓練 / 本次訓練課表三個 Aggregate 的查詢維度、「進階訓練計畫已解鎖」的呈現落點、以及公開課表（自訂訓練狀態＝已公開）是否需要獨立的瀏覽 Read Model 與查詢 Command。
本項為 `00_全域規範.md`〈Read Model 建立原則〉所要求的「以 226 個 Command 為索引逐一盤點」之產出，第三輪未執行。

# 優先級

High

# 解決結果

**選項 B 的欄位 ＋ 使用者追加「上次訓練日期」與「上次完成度」**

（原選項 C 為「上次使用日期 ＋ 總訓練量」，使用者改為**完成度**。
完成度為模型既有概念，值域 100% / 70% / 50%，比總訓練量更能反映「上次練得如何」。）

| 子決策 | 裁決 |
|--------|------|
| ① 涵蓋範圍 | 官方初階、官方進階、已發布自訂訓練、空白課表，四類全含 |
| ② 未解鎖進階計畫 | **呈現，且標示三種解鎖方式的當前狀態** |
| ③ 每份欄位 | 名稱、課表內容摘要、所需器材、解鎖狀態、解鎖條件、上次訓練日期、上次完成度 |

**不採** D（依註冊時推薦 Policy 標示「推薦給你」）：該 Policy 依註冊當下判定，
使用者訓練數月後標記已過時。
