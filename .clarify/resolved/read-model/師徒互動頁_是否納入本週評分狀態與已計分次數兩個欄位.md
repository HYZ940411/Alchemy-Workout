# 釐清問題

〈教官聲望 Aggregate〉新增了「每位學徒每週最多 2 次任務評分計入聲望」的上限，〈Read Model：師徒互動頁〉是否納入「本週是否已被該學徒評分」與「該學徒本週已計分的任務評分次數（0 / 1 / 2）」兩個欄位？

# 定位

流程：師徒互動流程
元素：Read Model「師徒互動頁」之學徒清單欄位
細節：D6 Read Model 欄位與來源、E4 Read Model → Command 支撐。00_全域規範〈Read Model：師徒互動頁〉之 `[待決策 Partial]`：「未納入時，教官無從得知本週的任務評分是否已達 2 次上限」。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 兩者皆納入：教官指派任務前需知道是否仍有計分空間，否則會持續指派而不知已不計分 |
| B | 僅納入「已計分次數」：其直接支撐「指派師徒任務」的決策；每週互動評分是否已收到不影響教官的任何 Command，屬回顧型資訊 |
| C | 兩者皆不納入：上限的用意即為防刷，揭露剩餘額度等於教你怎麼刷滿；且既有裁決明訂「不限制指派次數本身」，教官本就不應為計分而指派 |
| D | 僅納入「已計分次數」且**不顯示數字**，僅於達上限時標示「本週已達計分上限」 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響〈Read Model：師徒互動頁〉的學徒清單欄位、師徒關係 Aggregate 是否需新增「本週已計分任務評分次數」欄位（現僅有「最近一次評分所屬週」）、以及每週計分上限的實際嚇阻效果。

# 解決結果（2026-08-08，第八輪第 26 題）

**B ＋ 使用者提出的評分匿名性設計 ＋ 助理提出的初始帶徒上限調整。**

## 一、原題的兩個欄位

| 欄位 | 裁決 |
|------|------|
| 本週已計分次數 / 上限 | **納入** |
| 該學徒本週是否已評分我 | **不納入** |

- **已計分次數必須呈現**：既有規則「每位學徒每週最多 2 次任務評分計入聲望」
  若不呈現即成隱形規則 —— 教官指派第 3 個任務、學徒也評分了，聲望卻沒動，
  他只會認為系統故障。且該規則**需要被看見才有嚇阻效果**：
  意圖合謀刷聲望者看到「本週 2/2」即知刷不動。
- **不呈現「是否已評分我」**：等同把「去催學徒評分」變成可執行的動作，
  而每週評分的意義在於它是學徒自發的評價。

## 二、使用者提出的新設計：評分只給總平均，且 ≥3 人才顯示

> 我覺得當教官解鎖三個學徒後才解鎖可以看到總平均比較好，看單獨個人的會不會有不好的影響？

**有，而且是三層連鎖**：教官知道誰給低分 → 可藉指派更難的任務、消極回答或解除關係報復
→ 學徒因此給高分自保 → **聲望退化為帶徒時長的函數，不再反映指導品質**。

## 三、助理查證後發現該門檻在現行模型中無效

| 現況 | 出處 |
|------|------|
| 初始帶徒上限 ＝ **1 人** | `00_全域規範.md:3508` |
| 聲望點數對教官自己可見 | `00_全域規範.md:4920` |
| 每週評分的聲望變動為 −2 / 0 / +4 / +8 / +12 | `師徒互動流程.md:67` |

**學徒只有 1 位時，聲望的變動量可被減法直接還原為星數** ——
無論畫面呈現什麼，匿名性在數學上皆不成立。
而該狀態將持續約 13.5 週（升至 3 人所需時間），
正是報復風險最高的時期（只有一位學徒，不可能猜錯是誰）。

## 四、解法：初始帶徒上限 1 人 → 2 人

2 位起減法即失效（+12 可能是「一位 5 星」，也可能是「一位 4 星 ＋ 一位 3 星」）。

| | 原 | 改後 |
|---|---|---|
| 匿名性成立時點 | 第 13.5 週 | **第一天** |
| 到 3 人（可看總平均） | 13.5 週 | **6 週** |
| 聲望機制 | — | **完全不動** |

**幾乎免費**：帶徒上限的聲望門檻本即有 `[待決策 Partial]` 待重校
（原估算假設「每週 2 次評分＝問答與師徒任務各一」，而問答評分已於 2026-08-02 移除）。
初始值調整併入該次重校。

**代價**：新教官無「只帶一位練手」的緩衝。但其已通過初審門檻、教官測驗、
AI 訓練品質評分三道關卡；既以三關確認其能帶人，再令其自 1 位起步，
那三道關卡的意義本即被稀釋。

## 三個被否決的替代方案

| 方案 | 為何不採 |
|------|---------|
| 接受洩漏、記為已知風險 | 風險最高的前 3.5 個月完全不處理 |
| 聲望改為每週結算，使單次評分無法被還原 | 聲望同時是帶徒上限的觸發條件，週結算會連帶延遲上限提升，牽動範圍大於問題本身 |
| 直接讓教官看個別評分 | 使用者已判斷不可，助理同意 |
