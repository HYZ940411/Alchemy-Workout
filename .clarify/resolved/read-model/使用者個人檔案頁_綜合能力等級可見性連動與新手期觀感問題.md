# 釐清問題

〈六維能力值的對外可見性〉已定案：使用者可自行關閉六維能力值對他人的可見性（教官身分者強制可見，不可隱藏）。但兩點仍未定案：① 綜合能力等級的可見性是否隨六維能力值的開關連動，或需另設獨立開關；② 新手期使用者於個人檔案頁看到他人 S 級、自身為 E 級時的觀感問題，模型目前無任何緩解機制。

# 定位

流程：（跨流程，屬使用者個人檔案頁的呈現規則）
元素：Read Model「使用者個人檔案頁」〈六維能力值的對外可見性〉子節
細節：綜合能力等級為六維能力值的衍生彙總值，若六維本身被隱藏，綜合等級單獨顯示或隱藏在邏輯上需要一致的規則。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 綜合能力等級可見性與六維能力值可見性連動，共用同一個開關，不另設獨立欄位；新手期觀感問題暫不處理，列為已知取捨（比照能力值退步機制「規律訓練但1RM大幅下滑者，點數停留巔峰值不下降」等既有的已知取捨模式）（**推薦**：綜合等級是六維的直接衍生值，若六維隱藏而綜合等級仍可見，等於留一條後門可反推「大概多強」，與隱藏六維的初衷（保護隱私）相衝；新手期觀感問題屬於產品體感優化而非模型缺陷，且能力值等級本已明訂「E 級的實際起點為註冊初始值 10，非 0」，等級系統的設計本就假定會有落差，強行加入緩解機制（如新手保護期）需要額外的狀態與規則，成本與此問題的急迫性不成比例） |
| B | 綜合能力等級獨立於六維能力值的可見性設定，可單獨開關（使用者可選擇只隱藏六維細節但仍顯示綜合等級，或反之） |
| C | 新增新手期觀感緩解機制：新使用者（如註冊未滿 7 天或尚無任何能力值記錄）的個人檔案頁不顯示他人的能力值等級對比提示，或在雷達圖旁加註「多數人從 E 級開始」 |
| Short | 提供其他簡短答案（<=5 字） |

影響 Read Model「使用者個人檔案頁」的呈現規則；不影響 Aggregate 或 Command 結構。

# 解決結果

兩個子題依使用者要求**分開提問**，裁決如下：

| 子題 | 裁決 |
|------|------|
| ① 綜合能力等級的可見性 | **B：另設獨立開關**，不與六維連動 |
| ② 新手期觀感問題 | **A：不做緩解機制** |

## ① 綜合能力等級另設獨立開關

使用者 Aggregate 新增欄位「**綜合能力等級對外可見**」（bool，預設真），與六維各自獨立。

| 六維 | 綜合 | 效果 |
|------|------|------|
| 開 | 開 | 全部可見（預設） |
| **關** | **開** | **只露出整體評價，隱藏各部位細節** ← 本次所支援的核心情境 |
| 開 | 關 | 實質無效（綜合為六維平均，可自行算出）；允許設定但不另設限制 |
| 關 | 關 | 完全不對外呈現 |

**支援的情境**：使用者可能願意讓人知道自己「整體 B 級」，但不想被看出「腿特別弱」——
兩者為不同的隱私顧慮，應可分別控制。

**教官例外同時適用於兩個開關**：教官的六維與綜合等級皆強制對外可見，
理由與既有裁決相同（學徒須據以判斷實力，否則〈教官清單〉核心欄位將出現空值）；
教官資格撤銷後兩個例外一併解除。

## ② 新手期觀感問題不做緩解

- **第十輪的錨點下調已實質改善**：〈錨點分佈〉定案後 E 級只涵蓋完全未訓練者，
  練 1–2 個月即進入 D 級，新手停留在 E 的時間由數個月縮短至約 1–2 個月。
- **任何緩解機制都會與既有裁決相衝**：模型已明文「能力值對外呈現正是『關注』與
  『申請師徒關係』兩個 Command 的判斷依據」「預設隱藏會使該區塊形同不存在」。
- **承既有立場**：否決「相對百分位」時已確立「能力值代表身體能力，不因他人而變動」。
- **回饋密度已由 18 個小節點承擔**：其處理的正是「自己有沒有在進步」，而非「跟別人比如何」。
- 不採 B（新手期前 30 天不顯示他人等級）：會使新使用者在最需要判斷
  「該關注誰、該向誰拜師」的時期反而看不到判斷依據。
- 不採 C（只顯示等級不顯示點數）：等級本即離散六階，隱藏點數不降低比較強度
  （E 對 S 的落差在等級上更醒目），卻使使用者看不到自己距下一階還差多少。
