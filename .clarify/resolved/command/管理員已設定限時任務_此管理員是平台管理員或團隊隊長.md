# 釐清問題

「管理員已設定限時任務」中的「管理員」是平台管理員，還是團隊內的隊長 / 團隊管理員？

# 定位

流程：團隊組隊任務流程
元素：Command：設定限時任務；Actor：管理員
細節：Actor 識別（B4）；同名異義的角色術語衝突（F2、B5）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 平台管理員，全平台統一設定同一組限時任務 |
| B | 團隊隊長，各團隊自行設定任務，應改名為「隊長」以區分平台管理員 |
| C | 平台管理員設定任務池，團隊隊長從池中選擇，需拆為兩個 Command |
| D | 平台管理員，且應與管理員商品上架 / 管理社群流程的管理員為同一角色 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響設定限時任務 Command 的 Actor 與權限規則、團隊 Aggregate 是否需要隊長角色欄位、Actor 術語表的角色定義、以及「團隊已指派限時任務」的作用範圍（全平台或單一團隊）。

# 優先級

High

# 解決結果

D — 為平台管理員，且與管理員商品上架流程、管理員管理社群流程的管理員為同一角色。
團隊隊長無設定限時任務的權限。Event 名稱維持「管理員已設定限時任務」，不改名。

# 術語衝突已消解

「管理員」在全模型僅指平台管理員一種角色，不再有「團隊管理員 / 隊長」的第二種語意。
與第 17 題「團隊隊長不為獨立 Actor」的裁決一致。

# 連帶影響

「團隊已指派限時任務」的作用範圍（全平台各團隊皆為同一組任務，或可分團隊指派不同任務）
未表態 —— 使用者選 D 而非 A，A 的「全平台統一設定同一組」不得推定成立。
記錄於 `.clarify/pending-gaps.md` G15。
