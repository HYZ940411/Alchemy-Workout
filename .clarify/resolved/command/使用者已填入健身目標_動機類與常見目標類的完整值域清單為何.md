健身目標的「動機類」與「常見目標類」完整值域清單為何？（模型現以 [待決策 Partial] 標記待補）

細節：Command 輸入參數（B3）；類別邊界（C3）；待決事項（F3）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 動機類：健康陪伴家人 / 堅持夢想 / 自信外型 / 紓壓；常見目標類：增肌 / 減重 / 培養運動習慣 / 提升體能 |
| B | 同 A 的項目，但兩類皆為平台級可調參數，由管理員於後台維護，非寫死於系統 |
| C | 僅保留現有已列項目（動機類 2 項、常見目標類 3 項），不再擴充 |
| D | 常見目標類同 A 且由管理員維護；動機類改為自由文字，不設值域 |
| Short | 提供其他簡短答案（<=5 字） |

# 解決結果

**選項 B**：值域項目採選項 A 所列，但兩類皆為平台級可調參數，由管理員於後台維護。

| 分類 | 初始值域 | 填寫規則 |
|------|----------|----------|
| 動機類 | 健康陪伴家人 / 堅持夢想 / 自信外型 / 紓壓 | 選填，最多 1 項 |
| 常見目標類 | 增肌 / 減重 / 培養運動習慣 / 提升體能 | 必填，1 項 |

- 新增「健身目標設定」Aggregate（平台級），獨立 Aggregate 清單由 32 項增為 33 項。
- 訓練計畫 Aggregate 的「適用條件」欄位一律引用同一份值域清單。
- 管理員新增目標項目時，既有訓練計畫的適用條件不自動更新（避免出現「有目標但無計畫符合」的推薦失敗）。
- 值域調整不改動任何使用者已填入的健身目標。
- 理由：模型中所有清單型設定（新手任務範本、每日任務池、成就定義、獎勵定義、階級設定、權益設定、教官測驗設定、帶徒上限設定）皆已定案為管理員可調，寫死會成為唯一特例。
