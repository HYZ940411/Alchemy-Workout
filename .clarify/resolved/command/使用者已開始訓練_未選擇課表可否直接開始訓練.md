# 釐清問題

「使用者已開始訓練」是否一定要先有「使用者已選擇訓練課表」？可否不選課表直接開始自由訓練？

# 定位

流程：訓練紀錄流程（循環：使用者已記錄重量 > 組間休息已結束）
元素：Command：開始訓練（對應 Event：使用者已開始訓練）；上游 Event：使用者已選擇訓練課表
細節：Command 的輸入參數與必填 / 選填（B3）；Precondition 完整性（C1）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 必須先選擇課表，課表為必填輸入 |
| B | 可不選課表直接開始自由訓練，訓練中臨時加入動作 |
| C | 可不選課表，但需補上「使用者已開始自由訓練」為獨立 Event |
| D | 必須先選課表，但可選擇「空白課表」作為自由訓練的入口 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響開始訓練 Command 的輸入參數與 Precondition、訓練紀錄 Aggregate 與訓練課表 Aggregate 的關聯是否為必填、以及訓練進度條在無課表時的計算方式。

# 優先級

Medium

# 解決結果

D — 必須先選課表，課表為開始訓練的必填輸入；自由訓練以「空白課表」為入口。
不另立「使用者已開始自由訓練」Event。

# 連帶影響

- 「課表全部動作完成 → 使用者已完成訓練」的判定基準得以保留，因空白課表仍是課表實體。
- 但空白課表的動作數為 0（或訓練中動態增加），訓練進度條的分母如何計算未定義，
  記錄於 `.clarify/pending-gaps.md` G17。
- `aggregate/訓練進度條_進度百分比的計算公式為何.md`：該題須一併涵蓋空白課表情境。
