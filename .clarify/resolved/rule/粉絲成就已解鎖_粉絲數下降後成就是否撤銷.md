# 釐清問題

粉絲數因取消關注而下降至門檻以下時，已解鎖的粉絲成就是否撤銷？重新達標是否重複發獎？

# 定位

流程：關注流程
元素：Rule：粉絲成就已解鎖的 Precondition；Policy：粉絲成就門檻（10/50/100/300/500/1000/3000/5000/10000）
細節：單調遞增與不可逆性（C4）；狀態邊界：重複執行（C3）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 成就一經解鎖永久保留，粉絲數下降不撤銷，重新達標不重複發獎 |
| B | 成就撤銷，粉絲數回升後重新解鎖並重複發獎 |
| C | 成就撤銷但獎勵不回收，重新達標不重複發獎 |
| D | 以歷史最高粉絲數判定成就，粉絲數下降完全不影響 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響粉絲成就已解鎖的 Precondition、成就 Aggregate 的解鎖紀錄與單調性、是否需記錄歷史最高粉絲數欄位、以及與其他成就（簽到 / 訓練 / 互動）的一致性原則。

# 優先級

Medium

# 解決結果

**選項 A** —— 不撤銷，成就終身保留。承第 32 題「成就解鎖紀錄單調遞增、一經解鎖不可撤銷」的原則。
