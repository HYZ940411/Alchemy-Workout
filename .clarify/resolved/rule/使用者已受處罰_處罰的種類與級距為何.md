# 釐清問題

「使用者已受處罰」的處罰種類與級距為何？處罰是否有期限？累犯如何加重？

# 定位

流程：管理員管理社群流程
元素：Rule：使用者已受處罰的 Postcondition；Event：使用者已受處罰
細節：類別邊界（C3）；Postcondition 原子化（C2）；模糊描述未量化（F4）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 警告 / 禁言 7 天 / 禁言 30 天 / 永久停權四級，依違規次數遞增 |
| B | 僅有內容下架與永久停權兩種，無中間級距 |
| C | 警告 / 社群功能停權（限期）/ 帳號停權（限期）/ 永久停權，且教官資格一併撤銷 |
| D | 處罰種類與期限由管理員個案裁量，不設固定級距 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響使用者已受處罰的 Postcondition 與處罰類型欄位、使用者 Aggregate 的處罰狀態與到期時戳、社群互動功能解鎖的可逆性、教官資格撤銷的連動、以及是否需要「處罰已解除」Event。

# 優先級

High

# 既有約束（來自已解決項目）

第 8 題（`resolved/event/使用者已解鎖社群互動功能_解鎖前後的功能差異與是否可撤銷.md`，選項 A）已裁決：
社群互動功能解鎖為單調遞增、永久不可撤銷。
故處罰不得以撤銷該解鎖旗標的方式實作；若需限制社群行為，須採獨立機制。

# 解決結果

**併題第 11 題，選項 A**：四級處罰級距 ＋ 完整申訴與解除路徑。

**處罰級距（四級）**：警告 / 社群功能停權（限期）/ 帳號停權（限期）/ 永久停權。

- 處罰狀態為使用者 Aggregate 的獨立欄位，值域五值（含「無」）。
- 限期處罰須記錄處罰到期時戳；警告與永久停權的到期時戳為空值。
- 受處罰者具教官身分時，教官資格一併撤銷（觸發既有的「教官資格已撤銷」）。
- **關鍵約束**：社群功能停權不得以撤銷社群互動功能解鎖旗標實作（該旗標已裁決為單調遞增、永久不可撤銷），一律以處罰狀態欄位表達。

**新增 4 個 Event**：使用者已申訴、管理員已審視申訴、處罰已撤銷、處罰已到期解除。

- 「使用者已申訴」Precondition：該使用者存在生效中的處罰。
- 「處罰已到期解除」Precondition：處罰為限期處罰且已達處罰到期時戳。
- 兩個解除類 Event 的 Postcondition：處罰狀態回復為無，處罰到期時戳清空。
- 申訴不成立不另立 Event，維持原處罰。
- 永久停權無到期解除，僅能經申訴撤銷；警告無到期解除，為一次性記錄。
