# 釐清問題

教官專長的值域刻意排除具專業執照門檻的項目（飲食營養、傷後復健等），但上線地區不只一個而各地法規不同——值域是否需依地區分設？

# 定位

流程：教官申請流程
元素：Aggregate — 教官專長設定（值域）；Rule — 申請教官權限的輸入驗證
細節：`02_Aggregate定義.md`〈值域的界線〉之 `[待決策 Partial]`：「上線地區不只一個，而各地法規不同⋯現階段由管理員後台調整承接」。現況為全站單一值域（初始 11 項）

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 維持全站單一值域：取各地區的交集（最保守的一組），不依地區分設；理由為分設須為每個地區各維護一份清單且教官可能跨地區帶徒 |
| B | 值域增加「適用地區」欄位，管理員逐項標記；使用者申請時僅能選其所在地區可用的項目 |
| C | 維持現狀不裁決，於上線前逐地區送法務確認，模型僅記錄此為已知風險 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

- 教官專長設定 Aggregate 的欄位（是否新增適用地區）
- 使用者 Aggregate 的「教官專長」欄位值域與其跨地區有效性
- 〈Read Model：教官清單〉的專長篩選
- 相關已解決項目：`resolved/aggregate/教官申請_專長肌群的可選數量上限為何.md`

# 優先級

Low

# 解決結果

**A**：維持全站單一值域，取各上線地區的**交集**（最保守的一組），不依地區分設。

- **不採依地區分設**：教官會跨地區帶徒（模型對師徒配對無任何地區限制），
  分設後將出現「教官所在地可標示、學徒所在地看不到」的情形，
  而該判定要依教官所在地或學徒所在地**沒有乾淨的答案**。
- **交集的實際損失很小**：現行 11 項本即為保守版本
  （飲食營養、傷後復健、產後恢復、動作矯正、銀髮族五項已排除）。
- **新增上線地區時，若該地區對現有項目有額外限制，自值域移除該項**，
  不為單一地區保留例外。
- 值域調整不改動任何教官已填入的專長（承既有規則）。
