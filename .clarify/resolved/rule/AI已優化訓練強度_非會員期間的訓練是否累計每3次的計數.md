# 釐清問題

AI 自動優化訓練流程每 3 次訓練後觸發，且已定案為會員專屬（Precondition：會員權益生效中）。但非會員期間累積的訓練次數是否計入「每 3 次」的計數尚未裁決：若累計，使用者訂閱當下可能立即觸發一次優化（拿著非會員時期的舊訓練資料首發）；若不累計，則與「已啟用/關閉期間仍照常累計，重新啟用不補跑」的既有處理方式不一致，需要說明兩者為何有別。

# 定位

流程：AI 自動優化訓練流程
元素：Rule「每 3 次訓練依歷史訓練狀況產出優化」之 Precondition
細節：模型已定案「關閉期間仍照常累計訓練次數，重新啟用後不補跑期間錯過的優化」——這是同一計數器在「功能關閉」情境下的既有處理，本題問的是「非會員」情境是否比照辦理。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 非會員期間累計，比照「關閉期間仍照常累計」的既有邏輯：計數器不分會員身分，持續累加，訂閱當下若已達 3 次門檻即觸發一次優化（**推薦**：與模型已有的「關閉期間仍照常累計」判例同構——計數器本質是「距上次優化過了幾次訓練」，不因為某段時間內功能不可觸發就該歸零或暫停累計，訂閱當下立即獲得一次優化建議對新會員反而是正向的「立刻感受到會員價值」體驗） |
| B | 非會員期間不累計，計數器僅在會員權益生效中的期間累加；訂閱當下計數器歸零重新起算 |
| C | 非會員期間不累計，但保留累計進度：訂閱時將計數器「解凍」，從非會員前的進度繼續累加（不歸零、也不倒算非會員期間） |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響 AI 自動優化訓練流程的 Precondition 判定邏輯與計數器的儲存規則。此題於第八輪即已產生但兩輪皆未解決，屬長期懸而未決的既有缺口。

# 解決結果

**選項 A**：非會員期間照常累計「每 3 次」的計數。

訂閱當下計數若已達 3 次，**立即觸發一次優化**；但**不補跑期間錯過的多份優化**——
此與既有規則「關閉期間仍照常累計訓練次數，重新啟用後不補跑期間錯過的優化」完全一致
（該既有規則排除的是「補跑多份」，不排除「計數已達標而觸發一份」）。

判準：**計數器記錄的是「訓練事實」，取用權限（會員身分）決定的是「能不能收到建議」**，
兩者為不同的問題，計數器不為取用權限分岔。與「關閉期間」的形狀相同——
皆為「有訓練事實、只是當下不觸發優化」，模型中因此不出現兩套計數規則。

不採 C（訂閱後歸零重算）：新訂閱者須再練 3 次才看得到第一份建議，
而 AI 自動優化為會員權益的主要賣點之一，付費後最不該是空白期。

`[已知取捨]` 訂閱當下立即產出的那份建議，其依據為訂閱前的訓練資料。
刻意接受——該資料同為使用者的真實訓練紀錄，且「最近 3 次訓練」的既有取樣規則
本即不區分訂閱與否。
