# 釐清問題

能力值每滿 120 小時未訓練退步的「固定百分比」數值為何？六個肌群維度各自的註冊初始值（退步下限）為何？

# 定位

流程：訓練中斷流程、註冊流程
元素：Rule：Event「能力值已退步」的計算規則；Aggregate「使用者」的能力值欄位初始值
細節：Aggregate 內部不變條件（D3）；數值邊界（C3）；待決事項（F3）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 每次退步 5%，六維註冊初始值皆為 10 |
| B | 每次退步 10%，六維註冊初始值皆為 10 |
| C | 每次退步 5%，六維註冊初始值依註冊問卷的健身經驗給定（新手 / 有經驗不同） |
| D | 百分比與初始值皆為平台級可調參數，由管理員設定，本階段僅定義「六維初始值相同」 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響「能力值已退步」的 Postcondition 驗收、退步下限的實際值、以及「能力值已部分回復」的回復幅度基準。
承接 G24；與 `rule/能力值已提升_提升幅度的計算公式為何.md`（G18）為對稱決策，宜併題處理以保持升降對稱性。
相關已解決項目：`resolved/aggregate/能力值_能力值退步的計算公式與下限.md`（選項 A②，已定六維各自獨立計時）。

# 解決結果

**選項 A ＋ 使用者調整**：退步百分比 **2.5%**（原選項 A 為 5%），六維註冊初始值皆為 **10**。

| 停練時間 | 累計衰減（2.5%／120 小時） |
|----------|--------------------------|
| 10 天 | −5% |
| 1 個月 | −14% |
| 3 個月 | −37% |
| 6 個月 | −60% |
| 1 年 | −84%（趨近下限 10） |

**採 2.5% 而非 5% / 10%**：出差、受傷休養皆為正常生活事件，懲罰過重會使使用者乾脆放棄回歸，
與退步機制「促使回歸」的目的背道而馳。2.5% 讓一個月假期只損失約 14%，一年不練才會趨近下限。

**六維初始值皆為 10**：

- 初始值 10 等同一次基準訓練所得的點數（第 31 題定的基準提升點數即為 10），
  下限的意義為「無論荒廢多久仍保有一次認真訓練的水準」，而非歸零重來。
- 不採選項 C 的分級初始值：健身經驗的值域與對應點數尚未定義，且新手與老手的差異
  已由「訓練量決定成長速度」自然反映，不需在起跑線再分一次。
- 不採選項 D：依模型慣例，這兩個數字本就寫成管理員可調參數，A 給的是初始值；選 D 只會使 Partial 續留。

**明確的限制**：退步**不解決** H8（能力值累積無上限）。退步僅於該肌群 120 小時未訓練時觸發，
規律訓練者永不退步，能力值仍只增不減。調高退步百分比不能代替總量上限，兩者須分開處理。
