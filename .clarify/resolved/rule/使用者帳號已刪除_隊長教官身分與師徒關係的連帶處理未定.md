# 釐清問題

帳號刪除時，下列連帶情形尚未表態：刪除者為團隊隊長時團隊如何處理（自動轉讓或解散）；刪除者具教官身分時既有師徒關係與進行中師徒任務如何處理；刪除者為學徒時教官的帶徒名額何時釋放；刪除者的關注關係移除後，他人的粉絲數與粉絲成就是否重算。

# 定位

流程：團隊組隊流程、師徒互動流程、關注流程
元素：Event「使用者帳號已刪除」的 Postcondition
細節：模型對「教官資格已撤銷」「使用者已退出團隊」「團隊已解散」「粉絲成就已解鎖」皆已有既有裁決，本題應直接沿用而非另訂新規則。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 全數沿用既有裁決逐一比照套用：隊長比照「使用者已退出團隊」（隊長須先轉讓或觸發既有的隊長離隊規則）；教官比照「教官資格已撤銷」（既有師徒關係全數自動解除、未完成師徒任務作廢）；學徒比照師徒關係解除的既有名額釋放規則；粉絲數比照「使用者已取消關注」同步遞減，粉絲成就不隨之撤銷（承既有「一經解鎖不可撤銷」原則）（**推薦**：帳號刪除是這些既有規則共同的觸發源之一，而非需要新規則的特例，直接複用可避免同一件事在模型中出現兩套不一致的處理邏輯） |
| B | 帳號刪除時團隊與師徒關係一律走簡化路徑：團隊強制解散重組、師徒關係直接清除不留記錄 |
| C | 連帶效果延後至「已刪除」終止狀態才觸發，「已申請刪除」（冷靜期間）維持一切正常運作 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響 Event「使用者帳號已刪除」的 Postcondition 完整性；與 `rule/教官資格已撤銷_撤銷時既有師徒關係與進行中任務如何處理.md`、`rule/使用者已退出團隊_隊長退出前是否須先轉讓隊長.md`、`rule/團隊已解散_解散時既有團隊分數與排行榜名次如何處理.md`、`rule/粉絲成就已解鎖_粉絲數下降後成就是否撤銷.md` 四項已解決項目直接相關，答案應可直接沿用。

# 解決結果

**選項 A**：全數沿用既有裁決逐一比照套用，不另立新規則。

| 情形 | 處理 | 沿用的既有裁決 |
|------|------|---------------|
| 刪除者為團隊隊長 | 未指定接任者即自動轉讓給最早加入的成員；僅剩其一人時觸發「團隊已解散」 | 〈團隊組隊流程〉隊長離隊規則 |
| 刪除者具教官身分 | 既有師徒關係全數自動解除，未完成的師徒任務作廢；學徒豁免 3 天冷卻期 | 〈教官資格已撤銷〉的既有 Postcondition |
| 刪除者為學徒 | 釋放其所佔用的教官帶徒名額 | 〈帶徒上限設定〉之名額佔用規則 |
| 刪除者的關注關係 | 一律移除，被關注者的粉絲數同步遞減 | 「使用者已取消關注」的既有 Postcondition |
| 他人已解鎖的粉絲成就 | 不撤銷 | 「成就解鎖紀錄單調遞增，一經解鎖不可撤銷」 |

**觸發時點一併定案**（原選項 C 的爭點）：連帶效果一律於「使用者帳號已刪除」發生時觸發，
冷靜期間（待刪除狀態）不觸發任何連帶效果。理由：冷靜期內可取消，而解散團隊與解除師徒關係
皆為不可逆操作，提前執行後無法隨取消刪除而回復。

`[已知取捨]` 冷靜期 30 天內該使用者仍佔用團隊 5 人名額與教官帶徒名額，隊友與教官須等待至
實際刪除方能遞補；不另設「待刪除者不計入名額」的例外。
