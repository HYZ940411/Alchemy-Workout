# 釐清問題

平台對「訓練指導造成的傷害」的免責範圍是否需擴充？教官端是否也須確認一份指導責任聲明？

# 定位

流程：註冊流程（服務條款）、師徒互動流程（免責聲明）、教官申請流程
元素：Rule — 服務條款的涵蓋範圍；Event — 是否新增「教官已確認指導責任聲明」
細節：本項由使用者於第十一輪第 15 題提出（「本平台教練所產生的任何動作傷害或後果都需要免責證明」），
非 discovery 原有的 24 項之一。查得模型既有三層：① 服務條款免責（涵蓋教官回答、師徒任務、
公開課表三條路徑）② 學徒側的師徒免責聲明（首次建立關係時確認，有版本欄位）
③ 公開課表的來源免責標示。缺口為：教官端從未確認任何聲明、AI 訓練建議與平台動作示範不在免責路徑內。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 只擴充條款文字，免責路徑三條擴為五條，不新增 Event |
| B | A ＋ 新增 Event「教官已確認指導責任聲明」，終身一次，未確認前不得回答或指派任務 |
| C | B ＋ 每次建立師徒關係都重簽 |
| D | 維持現狀，條款文字留在系統邊界之外 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

服務條款的涵蓋路徑；使用者 Aggregate 的欄位；教官申請流程的終點；
「教官已回答」與「教官已指派師徒任務」的 Precondition；師徒互動頁的支撐 Command

# 優先級

High

# 解決結果

**B**：免責路徑三條擴為五條，並新增教官端的一次性確認。

- **服務條款的免責路徑擴為五條**：教官回答、師徒任務、公開課表、
  **AI 訓練建議**（AI 微調／調整／自動優化／替換動作、快照的預帶重量）、**平台動作示範內容**。
  - 擴充至 AI 訓練建議的理由：其為平台自身產出的指導，且模型明文記載
    「假的預帶重量會造成受傷風險」。
  - 擴充至平台動作示範：動作庫由平台維護並供全體選用，性質與公開課表同型。
- **新增 Command「確認指導責任聲明」與 Event「教官已確認指導責任聲明」**（Actor：使用者（教官）），
  攜帶聲明版本與確認時戳，**終身一次**，比照學徒側的既有處理。
- **未確認者不得發生「教官已回答」與「教官已指派師徒任務」**（兩條 Precondition）。
- 使用者 Aggregate 新增欄位「已確認指導責任聲明版本」。
- 聲明改版後，既有教官於下次回答或指派前須重新確認，本 Event 再次發生並更新版本。
- **不採每次建立師徒關係重簽**：學徒側已裁決「僅首次呈現一次」，兩側不一致無理由。
- **不採僅擴充條款文字**：學徒側已單獨確認「平台不擔保教官能力」，教官側卻從未確認
  「我對我給出的指導負責」——出事時平台僅有學徒那一份，而教官可主張平台將其配對給學徒、
  且呈現其聲望等級與六維能力值，等同背書。
