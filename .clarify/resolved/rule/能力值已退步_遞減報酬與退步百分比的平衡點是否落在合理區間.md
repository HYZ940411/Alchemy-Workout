# 釐清問題

能力值提升端採遞減報酬（隨現值收斂至理論上限 1,000），退步端為固定 2.5% / 120 小時，兩者會在某個現值形成動態平衡點。該平衡點是否落在合理區間？若過低（如僅 200–300），理論上限 1,000 將永無意義。

# 定位

流程：訓練結算流程、訓練中斷流程
元素：Rule：能力值提升公式的遞減報酬係數；能力值退步參數
細節：C3 數值邊界、D3 Aggregate 內部不變條件。
需驗算的情境：以每週 3 練、各肌群輪流訓練的典型頻率，推算各維的收斂值；並確認規律訓練者（該維 120 小時內必再訓練）是否確實永不退步 —— 若是，則平衡點僅對不規律者存在。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 先驗算典型頻率下的收斂值，再依結果決定是否調整理論上限或基準提升點數；本題答案為「驗算後再定」 |
| B | 維持現行參數：理論上限 1,000 本即為漸近線，收斂值低於上限屬預期，不調整 |
| C | 調高基準提升點數（10 點 → 更高）使收斂值上移，讓 1,000 的上限具備實際意義 |
| D | 調低理論上限至典型收斂值附近（如 400–500），使六維雷達圖的滿格更貼近可達水準 |
| Short | 提供其他簡短答案（<=5 字） |

# 解決結果

**選項 A：觸發間隔由 120 小時延長至 240 小時（10 天），退步幅度由 2.5% 提高至 5%。**

## 發現的問題：主流訓練法被持續懲罰

分部位訓練（推 / 拉 / 腿三分化，每個肌群每週練一次）為最主流的健身安排，
每週一次 ＝ 每 7 天 > 120 小時，故**每個肌群每週都退步一次**。

以中手練胸為例（每週一次、訓練量 2,800）：

| 項目 | 每週 |
|------|------|
| 訓練所得 | 14 ×（1 − x / 1000） |
| 退步 | 0.025x |

平衡點 14 − 0.014x ＝ 0.025x → **x ＝ 359**，永遠卡在 C 級。
老手（訓練量 4,800、基準點數 24）平衡點亦僅 490。
**S 級門檻 850 在此安排下數學上不可達。**

## 為何 240 小時 ／ 5%

長期衰減曲線幾乎不變 —— 衰減次數減半、每次幅度加倍：

| 停練時間 | 原（120h／2.5%） | 現（240h／5%） |
|----------|-----------------|---------------|
| 1 個月 | −14% | −14.3% |
| 1 年 | −84% | −84.5% |

「荒廢久了會退很多」的設計意圖完整保留，而每週練一次者（7 天 < 10 天）不再觸發退步。

- 不採 168 小時（7 天）：門檻過於貼邊，晚一天訓練即退步，體感差。
- 不採「幅度降至 1%、間隔維持 120 小時」：僅治標，平衡點升至約 583 仍到不了 S 級。

# ⚠️ 本裁決的存續取決於另一個項目

使用者於同一輪的後續討論中裁定：**能力值改採既有公開肌力標準
（估算 1RM ＋ 體重性別正規化），取代現行訓練量公式**。

改採後，能力值不再是累積值，「退步」的意義須重新界定，
**本裁決的 240 小時 ／ 5% 參數可能整條作廢**。

同時，本題所發現的「主流訓練法被懲罰」問題在新算法下**自動消失** ——
分數不再與訓練頻率掛鉤。

→ 見 `aggregate/能力值_改採既有公開肌力標準取代自訂訓練量公式.md` 之子題 5。
