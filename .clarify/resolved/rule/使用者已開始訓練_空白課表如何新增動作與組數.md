# 釐清問題

空白課表的本次訓練課表「總計畫組數為 0、課表內容為空」，但使用者仍須記錄成績（該路徑會產生能力值與排行榜分數）。空白課表訓練時，使用者如何新增動作與組？此行為對應哪個 Command 與 Event？

# 定位

流程：訓練紀錄流程
元素：Rule：Event「使用者已開始訓練」與「使用者已記錄該組成績」之間的缺口；Aggregate「本次訓練課表」
細節：C1 前置條件完整性、E1 Actor → Command → Event 串聯（有 Postcondition 依賴的資料，但無 Command 可產生）。
現況：流程檔第 12 行「自由訓練以『空白課表』為入口」，第 52 行「空白課表（總計畫組數為 0）的訓練，使用者主動結束一律判定為使用者已完成訓練」；但〈Command 清單〉訓練紀錄流程的 12 個 Command 中，無任何新增動作或新增組的 Command。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 新增 Command「加入動作至本次訓練」與 Event「使用者已加入動作至本次訓練」，訓練進行中隨時可加；總計畫組數隨之增加，進度條在有動作後成立 |
| B | 沿用自訂訓練流程的既有 Command（選擇動作、設定該動作的組數），空白課表即為「訓練當下即時編輯本次訓練課表」，不新增 Event |
| C | 空白課表不預先定義動作：使用者直接記錄成績，動作於「使用者已記錄該組成績」時一併帶入；總計畫組數恆為 0，進度條永不成立 |
| D | 取消空白課表：一律要求先選課表或先建自訂訓練，移除「空白課表」來源類型 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響訓練紀錄流程的 Event 清單與〈Command 清單〉、本次訓練課表 Aggregate 的「總計畫組數」是否可於訓練中變動、訓練進度條的成立條件、以及既有規則「使用者已記錄該組成績未修改預帶值即勾選者，以快照帶入的目標重量與次數作為實績寫入」（空白課表無預帶值）。
本問題亦影響一般課表：訓練中臨時加練一個計畫外動作，模型同樣無承接路徑。

# 解決結果

**選項 A** —— 新增 Command「加入動作至本次訓練」與 Event「使用者已加入動作至本次訓練」，
Actor 為使用者，訓練進行中隨時可加；總計畫組數隨之增加，進度條在有動作後成立。

裁決要點：

1. 本 Command 修改**本次訓練課表 Aggregate**，不沿用自訂訓練流程的「選擇動作」與
   「設定該動作的組數」（該二者修改自訂訓練 Aggregate），避免兩個生命週期不同的
   Aggregate 共用 Command。
2. 本 Command 對總計畫組數**只增不減**，已加入的動作與組不可移除；不想練的組不勾選即可。
3. **總計畫組數整體仍非單調遞增** —— AI 訓練中調整可使其下降。既有規則
   「AI 調整導致總計畫組數變動時，進度百分比允許下降」不受本裁決推翻。
4. 一般課表於訓練中臨時加練計畫外動作，走同一條路徑，不另立 Event。
5. 加入的組無快照帶入值，目標重量與次數由使用者於加入時指定。
