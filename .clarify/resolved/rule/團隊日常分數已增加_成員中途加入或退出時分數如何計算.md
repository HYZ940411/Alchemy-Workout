# 釐清問題

成員在週期中途加入或退出團隊時，其貢獻的團隊分數如何計算？退出時已貢獻的分數是否扣除？

# 定位

流程：團隊組隊任務流程
元素：Rule：團隊日常分數已增加 / 團隊限時分數已增加的 Postcondition
細節：狀態邊界與組合邊界（C3）；跨 Aggregate 一致性（D4）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 分數計入即歸團隊所有，成員退出不扣除（單調遞增） |
| B | 成員退出時扣除其本週期貢獻的全部分數 |
| C | 分數不扣除，但中途加入者僅能貢獻加入後產生的分數 |
| D | 分數不扣除，且設有防刷規則：同一使用者每週期僅能為一個團隊貢獻分數 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響團隊分數 Event 的 Postcondition 與單調遞增性、團隊 Aggregate 與成員貢獻明細的關聯、排行榜公平性、以及跨團隊換隊刷分的防範規則。

# 優先級

High

# 既有約束（來自已解決項目）

第 51 題（`resolved/aggregate/團隊日常分數_日常分數與限時分數的計算公式.md`，選項 A）已裁決：
團隊日常分數 ＝ 全體成員個人排行榜分數**加總**。
故本題的核心是：成員退出時，其已貢獻的分數是否從團隊分數扣除；
成員中途加入時，其加入前的個人分數是否計入。

# 解決結果

**選項 C** —— 分數計入即歸該團隊所有，退出不扣除；中途加入者僅能貢獻加入後產生的分數。

本規則承擔「防止月底跳槽蹭排行獎勵」的職責（12 小時換隊冷卻期不負責此事）。

使用者另提出新機制：每週期設 1～3 天的重新分隊期，該期間不計分。天數與細節尚未定案 → 新增 `rule/團隊日常分數已增加_重新分隊期的天數與計分規則.md`
