# 釐清問題

「訓練進度條」的進度百分比計算公式為何？以組數、動作數、或訓練量為分母？

# 定位

流程：訓練紀錄流程（循環：使用者已記錄重量 > 組間休息已結束）
元素：Aggregate：訓練進度條（或為訓練紀錄 Aggregate 的衍生欄位）；Event：訓練進度條已增加
細節：衍生欄位的定義公式（D3）；單調遞增（C4）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 已完成組數 / 總計畫組數，進度只增不減（單調遞增） |
| B | 已完成動作數 / 總計畫動作數 |
| C | 已完成訓練量 / 計畫總訓練量（重量 × 次數 × 組數） |
| D | 已完成組數 / 總計畫組數，但 AI 調整訓練後允許因分母變動而下降 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響訓練進度條的欄位型別與計算公式、訓練進度條已增加的 Postcondition、與 AI 訓練中調整流程「訓練進度條已重算」的一致性、以及是否違反單調遞增原則。

High

# 併同回答（來自已解決項目）

第 24 題（`resolved/command/使用者已開始訓練_未選擇課表可否直接開始訓練.md`，選項 D）已裁決：
自由訓練以「空白課表」為入口，課表為必填。
本題的計算公式**須一併涵蓋空白課表情境**（動作數為 0 或訓練中動態增加時，進度百分比如何計算）。

# 解決結果

D① + 使用者補充「這個不用單調遞增」 —

- 進度百分比 ＝ 已完成組數 / 總計畫組數
- 訓練進度條**不要求單調遞增**
- AI 調整訓練導致總計畫組數變動時，進度百分比允許下降
- 總計畫組數為 0（空白課表）時不顯示進度條，進度條不成立

採代號 ①：空白課表不顯示進度條。未採 ②（分母動態變動）與 ③（固定 0%）。
