# 釐清問題

使用者 Aggregate 中身高、體重、年齡三個欄位的資料型別、單位與合法範圍分別為何？

# 定位

流程：註冊流程
元素：Aggregate：使用者
細節：欄位型別與範圍限制、單位標明（D2）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 身高 int(公分, 50-250)、體重 float(公斤, 20-300)、年齡 int(歲, 13-120) |
| B | 身高 float(公分)、體重 float(公斤)，皆保留一位小數；年齡改記錄生日 date，年齡為衍生欄位 |
| C | 支援公制與英制雙單位，需額外記錄單位偏好欄位 |
| D | 不設上下限，僅要求為正數 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響使用者 Aggregate 欄位定義、「使用者已填入身高 / 體重 / 年齡」對應 Command 的輸入驗證 Precondition、以及 AI 訓練調整流程的計算輸入。

# 優先級

High

# 解決結果

ABC-合併（追問後收斂） —

| 欄位 | 型別 | 單位 | 合法範圍 |
|------|------|------|----------|
| 身高 | float（一位小數） | 公分 | 50–250 |
| 體重 | float（一位小數） | 公斤 | 20–300 |
| 生日 | date | — | 對應年齡 13–120 歲 |
| 單位偏好 | 列舉 | — | 公制 / 英制 |

- 儲存一律以公制為準，英制僅為顯示偏好。
- 英制範圍由公制換算（身高 20–98 in、體重 44–661 lb），不另設獨立範圍。
- 年齡不直接儲存，由生日衍生；未滿 13 歲不得完成註冊。

# 追問紀錄

初次回答為「A+B+C」，但 A（身高 int）與 B（身高 float）型別直接衝突。
追問後使用者選 ABC-合併：型別採 B 的 float 與生日，範圍採 A 的區間與 13 歲門檻，
雙單位採 C 並新增單位偏好欄位。
