# 釐清問題

「連續訓練已紀錄」中連續訓練天數的判定基準為何？與訓練中斷流程的 36 小時中斷判定如何協調？

# 定位

流程：訓練結算流程、訓練中斷流程
元素：Aggregate：連續訓練；Event：連續訓練已紀錄、連練天數已中斷
細節：欄位定義（D2）；欄位間不變條件（D3）；跨流程一致性（E3）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 以自然日判定：同一日內訓練即該日計一天，隔日未訓練即中斷；36 小時規則僅用於發送通知 |
| B | 以 36 小時滾動視窗判定：距上次訓練 36 小時內再次訓練即續連，與自然日無關 |
| C | 以自然日判定連續天數，但允許 36 小時內的跨日訓練視為續連（寬限機制） |
| D | 以簽到換日時點（當地 04:00）為日界判定 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響連續訓練 Aggregate 的欄位與計算、連續訓練已紀錄的 Postcondition、連續訓練獎勵加成的天數來源、連續訓練成就已解鎖的門檻比對，以及與訓練中斷流程 36 小時 Policy 的一致性。

# 優先級

High

# 解決結果

C — 以自然日判定連續天數，並提供 36 小時寬限：

- 同一自然日內訓練一次以上，該日計為 1 天，不重複計數
- 距上次訓練未超過 36 小時再次訓練，連續天數續計（即使跨過一個未訓練的自然日）
- 距上次訓練超過 36 小時，連續訓練天數歸零
- 判定基準為使用者當地時區時戳（沿用全域規範）

# 選擇理由（使用者要求「心理負擔較小」後採納之建議）

- A 與 D 皆為「隔日未訓練即中斷」，等於懲罰使用者安排必要的休息日，
  對健身類產品是錯誤的行為引導。
- B 與 C 的寬限度相同（皆 36 小時），差別在計數單位：
  B 實際計算的是次數卻稱為「天數」，語意混亂；C 維持「天數」的直覺語意。
- C 與現有模型完全相容：36 小時 Policy 保持原意，
  「連續訓練天數已歸零」仍掛在 36 小時之下，無既有 Event 語意需要改動。
