# 釐清問題

耐力值已定案為附掛值（不進六維能力值本身、不掛成就、不進綜合等級）。但耐力值於哪個畫面呈現給使用者、雷達圖是否需要畫出第二圈輪廓來對照力量與耐力，使用者於能力值算法整段重寫時裁示「晚點再談」，此題目前仍未回收。

# 定位

流程：訓練結算流程
元素：Read Model「六維能力值雷達圖」；Aggregate「能力值的維度結構」
細節：耐力值已有完整的計算公式（實際反覆次數 ÷ 該 %1RM 的標準反覆次數），但沒有任何 Read Model 欄位承載其呈現。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 雷達圖畫雙圈輪廓：內圈為力量（六維能力值）、外圈為耐力，同一張圖對照兩者（**推薦**：耐力值同樣依肌群分六維，與六維能力值天然同構，雙圈呈現不需要新畫面，且能直接回答「這個部位是弱在力量還是耐力」） |
| B | 耐力值另立獨立區塊（如條列六個數字），不畫在雷達圖上 |
| C | 耐力值暫不對使用者呈現，僅供內部或未來的 AI 調整參考使用 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響 Read Model「六維能力值雷達圖」的欄位與畫面設計；不影響任何 Rule 或 Aggregate 結構（耐力值的計算公式已定案）。

# 解決結果

**選項 B：耐力值以獨立區塊條列六個數值，不畫入雷達圖，且不作為主要呈現項目。**

使用者裁示：「**耐力值不必成為主要呈現的項目**」。

- **不採 A（雷達圖畫第二圈輪廓）**：耐力值雖同樣依肌群分六維、與六維能力值同構，
  但畫入同一張圖會使其取得與力量**同等的視覺份量**——
  而耐力值為附掛值（不掛成就、無退步機制、不進綜合能力等級），
  其在模型中的地位本即次於力量，呈現份量應與之相稱。
- 雷達圖維持**單一輪廓**（承既有欄位定義「一次僅呈現單一輪廓」），不因本項而改變。
- 空值處理：無可靠最佳 1RM 的維度其耐力值為空值（承既有規則「不推測」），
  該維呈現為空白或「—」，不以 0 表示。
- 六維皆為空值時（新使用者尚未做過大重量訓練）不呈現本區塊。
