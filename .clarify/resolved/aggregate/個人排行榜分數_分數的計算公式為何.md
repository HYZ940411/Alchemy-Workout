# 釐清問題

「個人排行榜分數」的計算公式為何？各來源（訓練結算、每日任務完成、每日任務全部完成加碼）各自加多少分？

# 定位

流程：訓練結算流程、每日任務流程
元素：Aggregate：個人排行榜分數（模型中尚未定義）；Event：個人排行榜分數已增加（於兩條流程共出現三次）
細節：隱含但未明確定義的 Aggregate（D1）；衍生欄位公式（D3）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 訓練結算依訓練量換算分數，每日任務為固定分數，全部完成另加固定加碼 |
| B | 所有來源皆為固定分數，與訓練量無關，避免長時間訓練者壟斷 |
| C | 訓練結算依訓練量並套用連續訓練加成，任務為固定分數 |
| D | 分數即經驗值，兩者為同一數值，不另外定義 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響個人排行榜分數 Aggregate 的欄位與公式、三處「個人排行榜分數已增加」Event 的 Postcondition、連續訓練獎勵加成是否套用於分數、以及排行榜週期結算流程的重置範圍。

# 優先級

High

# 解決結果

A — 訓練結算依訓練量換算分數；每日任務進度為固定分數；每日任務全部完成另加固定加碼分數。

未採 C（不預設連續訓練加成套用於分數）、B（固定分數與訓練量無關）、
D（分數即經驗值 —— 該選項會與第 26、31 題衝突，因經驗值單調遞增供階級判定，
而排行榜分數具週期重置，同一數值不可能兼具兩種性質）。

**Partial**：三種來源的具體分數值未給定。
