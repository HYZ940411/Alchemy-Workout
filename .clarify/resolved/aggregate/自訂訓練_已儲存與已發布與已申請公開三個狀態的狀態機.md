# 釐清問題

自訂訓練 Aggregate 的「已儲存」「已發布」「已申請公開」「已審核」四個狀態的定義、差異與合法轉換路徑為何？

# 定位

流程：自訂訓練流程（循環 1：使用者已選擇動作 > 使用者已設定該動作的組數、循環 2：使用者已設定該組的重量 & 次數）
元素：Aggregate：自訂訓練；Event：使用者已儲存自訂訓練、使用者已發布自訂訓練、使用者已申請公開訓練、管理員已審核公開訓練
細節：生命週期與狀態機（D5）；狀態轉換規則完整性（D5）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 草稿 → 已儲存 → 已發布（自己可用）→ 已申請公開 → 已公開；單向不可退回 |
| B | 草稿 → 已儲存 →（可選）已發布給追蹤者 →（可選）已申請公開；已發布可退回私人 |
| C | 已儲存即可自己使用；已發布 = 分享至社群；已申請公開 = 進入官方課表庫，三者為獨立旗標而非狀態 |
| D | 已儲存與已發布為同一狀態，模型中應合併為一個 Event |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響自訂訓練 Aggregate 的狀態欄位與狀態機定義、四個 Event 的 Precondition 與 Postcondition、每次狀態轉換是否都對應一個 Event（D5）、以及管理員審核的作用對象。

# 優先級

High

# 解決結果

B — 五個狀態、六條合法轉換：

| 起始狀態 | 觸發 Event | 目標狀態 |
|----------|-----------|----------|
| 草稿 | 使用者已儲存自訂訓練 | 已儲存 |
| 已儲存 | 使用者已發布自訂訓練 | 已發布 |
| 已發布 | 使用者已取消發布自訂訓練 | 已儲存 |
| 已發布 | 使用者已申請公開訓練 | 已申請公開 |
| 已申請公開 | 管理員已審核公開訓練 | 已公開 |
| 已申請公開 | 公開訓練審核未通過 | 已發布 |

發布與申請公開皆為選用步驟，停留於已儲存即可自己使用。

# 新增 Event

「使用者已取消發布自訂訓練」—— 選項 B 明文包含「已發布可退回私人」，
此轉換原本無對應 Event，狀態機不完整（D5 要求每次狀態轉換都對應一個 Event）。
本 Event 由選項 B 的內容直接推導，非額外擴張。

# 統一語言修正

選項 B 原文為「已發布給**追蹤者**」。依 `00_全域規範.md`
「『追蹤』為棄用詞，一律改用『關注』」的既有裁決，回寫時改為「關注者」。
