# 釐清問題

能力值等級的判定基準為何 —— 絕對點數門檻，還是全平台相對百分位？

# 定位

流程：訓練結算流程
元素：Aggregate「使用者」的維度能力等級推導規則
細節：D3 衍生欄位公式、C3 數值邊界。

前置：`resolved/aggregate/六維能力值_能力值是否分等級與分級對象為何.md`（第 22.1 題）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 絕對點數門檻，六維共用同一組門檻 |
| B | 絕對點數門檻，但六維各自一組門檻，依各肌群基準訓練量校準 |
| C | 全平台相對百分位（如前 5% 為 S） |
| D | 絕對門檻，但依健身經驗分級（新手 / 中階 / 進階）分別設定 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響能力值等級的推導規則、綜合能力等級的推導公式（22.3）是否有共同尺度、
能力值上限的可達性、以及成就是否可掛勾等級。

# 優先級

High

# 解決結果

**選項 A** —— 絕對點數門檻，六維共用同一組門檻。

使用者另裁決：**「可到達 1000，不必恆小於 1,000」**。

裁決要點：

1. 六維共用一組門檻，不依維度分設，亦不依健身經驗分級分設；不採相對百分位。
2. 跨肌群正規化已由〈能力值提升公式〉的獨立基準訓練量完成，故無須依維度分設門檻。
3. 「理論上限」更名為「**能力值上限**」，1,000 為**可達成**之值，S 級的頂點即 1,000。
4. 六個等級的具體點數門檻尚未給定，標為待決策。

## 推翻的既有共識

`resolved/aggregate/能力值_是否設總量上限或遞減報酬.md` 的兩條被推翻：
「理論上限為漸近線，不是可達成的值」、「能力值恆小於 1,000」。
該檔已追加〈後續修正〉章節。
