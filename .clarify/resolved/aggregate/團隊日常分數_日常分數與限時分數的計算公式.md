# 釐清問題

「團隊日常分數」與「團隊限時分數」的計算公式各為何？兩者是獨立排行榜還是可合併？

# 定位

流程：團隊組隊任務流程
元素：Aggregate：團隊日常分數、團隊限時分數；Rule / Policy：成員完成訓練 / 社群互動 → 累計團隊日常分數
細節：衍生欄位公式（D3）；Aggregate 邊界（D1）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 日常分數 = 全體成員個人排行榜分數加總；限時分數 = 完成限時任務的成員數 × 固定分 |
| B | 日常分數依成員完成訓練 / 社群互動次數計固定分，與個人分數脫鉤；限時分數同理 |
| C | 兩者皆依人均計算（總分 / 成員數），避免大團隊優勢 |
| D | 兩者為同一分數，僅來源不同，應合併為單一「團隊分數」與單一排行榜 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響兩個團隊分數 Aggregate 的欄位與公式、對應 Event 的 Postcondition、日常與限時兩個排行榜是否需分開維護、以及排行榜週期結算流程的三種獎勵發放。

# 解決結果

A + 使用者補充 — 使用者原話：「A，但限時任務是每天都有，所以當團隊每個人都有完成，會加成」。

- **團隊日常分數** ＝ 全體成員個人排行榜分數加總（直接沿用第 43 題的個人分數，不另定計分規則）
- **團隊限時分數** ＝ 完成限時任務的成員數 × 固定分，不依訓練量計算
- **全員完成加成**：團隊全體成員皆完成限時任務時，額外給予加成
- 限時任務為**每日指派**
- 兩個分數不合併，兩個排行榜各自維護（未採 D）

**Partial ×2**：固定分的數值、全員完成的加成幅度。

# 設計意涵

日常分數衡量成員的訓練努力程度（隨訓練量變動），
限時分數衡量團隊的動員參與率（人人一票，與練多練少無關）。
兩者各自對應排行榜週期結算流程中的一種獎勵。

# 承接的既有裁決

- 第 43 題：個人排行榜分數的計算方式已定，團隊日常分數直接加總即可。
- 第 44 題：團隊人數上限 5 人，加總不致造成大團隊碾壓，故未採 C 的人均計算。
