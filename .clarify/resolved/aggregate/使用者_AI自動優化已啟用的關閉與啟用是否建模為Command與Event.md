# 釐清問題

使用者 Aggregate 於第七輪新增欄位「AI 自動優化已啟用」（bool，預設真）。該欄位的變更是否建模為 Command 與 Event？模型既有的兩條判準在本欄位上互相衝突。

# 定位

流程：AI 自動優化訓練流程
元素：使用者 Aggregate 欄位、〈Command 清單〉
細節：B1 Command 識別完整性、E1 Actor→Command→Event 串聯。
由使用者於第七輪第 9 題主動提出「自動優化使用者可以關閉」後產生。

# 背景：兩條既有判準在此衝突

| 既有欄位 | 建模為 Event？ | 模型給的理由 |
|---------|--------------|-------------|
| 六維能力值對外可見 | **否** | 純設定、**不影響任何規則判定** |
| 對關注者可見（自訂訓練） | **是** | 決定**他人**能否下 Command，屬他人的 Precondition |
| 隊長已變更團隊可見性 | **是** | 同上 |

「AI 自動優化已啟用」兩邊都不符：

- 它**不影響他人**，只影響自己 → 依第二條判準不需建模。
- 但它是〈AI 自動優化訓練流程〉Policy 的 **Precondition**，直接決定該流程會不會觸發
  → 依第一條判準（「不影響任何規則判定」才不建模）**應該**建模。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | **不建模**：純設定頁欄位，比照「六維能力值對外可見」。判準收窄為「是否影響**他人**下 Command」 |
| B | **建模為 Command ＋ Event**（設定自動優化開關 → 使用者已變更自動優化設定）。判準維持為「是否影響任何規則判定」 |
| C | **建模但不新增 Event**：僅列入〈Command 清單〉為查詢類以外的設定類 Command，統一處理全部設定頁欄位 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

本題實為**判準之爭**，其答案將及於模型中全部設定頁欄位，非僅本欄位。
連帶影響：`command/使用者_持有器材明細的設定Command與Event全數缺失.md`（同類問題）、
「六維能力值對外可見」既有裁決是否需重新檢視、以及〈Command 清單〉的總條數。

**建議與 `command/使用者_持有器材明細…md` 合併為同一題裁決** —— 兩者為同一個判準問題的兩個實例。

# 解決結果（2026-08-08，第八輪第 21 題，兩檔合併裁決）

**D —— 依判準分流。判準：該欄位是否被任何 Precondition 或 Policy 讀取。**

| 欄位 | 建模 | 被誰讀取 |
|------|------|---------|
| 持有器材明細 | ✅ | 訓練前的器材比對 Policy、AI 替換動作的調整依據 |
| AI 自動優化已啟用 | ✅ | 〈AI 自動優化訓練流程〉Policy 的 Precondition |
| 偏好訓練時段 | ✅（既有） | 訓練提醒的發送時段判定 |
| 六維能力值對外可見 | ❌ | 無任何規則讀取 |
| 單位偏好 | ❌ | 僅影響顯示 |

## 關鍵論據：模型早已在用這條判準

「偏好訓練時段」正是「**只影響自己、但被規則讀到**」的欄位，
其既有 Event「使用者已選擇偏好訓練時段」即依本判準成立。
本題僅將該判準明文化，非新增判準。

**選項 A（判準收窄為「是否影響他人」）會反過來推翻該既有 Event。**

## 被推翻的既有共識

`00_全域規範.md` 原規則：

> 本欄位（持有器材明細）**不建模為 Event**：比照「六維能力值對外可見」——
> 純設定、不影響任何規則判定、不作為任何 Precondition，只影響預設篩選與 AI 的輸入。

**該理由於寫下時即與事實不符**，且其後又新增兩處讀取點：
① 器材比對 Policy 以本欄位判定是否觸發「本次訓練器材已解鎖」；
② 「AI 已替換動作」以本欄位為調整依據。

## 兩個不採方案

- **不採逐一建模全部設定欄位**：單位偏好、雷達圖隱藏等純顯示欄位各給一個 Event，
  Event 總數膨脹而無任何讀者。
- **不採單一泛用 Command「變更個人設定」**：其攜帶任意欄位的任意值，
  Postcondition 只能寫成「該欄位變成新值」，等同無驗收標準 ——
  承〈平台級設定的軟體邊界〉否決「平台設定已變更」單一泛用 Event 的相同理由。

## 一併收斂的暗路

「持有器材明細」原有**三條寫入路徑、零個 Command**。現收斂為兩條路徑共用同一個 Command：
① 設定頁填寫；② 於「本次訓練器材已解鎖」時勾選「套用至未來所有訓練」。
（第三條為註冊時的 3 級器材，屬不同欄位，本即有自己的 Event。）
