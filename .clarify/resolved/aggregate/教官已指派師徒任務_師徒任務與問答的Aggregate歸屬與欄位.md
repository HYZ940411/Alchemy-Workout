# 釐清問題

「師徒任務」與「問答」是否為獨立 Aggregate？其欄位與狀態機（含未完成作廢）為何？

# 定位

流程：師徒互動流程
元素：Aggregate（尚未定義）；Event「教官已指派師徒任務」「學徒已完成師徒任務」「學徒已提問」「教官已回答」「學徒已評分該次問答」「學徒已評分該次師徒任務」
細節：Aggregate 識別與邊界（D1）；欄位定義（D2）；生命週期與狀態機（D5）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 師徒任務與問答各為獨立 Aggregate，皆以師徒關係 ID 關聯，各自有評分欄位 |
| B | 合併為單一「師徒互動」Aggregate，以類型欄位區分任務與問答 |
| C | 兩者皆併入師徒關係 Aggregate，作為其下的子集合 |
| D | 僅師徒任務為獨立 Aggregate；問答比照私訊處理，不另建模 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響「師徒任務獎勵已發放」的 Precondition、「教官聲望已變動」的兩種評分來源歸屬、
師徒關係解除時「未完成的師徒任務作廢」的狀態落點，以及教官資格撤銷時進行中任務的處理
（`rule/教官資格已撤銷_撤銷時既有師徒關係與進行中任務如何處理.md`）。
本項為新掃描發現，非承接 `pending-gaps.md`。

# 優先級

High

# 解決結果

**選項 A**：師徒任務與師徒問答各為獨立 Aggregate，皆以師徒關係 ID 關聯，各自有評分欄位。

**師徒任務 Aggregate**：師徒關係 ID、指派者、任務內容、狀態、學徒評分。

| 起始狀態 | 觸發 Event | 目標狀態 |
|----------|-----------|----------|
| — | 教官已指派師徒任務 | 已指派 |
| 已指派 | 學徒已完成師徒任務 | 已完成 |
| 已指派 | 師徒關係已解除 | 已作廢（終止） |

**師徒問答 Aggregate**：師徒關係 ID、提問者、提問內容、回答內容、學徒評分；不設狀態機。

**理由**：

- 兩者皆需被評分（學徒已評分該次問答 / 該次師徒任務），要被指名評分就需獨立 ID
  —— 此點直接排除選項 D（問答不建模則評分無對象）。
- 生命週期不同：任務有已指派 / 已完成 / 已作廢的流轉，問答無作廢概念。選項 B 合併後任務的狀態欄位對問答不適用。
- 不併入師徒關係（選項 C）：一段長期關係下的任務與問答數無上限成長，與訊息不併入對話、關注不併入使用者一致。
- 「已作廢」納入狀態值域，供「師徒關係已解除 → 未完成任務作廢」與後續的「教官資格已撤銷」規則落點。

- 獨立 Aggregate 清單 40 → 42 項。
