# 釐清問題

本次訓練課表的快照應於哪一個時點產生？

# 定位

流程：訓練紀錄流程、AI 訓練前調整流程
元素：Aggregate「本次訓練課表」的產生時點；Event「使用者已選擇訓練課表」「使用者已開始訓練」
細節：事件時序與因果（A3）；Event → Aggregate 一致性（E3）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 改為「使用者已選擇訓練課表」時產生快照 |
| B | 維持「使用者已開始訓練」時產生；AI 訓練前調整改來源課表的暫存副本，開始訓練時併入 |
| C | 維持開始訓練時產生；AI 訓練前調整改為在「使用者已開始訓練」之後才能觸發 |
| D | 快照分兩段：選擇課表時產生草稿快照，開始訓練時凍結為正式快照 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響「訓練課表已套用新強度〔作用範圍＝本次訓練〕」的 Postcondition 是否可驗收、
快照帶入上次重量的發生時點，以及 AI 訓練前調整流程的產品行為。

# 優先級

High

# 來源

本項為第 19 題於 formulation 過程中發現並即時開立，非 discovery 掃描產出。
發現方式：第 17 題的寫回內容與 AI 訓練前調整流程的既有時序不相容。

# 解決結果

**選項 A**：快照於「使用者已選擇訓練課表」時產生。

- 選了課表即確定「本次要練什麼」，開始訓練只是開始執行。
- AI 訓練前調整改的即為此快照，Postcondition 得以驗收。
- 不採 B：暫存副本等於多一個沒有名字的 Aggregate。
- 不採 C：會改變產品行為（本來開練前先調整，變成要先開始才能調）。
- 不採 D：兩段式狀態多一組轉換規則但無對應好處。
