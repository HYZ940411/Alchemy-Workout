# 釐清問題

「能力值已退步」的退步幅度計算公式為何？退步是否有下限（不低於初始值或某一保底值）？

# 定位

流程：訓練中斷流程
元素：Aggregate：能力值（模型中尚未定義）；Event：能力值已退步
細節：衍生欄位計算公式（D3）；數值邊界與最小值（C3）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 每滿 120 小時未訓練退步固定百分比，下限為註冊初始值 |
| B | 每滿 24 小時（超過 120 小時後）退步固定點數，下限為 0 |
| C | 依當前能力值等比衰減，下限為該使用者歷史最高值的 50% |
| D | 一次性扣除固定比例，不再持續退步，直到下次訓練 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響能力值 Aggregate 的欄位定義與不變條件、能力值已退步的 Postcondition、階級提升流程中階級是否可因此下降、以及與訓練結算流程「能力值已提升」的計算對稱性。

# 優先級

High

# 既有約束（來自已解決項目）

故本題的退步公式與下限**須逐維定義**，而非單一總值。

第 6 題（`resolved/event/回歸任務已指派_與訓練中斷流程同時觸發時如何協調.md`）已裁決：

# 解決結果

A②（使用者於第 40 題提問時補答代號） — 每滿 120 小時未訓練退步固定百分比（可持續發生），
下限為註冊初始值；**六維各自獨立計時**：自該維最後一次訓練起算滿 120 小時才退該維，
僅退步逾時的維度，其餘維度不受影響。

未採 B（下限 0）、C（下限為歷史最高的 50%）、D（一次性扣除不持續）。

**Partial ×1**：退步的固定百分比數值未給定。

**補答紀錄**：初次僅回答「A」，六維規則一度記為 Partial。
使用者於第 40 題提問時補上「上一題是 A②」，逐維規則因此定案為②（各維獨立計時），
該項 Partial 已消解。
