# 釐清問題

站內是否存在虛擬貨幣？共有幾種？取得來源（任務獎勵 / 訓練獎勵 / 儲值）與消耗用途為何？

# 定位

流程：虛擬商品購買流程、訓練結算流程、每日任務流程
元素：Aggregate：虛擬貨幣（模型中尚未定義，但各流程的「獎勵已發放」可能包含）
細節：隱含但未明確定義的 Aggregate（D1）；欄位定義（D2）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 單一種虛擬貨幣，可由各類獎勵取得亦可儲值，用於購買虛擬商品與補簽券 |
| B | 兩種貨幣：免費幣（獎勵取得）與付費幣（儲值取得），部分商品僅收付費幣 |
| C | 單一種虛擬貨幣，僅能由獎勵取得不可儲值 |
| D | 無虛擬貨幣，所有獎勵皆為實體效果（經驗值 / 能力值 / 道具） |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響是否需新增虛擬貨幣 Aggregate、各流程「獎勵已發放」Event 的 Postcondition 內容、虛擬商品購買流程的支付方式、補簽券的取得來源、以及是否需要儲值流程。

# 優先級

High

# 解決結果

A（含使用者命名） — 站內僅有一種虛擬貨幣，名稱為**金幣**。

- 取得來源：各類獎勵發放、儲值
- 消耗用途：購買虛擬商品、購買補簽券
- 不區分免費幣與付費幣
- 金幣餘額不得為負值

使用者原話：「A，稱為：金幣」。
