# 釐清問題

使用者 Aggregate 的性別欄位值域為何？

# 定位

流程：註冊流程
元素：Aggregate：使用者，欄位：性別
細節：類別邊界與值域定義（D2、C3）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 男 / 女 二元列舉，必填 |
| B | 男 / 女 / 其他 三值列舉，必填 |
| C | 男 / 女 / 其他 / 不願透露，可選填，未填時訓練計畫推薦使用中性參數 |
| D | 自由文字，不做列舉限制 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響使用者 Aggregate 欄位型別、「使用者已填入性別」Command 的輸入驗證、以及「依經驗/目標/器材從既有計畫中推薦」Policy 是否將性別納入推薦參數。

# 優先級

Medium

# 解決結果

A — 性別為男 / 女二元列舉，必填。

不含「其他」與「不願透露」選項（未採 B、C），亦非自由文字（未採 D）。

# 相容性確認

註冊流程既有規則「9 項個人資料全數填畢，方可發生『使用者已完成註冊』」
與本題的「必填」一致，該規則不需調整。

# 連帶影響

性別既為必填且值域明確，訓練計畫推薦 Policy 可直接以性別為參數，
不需定義「未填時的中性參數」。
