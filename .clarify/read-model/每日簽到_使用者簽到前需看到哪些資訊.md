# 釐清問題

使用者在執行簽到 Command 前，需要看到哪些資訊才能做決策？此 Read Model 應包含哪些欄位？

# 定位

流程：每日簽到流程
元素：Read Model：簽到頁（尚未定義）；服務對象 Actor：使用者
細節：Read Model 識別與欄位來源（D6）、Read Model 支撐 Command（E4）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 當日是否已簽到、連續天數、累計天數、次一個成就門檻與距離 |
| B | 上述加上本月簽到日曆、補簽券持有數量 |
| C | 上述全部加上今日簽到可獲得的獎勵預覽與連續加成 |
| D | 僅需「當日是否已簽到」與「連續天數」 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響簽到頁 Read Model 的欄位定義與資料來源（連續簽到 Aggregate、成就 Aggregate、補簽券 Aggregate）、即時性要求、以及是否揭露成就門檻參數給使用者。
