# 釐清問題

「使用者已申請 師徒關係」的申請方是想拜師的學徒，還是想收徒的教官？雙向皆可嗎？

# 定位

流程：師徒互動流程
元素：Command：申請師徒關係；Actor：使用者（未區分學徒 / 教官）；Event：使用者已申請 師徒關係、對方已接受申請
細節：Actor 識別（B4）；同一 Command 是否可由多種 Actor 執行且行為是否有差異（B4）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 僅學徒可向教官申請，教官不可主動邀請 |
| B | 雙向皆可，需拆為「學徒已申請拜師」與「教官已邀請收徒」兩個 Event |
| C | 雙向皆可，維持單一 Event，申請方角色為其攜帶資訊 |
| D | 僅教官可主動邀請，學徒不可申請 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響申請師徒關係 Command 的 Actor 與權限、師徒互動流程的 Event 數量、師徒關係 Aggregate 的發起方欄位、以及「對方已接受申請」的 Actor 定義。
