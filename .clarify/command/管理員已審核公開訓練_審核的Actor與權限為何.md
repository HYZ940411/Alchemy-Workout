# 釐清問題

「管理員已審核公開訓練」的管理員是哪一類角色？是否需要特定權限？教官可否代為審核？

# 定位

流程：自訂訓練流程（循環 1：使用者已選擇動作 > 使用者已設定該動作的組數、循環 2：使用者已設定該組的重量 & 次數）
元素：Command：審核公開訓練；Actor：管理員
細節：Actor 識別與權限（B4、B5）；誰不能執行此 Command（B5）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 僅平台管理員可審核，教官與一般使用者皆不可 |
| B | 平台管理員與通過認證的教官皆可審核，但教官不可審核自己申請的課表 |
| C | 僅平台管理員可審核，但教官申請的課表可免審核直接公開 |
| D | 系統自動初審（內容檢查），管理員複審 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響審核公開訓練 Command 的 Actor 定義與權限規則、與教官申請流程的角色關係、是否需要「系統自動初審」的額外 Event、以及利益衝突的 Precondition（不可審核自己的申請）。
