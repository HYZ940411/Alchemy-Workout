# 釐清問題

「管理員已設定限時任務」中的「管理員」是平台管理員，還是團隊內的隊長 / 團隊管理員？

# 定位

流程：團隊組隊任務流程
元素：Command：設定限時任務；Actor：管理員
細節：Actor 識別（B4）；同名異義的角色術語衝突（F2、B5）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 平台管理員，全平台統一設定同一組限時任務 |
| B | 團隊隊長，各團隊自行設定任務，應改名為「隊長」以區分平台管理員 |
| C | 平台管理員設定任務池，團隊隊長從池中選擇，需拆為兩個 Command |
| D | 平台管理員，且應與管理員商品上架 / 管理社群流程的管理員為同一角色 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響設定限時任務 Command 的 Actor 與權限規則、團隊 Aggregate 是否需要隊長角色欄位、Actor 術語表的角色定義、以及「團隊已指派限時任務」的作用範圍（全平台或單一團隊）。
