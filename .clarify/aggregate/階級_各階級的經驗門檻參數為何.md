# 釐清問題

階級提升流程中「經驗達門檻升階（參數待定）」的各階級門檻值為何？共有幾個階級？

# 定位

流程：階級提升流程
元素：Aggregate：階級；Rule / Policy：階級門檻判定（經驗達門檻升階，參數待定）
細節：待決事項 TODO（F3）；欄位範圍與數值邊界（D2、C3）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 固定階級數（如 10 階），門檻為等差級數 |
| B | 固定階級數（如 10 階），門檻為等比級數（越高階越難） |
| C | 無上限階級，門檻依公式動態計算 |
| D | 固定階級數，門檻由管理員在後台可調整，需要「階級設定」Aggregate 與管理員 Command |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響階級 Aggregate 的欄位與門檻定義、使用者已提升階級的 Precondition、進階訓練計畫已解鎖的階級對應關係、以及是否需要管理員設定流程。此為模型中明確標記「參數待定」的 TODO。
