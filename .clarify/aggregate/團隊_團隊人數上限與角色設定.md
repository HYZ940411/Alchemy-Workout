# 釐清問題

團隊 Aggregate 的人數上限、角色設定（隊長 / 成員）、以及建立團隊的門檻為何？

# 定位

流程：團隊組隊任務流程
元素：Aggregate：團隊（模型中尚未定義）
細節：隱含但未明確定義的 Aggregate（D1）；欄位定義與範圍（D2）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 人數上限固定（如 10 人），建立者即隊長，隊長可轉讓，無建立門檻 |
| B | 人數上限固定，僅有隊長與成員兩種角色，需達指定階級才可建立團隊 |
| C | 人數上限依團隊等級成長，設隊長 / 副隊長 / 成員三種角色 |
| D | 無人數上限，無角色區分，所有成員權限相同 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響團隊 Aggregate 的欄位定義與不變條件、使用者已建立團隊 / 已加入團隊的 Precondition、管理員已設定限時任務的 Actor 權限、以及團隊分數的計算基數。

# 優先級

High
