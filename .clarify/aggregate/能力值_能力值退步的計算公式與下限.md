# 釐清問題

「能力值已退步」的退步幅度計算公式為何？退步是否有下限（不低於初始值或某一保底值）？

# 定位

流程：訓練中斷流程
元素：Aggregate：能力值（模型中尚未定義）；Event：能力值已退步
細節：衍生欄位計算公式（D3）；數值邊界與最小值（C3）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 每滿 120 小時未訓練退步固定百分比，下限為註冊初始值 |
| B | 每滿 24 小時（超過 120 小時後）退步固定點數，下限為 0 |
| C | 依當前能力值等比衰減，下限為該使用者歷史最高值的 50% |
| D | 一次性扣除固定比例，不再持續退步，直到下次訓練 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響能力值 Aggregate 的欄位定義與不變條件、能力值已退步的 Postcondition、階級提升流程中階級是否可因此下降、以及與訓練結算流程「能力值已提升」的計算對稱性。
