# 釐清問題

「進階訓練計畫已解鎖」解鎖的是哪些計畫？與註冊流程推薦的訓練計畫是同一個 Aggregate 嗎？階級與計畫的對應關係為何？

# 定位

流程：階級提升流程、註冊流程
元素：Aggregate：進階訓練計畫 / 訓練計畫（模型中尚未定義）；Rule / Policy：階級解鎖判定（達對應階級解鎖該階進階計劃）
細節：隱含但未明確定義的 Aggregate（D1）；Aggregate 命名歧義（D1、F2）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 與註冊推薦的訓練計畫為同一 Aggregate，僅多一個「所需階級」欄位 |
| B | 為獨立 Aggregate，進階計畫由平台另行製作，與初階推薦計畫來源不同 |
| C | 為同一 Aggregate，但進階計畫另需會員訂閱才可使用 |
| D | 每個階級對應固定一組進階計畫，一對一關係 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響訓練計畫 Aggregate 的邊界與命名、階級與計畫的關聯關係（一對多或多對多）、註冊流程推薦 Policy 是否需納入階級條件、以及與會員權益的關係。
