# 釐清問題

「會員權益已生效」的權益具體包含哪些內容？訂閱方案有幾種（月 / 季 / 年）？價格與權益差異為何？

# 定位

流程：會員訂閱流程
元素：Aggregate：會員權益 / 會員訂閱（模型中尚未定義）
細節：隱含但未明確定義的 Aggregate（D1）；欄位定義（D2）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 單一方案（月訂閱），權益為：AI 調整無次數限制 + 進階訓練計畫 + 每月補簽券 |
| B | 月 / 年兩種方案，權益相同僅價格不同 |
| C | 多層級方案（基礎 / 進階），權益依層級遞增，需要權益層級欄位 |
| D | 單一方案，權益內容由管理員後台可調整，需要「權益設定」Aggregate |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響會員權益 Aggregate 的欄位與方案結構、會員權益已生效的 Postcondition、各流程中會員相關 Precondition（AI 調整次數、補簽券配發、進階計畫存取）、以及虛擬商品購買流程的品項重疊。
