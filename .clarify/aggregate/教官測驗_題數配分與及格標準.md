# 釐清問題

教官測驗 Aggregate 的題數、選擇題與簡答題的比例、配分與及格標準為何？

# 定位

流程：教官申請流程
元素：Aggregate：教官測驗（模型中尚未定義）；Policy：教官測驗判定（選擇題 → 系統即時判定，簡答題 → 管理員人工審核）
細節：隱含但未明確定義的 Aggregate（D1）；欄位定義與數值邊界（D2、C3）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 固定題庫，選擇題 20 題 + 簡答題 3 題，選擇題需達 80% 且簡答題皆通過 |
| B | 隨機抽題，選擇題 20 題 + 簡答題 2 題，總分達 80 分及格 |
| C | 題庫與及格標準由管理員後台設定，需要「教官測驗設定」Aggregate |
| D | 僅有選擇題，無簡答題，應移除人工審核 Policy |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響教官測驗 Aggregate 的欄位定義、教官資格已通過的 Precondition、管理員已審核教官測驗的作用對象與範圍、以及是否需要管理員題庫維護流程。
