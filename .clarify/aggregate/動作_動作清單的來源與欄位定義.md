# 釐清問題

「使用者已選擇動作」所選的動作來自何處？動作 Aggregate 的欄位定義為何？使用者可否自建動作？

# 定位

流程：自訂訓練流程（循環 1：使用者已選擇動作 > 使用者已設定該動作的組數、循環 2：使用者已設定該組的重量 & 次數）
元素：Aggregate：動作（模型中尚未定義）；Event：使用者已選擇動作
細節：隱含但未明確定義的 Aggregate（D1）；欄位定義（D2）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 平台維護的固定動作庫，欄位含名稱 / 目標肌群 / 所需器材 / 示範內容，使用者不可自建 |
| B | 平台動作庫為主，使用者可自建私人動作，需補上「使用者已建立自訂動作」Event |
| C | 平台動作庫，且使用者可申請新增動作至公用庫，需管理員審核 |
| D | 僅有動作名稱字串，無獨立 Aggregate |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響是否需新增動作 Aggregate 與管理員維護流程、能力值分肌群計算的資料來源、註冊流程「依器材推薦」Policy 的比對依據、以及自訂訓練與動作的關聯關係（一對多）。
