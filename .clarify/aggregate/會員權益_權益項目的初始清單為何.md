# 釐清問題

權益設定 Aggregate 的權益項目初始清單包含哪些項目？

# 定位

流程：會員訂閱流程
元素：Aggregate「權益設定」；Event「會員權益已生效」的 Postcondition
細節：欄位定義（D2）；權益項目會反向產生各流程的會員 Precondition。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | AI 調整無次數限制 ＋ 每月配發補簽券 ＋ 專屬外觀（非會員的 AI 調整因此需設次數上限） |
| B | 僅每月配發補簽券與虛擬貨幣，不影響任何既有功能的可用性 |
| C | 去廣告 ＋ 進階數據分析 Read Model，不影響訓練與簽到規則 |
| D | 本階段僅定義權益設定 Aggregate 的結構，初始清單延後至上線前由管理員填入 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響會員權益已生效的 Postcondition、各流程是否新增「會員 / 非會員」Precondition 分歧；
若含配發補簽券，須與補簽券持有上限 5 張對齊（達上限時如何配發）；
若含「AI 調整無次數限制」，代表須在三條 AI 流程新增非會員的次數上限規則（該規則目前不存在）。
承接 G28；相關已解決項目：`resolved/aggregate/會員權益_會員權益的內容與方案設計.md`、`resolved/aggregate/補簽券_補簽券的取得來源與持有上限.md`。

# 使用者已提供的輸入（2026-08-02，第 66 題）

使用者於第 66 題主動提出一項權益項目：

> 「無限自訂訓練，沒有會員的只有 3~5 個自訂訓練額度」

**尚未收斂**：3～5 為區間而非單一值。

**與既有模型的相容性檢查**（助理確認，非裁決）：
- 自訂訓練已為獨立 Aggregate，加上數量上限不需新增結構。
- 「使用者已解鎖自訂訓練功能」的既有 Precondition 為累積訓練次數 ≥ 1，
  與額度上限並存無衝突：解鎖決定能不能建，額度決定能建幾份。
- 第 66 題已定案「權益失效後進階計畫鎖定但資料保留」，
  故會員到期且自訂訓練超過免費額度時，超出的部分應比照處理為**鎖定而非刪除**，
  此點需於本題一併裁決。

**助理建議值（供參考，非裁決）**：**3 個**。
理由為最常見的訓練分化是推 / 拉 / 腿三日循環，3 個額度剛好覆蓋一套完整課表；
5 個則已接近「不太會碰到上限」，付費誘因隨之削弱。

本項目仍待使用者裁決完整的權益項目清單。

# 新增候選權益項目（2026-08-02，第五輪第 2 題）

第 2 題（`resolved/read-model/訓練歷史_可回溯時間範圍與圖表與搜尋.md`）裁決 Read Model
「訓練歷史」的回溯範圍**不設限**，明確**不以會員身分限制存取自己的訓練紀錄**。

裁決過程中衍生一個候選權益項目，使用者表示「把付費牆放在分析」，但**本題尚未裁決其細節**：

| 候選項目 | 免費層 | 會員層 |
|----------|--------|--------|
| 訓練歷史的圖表與長期分析 | 訓練清單 ＋ 動作趨勢**列表**（重量、次數、時序） | 動作趨勢**折線圖**、期間比較、進步幅度統計 |

**性質**：屬「往前的能力」而非「往回的存取」，與既有的自訂訓練額度同為擴張型付費牆，
不產生「贖回自己的資料」的觀感。

**現況**：`00_全域規範.md`〈Read Model：訓練歷史〉現已寫成**折線圖對全體使用者開放**。
若本題裁決將圖表列為會員權益，須回頭修改該段落。

**時限**：規格階段改動無代價；上線後再收緊即為對既有使用者的取走，反彈成本高。
故本項須於上線前定案。

**尚未定義**：「期間比較」「進步幅度統計」為本輪新提之詞，模型中尚無對應欄位，
若採納須一併定義其欄位與來源。
