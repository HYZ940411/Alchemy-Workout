# 釐清問題

使用者 Aggregate 中身高、體重、年齡三個欄位的資料型別、單位與合法範圍分別為何？

# 定位

流程：註冊流程
元素：Aggregate：使用者
細節：欄位型別與範圍限制、單位標明（D2）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 身高 int(公分, 50-250)、體重 float(公斤, 20-300)、年齡 int(歲, 13-120) |
| B | 身高 float(公分)、體重 float(公斤)，皆保留一位小數；年齡改記錄生日 date，年齡為衍生欄位 |
| C | 支援公制與英制雙單位，需額外記錄單位偏好欄位 |
| D | 不設上下限，僅要求為正數 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響使用者 Aggregate 欄位定義、「使用者已填入身高 / 體重 / 年齡」對應 Command 的輸入驗證 Precondition、以及 AI 訓練調整流程的計算輸入。

High
