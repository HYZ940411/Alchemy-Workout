# 釐清問題

模型中共有連簽成就、累簽成就、連續訓練成就、累積訓練成就、新手成就、互動成就（四類）、粉絲成就等多種成就，是否共用同一個成就 Aggregate？結構為何？

# 定位

流程：每日簽到流程、補簽流程、訓練結算流程、新手任務流程、發文與互動流程、關注流程
元素：Aggregate：成就（模型中尚未定義）；Event：連簽成就已解鎖、累簽成就已解鎖、連續訓練成就已解鎖、累積訓練成就已解鎖、新手成就已解鎖、互動成就已解鎖、粉絲成就已解鎖
細節：隱含但未明確定義的 Aggregate（D1）；Aggregate 邊界與命名（D1）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 單一成就 Aggregate，含類型 / 門檻 / 獎勵 / 解鎖狀態，各類成就僅為類型不同 |
| B | 單一成就定義 Aggregate 加上「使用者成就解鎖紀錄」Aggregate，兩者分離 |
| C | 依類別拆為簽到成就 / 訓練成就 / 社群成就三個 Aggregate |
| D | 不建立成就 Aggregate，各流程各自維護解鎖旗標 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響成就 Aggregate 的結構與數量、七個成就解鎖 Event 是否可合併為單一「成就已解鎖」Event、成就門檻是否可由管理員設定、以及各成就的重複解鎖與撤銷規則一致性。
