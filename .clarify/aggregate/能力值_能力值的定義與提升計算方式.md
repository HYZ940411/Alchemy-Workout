# 釐清問題

「能力值」的定義為何？是單一數值還是分部位 / 分項目的多維數值？每次訓練後如何計算提升幅度？

# 定位

流程：訓練結算流程、訓練中斷流程、新手任務流程
元素：Aggregate：能力值（模型中尚未定義，卻被三條流程改動）
細節：隱含但未明確定義的 Aggregate（D1）；欄位定義與衍生公式（D2、D3）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 單一總能力值 int，依訓練總量（重量 × 次數 × 組數）換算提升 |
| B | 分肌群多維能力值（胸 / 背 / 腿 / 肩 / 手 / 核心），依動作所屬肌群分別提升 |
| C | 分訓練屬性（力量 / 耐力 / 爆發），依動作類型分別提升 |
| D | 單一總能力值，但依動作難度係數加權計算 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響能力值 Aggregate 的結構、能力值已提升 / 已退步兩個 Event 的 Postcondition、動作 Aggregate 是否需肌群或屬性欄位、以及階級提升與 AI 優化訓練的計算基礎。
