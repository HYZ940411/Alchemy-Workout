# 釐清問題

「團隊日常分數」與「團隊限時分數」的計算公式各為何？兩者是獨立排行榜還是可合併？

# 定位

流程：團隊組隊任務流程
元素：Aggregate：團隊日常分數、團隊限時分數；Rule / Policy：成員完成訓練 / 社群互動 → 累計團隊日常分數
細節：衍生欄位公式（D3）；Aggregate 邊界（D1）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 日常分數 = 全體成員個人排行榜分數加總；限時分數 = 完成限時任務的成員數 × 固定分 |
| B | 日常分數依成員完成訓練 / 社群互動次數計固定分，與個人分數脫鉤；限時分數同理 |
| C | 兩者皆依人均計算（總分 / 成員數），避免大團隊優勢 |
| D | 兩者為同一分數，僅來源不同，應合併為單一「團隊分數」與單一排行榜 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響兩個團隊分數 Aggregate 的欄位與公式、對應 Event 的 Postcondition、日常與限時兩個排行榜是否需分開維護、以及排行榜週期結算流程的三種獎勵發放。
