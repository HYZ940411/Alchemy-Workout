# 釐清問題

模型中存在多組術語不一致（追蹤 vs 關注、分享的兩種語意、管理員的兩種角色、中斷的兩種語意、能力值 vs 經驗值 vs 分數），是否應建立標準術語詞彙表？

# 定位

流程：全流程
元素：統一語言詞彙表（F1、F2 檢查項於全模型皆為 Missing）
細節：統一語言（F1）；同義詞混用與同名異義（F2）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 建立獨立的術語詞彙表檔案，列出所有核心概念的標準名稱、定義與已棄用的替代說法 |
| B | 不另建檔案，於事件風暴模型.md 中增設術語章節 |
| C | 建立詞彙表檔案，且各流程檔案中的 Event 名稱一律以詞彙表為準統一改寫 |
| D | 暫不建立，待各項術語衝突逐一釐清後再彙整 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響是否新增術語詞彙表檔案、各流程 Event 名稱的統一改寫、以及後續 Command 與 Aggregate 命名的一致性基準。建議待各項命名衝突釐清後於最後階段一次彙整。
