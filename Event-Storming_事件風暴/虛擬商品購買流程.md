[狀態] ​訂​單​ →​ 待​付​款  
[支付方式] ​虛​擬​貨​幣​ / ​真​實​金​流​ / ​兩​者​併​用（​虛​擬​貨​幣​不​足​時​以​現​金​補​差​額）  
虛​擬​貨​幣​已​扣​除 〔虛擬貨幣＝金幣，站內唯一幣別〕  
[Rule] Precondition：​金​幣​餘​額​扣​除​後​不​得​為​負​值  
使用者​已​支付 〔真實金流〕  
[Rule] Precondition：​併​用​時​，​虛​擬​貨​幣​扣​除​與​真​實​金​流​支​付​須​同​時​成​功​，​方​可​完​成​購​買  
使用者​已​購買虛擬​商品​ 〔交易成立〕  
[狀態] ​待​付​款​ →​ 已​付​款  
[決策] ​「​使用者​已​購買虛擬​商品​」​與​「​商品​已​發放​」​為​兩​個​不​同​事​實，​不​合​併  
[Rule] Precondition：​「​使用者​已​購買虛擬​商品​」​已​發​生，​方​可​發​生​「​商品​已​發放​」  
[決策] ​發​放​可​為​非​同​步，​不​保​證​與​交​易​成​立​在​同​一​時​點  
商品​已​發放 〔道具入庫〕  
[狀態] ​已​付​款​ →​ 已​發​放（​終​止​狀​態）​  
[失敗路徑]  
[分支] ​餘​額​不​足​ / ​商​品​售​完​ / ​其​他​原​因​ → ​購​買​已​失​敗  
購​買​已​失​敗 〔攜帶資訊：失敗原因（餘額不足 / 商品售完 / 其他）〕  
[狀態] ​待​付​款​ →​ 已​失​敗（​終​止​狀​態）​
