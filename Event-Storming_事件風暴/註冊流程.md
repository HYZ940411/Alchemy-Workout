[決策] 承模型否決「平台設定已變更」單一泛用 Event 的同一理由：沒有讀者的 Event 是純粹的成本  
[Rule] 本 Event **不標記為「不需精準追蹤」**（2026-08-11 定案），照常建立 Precondition 與 Postcondition 驗收條件
