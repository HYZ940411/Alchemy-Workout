關注流程
使用者已關注帳號  
[Rule] 關注關係為獨立 Aggregate，欄位含關注者、被關注者、關注時戳  
[Rule] 關注為單向關係，唯一鍵為 關注者 ID ＋ 被關注者 ID  
對方帳號粉絲數已增加  
[Rule] Postcondition：被關注者的粉絲數 +1  
[Rule] 粉絲數為使用者 Aggregate 的儲存欄位，非即時彙總  
[Rule] 不變條件：粉絲數 ＝ 關注關係中被關注者為本人的筆數  
[Policy] 粉絲成就門檻 粉絲數達 10 / 50 / 100 / 300 / 500 / 1000 / 3000 / 5000 / 10000  
粉絲成就已解鎖  
[Rule] 粉絲數下降不撤銷任何已解鎖的粉絲成就  
[決策] 承「使用者成就解鎖紀錄為單調遞增、一經解鎖不可撤銷」的既有原則  
[決策] 不採撤銷：粉絲取消關注為他人的行為，成就會因他人的舉動被拿走  
[決策] 不採「保留成就但回收獎勵」：金幣可能早已花掉，回收將出現負餘額  
[反向操作]  
使用者已取消關注  
對方帳號粉絲數已減少
