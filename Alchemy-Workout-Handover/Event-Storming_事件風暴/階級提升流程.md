階級提升流程
[串聯] 管理員執行「設定階級門檻」導致「管理員已設定階級門檻」— Actor：管理員  
管理員已設定階級門檻  
[Rule] Postcondition：階級數固定，門檻值由管理員於後台調整，存於階級設定 Aggregate  
[Rule] Postcondition：門檻調整不改動任何使用者既有的階級  
[Policy] 階級門檻判定 經驗達門檻升階  
[Rule] Precondition：使用者經驗值達下一階門檻，方可發生「使用者已提升階級」  
[Rule] 階級總數為 99，初始階級為 1，第 99 階為滿等  
[已知取捨] **滿等（約 365 天）後經驗值失去全部用途**，「經驗值已提升」照常發生但不再導致任何後果；**2026-08-20 明示接受，不改動模型**，理由見 02_Aggregate定義.md〈滿等後經驗值失去用途〉  
[Rule] 累計經驗值門檻公式：C(n) ＝ 8,340 × ((n − 1) / 98)²，n 為階級（2–99）  
[Rule] 滿等所需累計經驗值不得低於一般使用者 365 天可取得的累計經驗值  
[Rule] 經驗值數額調整時，階級門檻須同步重新校準，以維持 365 天下限  
[Rule] 管理員調整的是階級總數、滿等累計經驗值、曲線指數三個參數，非 98 個門檻數字  
使用者已提升階級  
[Rule] Postcondition：階級為單調遞增，永不下降  
[Rule] 不變條件：階級為單調遞增，永不下降  
[Rule] 經驗值單調遞增永不減少，故無因經驗值下降而降階的路徑  
[Rule] 不另設獨立於經驗值的降階機制（如久未訓練降階）  
[決策] 階級不下降：經驗值管年資、能力值管實力，退步的職能已由能力值承擔；階級同時下降等於同一件事罰兩次  
[決策] 降階會連帶影響以階級為門檻的進階訓練計畫解鎖與教官初審資格，須處理「解鎖後又失去資格」的連動，複雜度與價值不成比例  
[串聯] 系統執行「解鎖階級成就」導致「階級成就已解鎖」— Actor：系統  
階級成就已解鎖  
[Rule] Precondition：「使用者已提升階級」已發生，且提升後的階級達某一枚階級成就的門檻  
[Rule] 本類成就為全模型第 9 類，共用〈成就 Aggregate〉的統一結構  
[決策] 新增階級成就的理由：階級為模型中最長線的養成（99 階、約一年滿等），但原本連一個里程碑都沒有 —— 僅有一條每次訓練推進不足 1% 的進度條。其理由與新增第 8 類能力值成就時同型：既有類別無一衡量該面向（前 7 類衡量行為次數、第 8 類衡量變得多強、第 9 類衡量投入了多久）  
[決策] 階級的里程碑掛成就而非於結算頁另立呈現區塊：模型中「離散的里程碑」本即由成就承載，另立區塊等同同一件事給兩種呈現  
[Rule] 階級成就共 **5 枚**，門檻為階級 **10 / 25 / 45 / 70 / 99**  
[Rule] Postcondition：獎勵為金幣 100 → 500 遞增，**不給經驗值**  
[決策] 不給經驗值：階級本即由經驗值推動，階級成就再給經驗值將形成「升階 → 得經驗值 → 再升階」的循環  
[決策] 門檻沿用進階訓練計畫與自訂訓練名額的同一組里程碑（10 / 25 / 45 / 70），再加滿等 99  
[Policy] 階級解鎖判定 達對應階級解鎖該階進階計劃  
進階訓練計畫已解鎖  
[Rule] 本 Event 為多對一，三條解鎖路徑共用：階級達標（本流程）/ 金幣購買（虛擬商品購買流程）/ 會員身分（會員訂閱流程）
[Rule] 本 Event 攜帶解鎖方式（階級達標 / 金幣購買 / 會員身分）與所解鎖的訓練計畫 ID
[Rule] Postcondition：本路徑的解鎖方式為階級達標，屬永久取得，不因任何事由回退
[Rule] Precondition：解鎖為冪等狀態：已以任一方式解鎖者再次觸發，不重複產生本 Event
[Rule] 「進階訓練計畫」非獨立 Aggregate，為所需階級欄位有值的訓練計畫  
[Rule] 一個階級可解鎖多個訓練計畫，非一對一關係  
[Rule] 進階計畫不另需會員訂閱即可使用  
[Rule] 並非每一階都解鎖進階訓練計畫，僅指定階級解鎖  
[Rule] 進階計畫的所需階級初始設四個里程碑：階級 10 / 25 / 45 / 70，分散於階級曲線
[Rule] 份數不限定：一個階級可解鎖多份計畫；所需階級為平台級可調參數
[Rule] 不變條件：器材（3）× 健身經驗（3）× 常見目標（4）＝ 36 種組合，每一種皆須至少有一份初階計畫可供推薦
[決策] 不規定初階計畫的份數：份數為內容團隊的產能問題，非建模問題；一份計畫可同時覆蓋多個組合
[決策] 進階計畫不可延後：課表選擇頁的「未解鎖進階計畫一併呈現」為三種解鎖方式的唯一曝光點
