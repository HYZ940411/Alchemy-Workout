# E2E Test 技術架構

## 技術棧

| 面向 | 選擇 |
|------|------|
| 後端框架 | FastAPI |
| 測試框架 | pytest |
| HTTP Client | requests (透過 fixture) |
| 資料庫 | PostgreSQL (Testcontainers) |
| ORM | SQLAlchemy + Repository Pattern |
| Schema 管理 | Alembic |
| 認證 | JwtHelper class |
| 測試隔離 | Truncate tables (每測試後) |
| 變數傳遞 | context dict (fixture) |
| 容器 Scope | Session (PostgreSQL、後端服務) |

## Fixtures 設定

### HTTP Client

```python
@pytest.fixture
def api_client():
    session = requests.Session()
    session.headers.update({"Content-Type": "application/json"})
    session.base_url = os.getenv("API_BASE_URL", "http://localhost:8000")
    
    original_request = session.request
    def request_with_base_url(method, url, **kwargs):
        if not url.startswith("http"):
            url = session.base_url + url
        return original_request(method, url, **kwargs)
    session.request = request_with_base_url
    
    yield session
    session.close()
```

## Repository Pattern

```python
class CartRepository:
    def __init__(self, session: Session):
        self.session = session
    
    def save(self, entity):
        self.session.merge(entity)
        self.session.commit()
    
    def find_by_user_and_product(self, user_id: str, product_id: str):
        return self.session.query(CartItem).filter_by(
            user_id=user_id, product_id=product_id
        ).first()
```
