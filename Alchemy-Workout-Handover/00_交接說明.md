# 健金術 Alchemy Workout —— 交接包

一個健身 App：把訓練轉成看得見的六維能力值，外加階級、成就、排行榜、
師徒制與團隊。Flutter 跨平台，前端幾乎完整，**後端一行都還沒有**。

> 這個檔案不在版控裡，是交接包專用的入口。其餘所有檔案都與原專案的
> git 提交完全一致（`git log` 有兩筆歷史，可直接接著做）。

---

## 先做這三件事

**1. 讀 [`PROGRESS.md`](PROGRESS.md)**

完成了什麼、還差什麼、哪些一定要人手動做、哪些能交給 Claude Code，
全在那一份裡。待辦項目都有穩定編號（`BE-` 後端／`DEP-` 部署／`QA-` 檢查）。

**2. 先看得到東西，再談改程式**

不必先裝 Flutter。解開 `可直接執行/健金術-web.zip`，用任何本機
HTTP 伺服器開起來就能玩（**不能用 `file://` 直接開**）：

```bash
unzip 健金術-web.zip -d web && cd web && python3 -m http.server 8000
# 瀏覽器開 http://localhost:8000
```

**3. 要動程式碼才裝環境**

需要 **Flutter 3.44.1 stable**、Dart SDK `^3.12.1`。版本漂移會讓上千個
測試一起紅 —— 先確認版本再查 bug。

**這個資料夾不要改成中文名稱，也不要放進含中文的路徑。**
Flutter 的分析伺服器處理非 ASCII 路徑會崩潰（`FormatException:
Unterminated string`），`flutter analyze` 直接跑不起來。細節見
`PROGRESS.md` 第 2 節。

```bash
cd fitness-app
flutter pub get
flutter analyze                 # 應該完全乾淨
flutter test --timeout 90s      # 應該 1,212 passed
```

`--timeout 90s` 不是可選的。沒有它，無窮迴圈會空轉到你以為只是慢。

## 怎麼跟 Claude Code 配合

`CLAUDE.md` 它會自動讀，不用特別叫。開場只要指一下追蹤表：

```
讀 PROGRESS.md，然後告訴我現在該做什麼。
```

要開始做某一項，**用編號**指定（編號穩定，順序不穩定）：

```
讀 PROGRESS.md，開始做 BE-03。
```

做完叫它回寫：

```
BE-03 做完了，更新 PROGRESS.md。
```

勾選規範寫在 `PROGRESS.md` 第 4 節開頭，它會照做：只在行尾補日期，
不改寫任務文字，也不會自己勾掉標【人】的項目。
