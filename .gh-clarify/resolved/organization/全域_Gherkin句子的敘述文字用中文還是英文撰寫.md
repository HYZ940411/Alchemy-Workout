# 釐清問題

Gherkin 檔案裡「那一句一句的描述文字」（例如「使用者的補簽券持有張數為 1」）要用中文寫，還是翻成英文寫？

# 定位

翻譯單元：全部 318 個翻譯單元（283 個 Command ＋ 35 個 Read Model），不限單一 Aggregate。
Gherkin 位置：Given / When / Then 的句子本體（不含關鍵字，關鍵字另有一題）。
對應樣板空格：樣板中每一格「Aggregate、Command、Event、Read Model」被寫成人話的那一段文字。
相關既有共識：`.es-clarify/resolved/aggregate/統一語言_尚未建立標準術語詞彙表.md`（裁決：詞彙表以中文寫在 `00_全域規範.md`，不另建檔）。

# 白話說明

事件風暴模型從頭到尾是中文寫的：Event 叫「使用者已使用補簽券」、Aggregate 叫「補簽券」、
Command 叫「使用補簽券」。現在要把這些翻成 Gherkin，第一個要決定的是**句子要用哪種語言**。

選 A（中文句子）會長這樣：

```gherkin
Rule: 業務規則驗證
  Scenario: 補簽券張數不足時無法補簽
    Given 使用者（U001）的補簽券持有張數為 0
    When 使用者（U001）使用補簽券回補 2026-08-20
    Then 操作失敗
    And  使用者（U001）的補簽券持有張數仍為 0
```

選 B（英文句子）會長這樣：

```gherkin
Rule: Business rule validation
  Scenario: Cannot make up attendance without a ticket
    Given the user (U001) has 0 makeup tickets
    When the user (U001) uses a makeup ticket for 2026-08-20
    Then the operation fails
    And  the user (U001) still has 0 makeup tickets
```

差別在於：選 B 的每一個名詞都要先決定英文譯名（補簽券 = makeup ticket？retro check-in pass？），
而模型裡沒有任何一份中英對照表。

# 多選題

| 選項 | 描述 | 推薦 |
|------|------|------|
| A | 句子全部用中文，名詞逐字沿用 `00_全域規範.md`〈統一語言：已定案術語〉的中文原名 | ★ |
| B | 句子全部用英文，另外建立一份中英對照表，模型裡每個名詞都指定英文譯名 |  |
| C | 句子用英文，但保留中文名詞（例如 `Given the user (U001) has 0 補簽券`） |  |
| Short | 提供其他簡短答案（<=5 字） |  |

# 推薦選項與理由

**推薦 A（全中文句子）。**

Gherkin 的設計目的是「讓不寫程式的人也能讀懂規格」，所以業界通例是**用團隊日常溝通的語言撰寫**，
而不是一律用英文——這是 Gherkin 本身支援 70 多種語言的原因。本專案的模型、釐清紀錄、
決策理由全部是中文，翻成英文等於為所有讀者多加一層翻譯。

本專案另有一條具體證據支持 A：`.es-clarify/resolved/aggregate/統一語言_尚未建立標準術語詞彙表.md`
的裁決是「**不另建獨立詞彙表檔案**，於 `00_全域規範.md` 擴充統一語言章節」，理由是
「另開檔案會使術語定義散在兩處，反而更難維護」。選 B 等於必須另建一份中英對照表——
正是該裁決明確否決過的做法，且這次要對照的名詞遠多於當時（65 個 Aggregate、283 個 Command）。

不推薦 C：中英混寫的句子讀起來兩邊都不順，且沒有任何一方得益。

# 各選項的翻譯後果

| 選項 | Feature 檔數 | Scenario 條數 | 維護成本 |
|------|-------------|--------------|----------|
| A | 318（不受本題影響） | 不受本題影響 | 最低。名詞直接抄模型，改名時 grep 中文原名即可全數找到 |

| C | 318（不受本題影響） | 不受本題影響 | 中。省下名詞翻譯，但句型仍需英文語感審閱 |

# 影響範圍

影響**每一個** Feature File 的每一行句子。這一題不先定案，後續任何一批翻出來的檔案都要整批重寫。
連帶決定：`.gh-clarify/organization/全域_Gherkin關鍵字用中文還是英文.md`（關鍵字語言）、
`.gh-clarify/organization/全域_FeatureFile的檔名用中文還是英文.md`（檔名語言）、
`.gh-clarify/organization/全域_模型術語過長時Gherkin句子是否縮寫.md`（縮寫規則）。
