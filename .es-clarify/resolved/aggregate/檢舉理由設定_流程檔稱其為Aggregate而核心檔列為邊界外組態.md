# 解決結果

**選項 A**：補為正式 Aggregate，補入〈獨立 Aggregate 清單〉（62 → **63**），
**維持於〈平台級設定的軟體邊界〉右欄**（不建 Command 與 Event）。

- 欄位：理由項目 ID、理由名稱、適用對象類型（貼文 / 留言 / 帳號 / 私訊）、是否啟用、顯示順序。
- 本表為〈檢舉 Aggregate〉「理由」欄位的值域來源。
- **停用而非刪除**：既有案件仍指涉該理由項目，刪除會使歷史案件指向不存在的 ID。
- 值域調整不改動任何既有檢舉案件，承既有規則。

**本題確立的判準**：「留在軟體邊界之外」與「是否需要 Aggregate」是**兩個問題**。
〈平台級設定的軟體邊界〉右欄處理的是**是否建 Command 與 Event**；
同在右欄的帶徒上限設定與教官專長設定皆為完整定義的 Aggregate 且列於清單中。
既有先例：同在右欄的「器材明細值域」已於 2026-08-20 改為〈器材設定 Aggregate〉並補入清單。
