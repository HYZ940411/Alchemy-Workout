# 釐清問題

六維能力值的「相對強度係數」機制已定案（每個動作一個係數，換算至該肌群的標準化 1RM），但六個肌群各自的錨點動作（係數 1.0 者）尚未指定，其餘動作的初始係數亦未給定。這些數值是否於上線前定案，或以暫定值上線、日後用自家資料校準？

# 定位

流程：訓練紀錄流程、AI 訓練前/中調整流程（預帶重量與能力值判定皆依賴此係數）
元素：Aggregate「動作」的〈相對強度係數〉子節
細節：`00_全域規範.md`〈動作的相對強度係數〉明文「初始值之後以自家資料校準，非上線阻擋」，但完全未給出任何一個肌群的錨點動作或任何動作的初始係數，等級判定與快照預帶重量皆直接依賴此值。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 上線前由管理員／內容團隊依訓練學常識給定六個錨點動作與主要動作的初始係數，作為平台級可調參數（**推薦**：模型已明文「非上線阻擋」，但若完全空白，等級判定與預帶重量在上線當下即無法運作，至少需要一組可用的起始值） |
| B | 上線時六維各自僅開放錨點動作（係數 1.0），其餘動作暫不開放能力值計算，待係數校準後再逐一開放 |
| C | 延後至重跑本次 discovery 之後的下一輪再處理，本階段僅記錄為已知缺口 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響能力值提升公式（標準化 1RM 的計算）、快照預帶重量（採同一組肌力標準）、AI 調整安全上限（重量絕對上限以估算 1RM 為錨點）。若無初始值，這三處在上線當下皆無法實際運算。

# 優先級

High

# 解決結果

選項 A（採用）：上線前由團隊依訓練學常識給定六個錨點動作，其餘動作係數之後補齊、上線後校準。

六個肌群的錨點動作最終定案：
- 胸：槓鈴臥推
- 背：**高位下拉**（原提議硬舉，經使用者質疑後改為高位下拉——硬舉同時吃重腿部與下背，非純背部動作；高位下拉較單純訓練背闊肌，且公開肌力標準資料庫亦有收錄）
- 腿：槓鈴深蹲
- 肩：站姿槓鈴肩推
- 手：槓鈴彎舉
- 核心：負重繩索捲腹（Cable Crunch）（原提議「負重捲腹」過於籠統，查證後改為 Cable Crunch，是少數在公開肌力標準資料庫中實際列出重量標準的核心動作）

其餘動作（如上斜啞鈴臥推、腿推、引體向上等）的初始係數，由內容團隊於上線前依訓練學常識逐一給定，非上線阻擋。
