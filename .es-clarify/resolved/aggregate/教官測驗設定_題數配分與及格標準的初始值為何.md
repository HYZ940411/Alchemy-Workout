# 釐清問題

教官測驗設定 Aggregate 的選擇題題數、簡答題題數、配分方式與及格標準初始值為何？題目為固定或自題庫隨機抽取？

# 定位

流程：教官申請流程
元素：Aggregate「教官測驗設定」；Event「教官資格已通過」的 Precondition
細節：欄位定義（D2）；前置條件完整性（C1）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 選擇題 20 題、簡答題 3 題；雙門檻：選擇題答對 ≥ 80% 且簡答題全數通過；題目自題庫隨機抽取 |
| B | 同 A 的題數，但採總分制（選擇題 70 分 ＋ 簡答題 30 分，總分 ≥ 70 及格）；題目隨機抽取 |
| C | 選擇題 10 題、簡答題 1 題；雙門檻同 A；題目固定不隨機 |
| D | 本階段僅定義設定 Aggregate 的參數欄位，初始值延後至上線前由管理員填入 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響「教官資格已通過」與「教官資格已駁回（測驗階段）」的 Precondition 驗收、教官測驗 Aggregate 的作答紀錄結構，以及重考規則的計算基礎（`rule/使用者已作答教官測驗_可否重考與重考間隔.md`）。

# 解決結果

**選項 A**：選擇題 20 題、簡答題 3 題；雙門檻及格；題目自題庫隨機抽取。

| 參數 | 初始值 |
|------|--------|
| 選擇題題數 | 20 題（隨機抽取） |
| 簡答題題數 | 3 題（隨機抽取） |
| 選擇題及格標準 | 答對 ≥ 80%（≥ 16 題），系統即時判定 |
| 簡答題及格標準 | 全數通過，管理員人工審核 |
| 及格判定方式 | 雙門檻，兩者缺一不可 |

**三項理由**：

1. **雙門檻優於總分制**：模型已定案簡答題由管理員人工審核，其存在理由即為判斷申請者是否真懂訓練原理。
   總分制下選擇題全對（70 分）者可簡答全錯仍及格，人工審核形同虛設，教官資格失去把關意義。
2. **題目必須隨機抽取**：教官申請持續開放，固定題目數週內即會有完整題庫答案流出。
   且隨機抽取是重考機制的前提，否則重考等於重看同一份考卷
   （`rule/使用者已作答教官測驗_可否重考與重考間隔.md` 依賴本項）。
3. **20 ＋ 3 題的鑑別度優於 10 ＋ 1**：選擇題 10 題時 80% 門檻等於只能錯 2 題，一次手滑即落榜；
   簡答題 1 題則過度依賴單一題目的運氣。

**消除三處 Partial**：選擇題題數、簡答題題數、配分與及格標準。
