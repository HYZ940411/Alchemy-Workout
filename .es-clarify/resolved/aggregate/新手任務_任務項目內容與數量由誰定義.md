# 釐清問題

新手任務包含哪些任務項目？數量與內容是固定的、由管理員設定的、還是依註冊資料動態產生？

# 定位

流程：新手任務流程
元素：Aggregate：新手任務
細節：隱含但未明確定義的 Aggregate（D1）、欄位定義（D2）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 全平台固定同一組任務，寫死在系統內，無需 Aggregate |
| B | 由管理員在後台設定任務清單，需要「新手任務範本」Aggregate 與對應的管理員 Command |
| C | 依註冊時填寫的健身經驗與目標動態產生不同任務組合 |
| D | 固定任務組合，但數量依會員身分不同 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響是否需要新增「新手任務範本」Aggregate 與管理員設定流程、「新手任務已指派」的 Postcondition 內容、以及「使用者已完成新手任務」的判定 Precondition。

# 優先級

High

# 解決結果

B — 由管理員在後台設定任務清單，新增「新手任務範本」Aggregate 與管理員 Command。

- 新手任務範本（平台級）：任務項目清單與數量，管理員可調整
- 新手任務（每使用者）：指派給該使用者的任務與完成進度
- 「新手任務已指派」時依當時的範本內容產生
- 範本調整不改動任何已指派的新手任務
- 全平台同一份範本，不依註冊資料或會員身分產生差異（未採 C、D）

新增 Event「管理員已設定新手任務範本」，Actor 為管理員。
