# 釐清問題

每日任務獎勵、分享獎勵、發文獎勵、按讚獎勵、留言獎勵五個來源的初始內容與數量為何？

# 定位

流程：每日任務流程、發文與互動流程
元素：Aggregate「獎勵定義」的內容欄位（平台級）
細節：D2 欄位初始值、C3 數值邊界。

**本批的決策重心為刷分風險**：按讚與留言的執行成本極低（一次點擊），
若給予金幣獎勵，使用者可於數分鐘內對大量貼文按讚換取金幣，而金幣已定案 1 金幣 ＝ 1 元、
可購買虛擬商品與補簽券。模型已有一個待釐清項目正在處理此問題的另一面
（`rule/發文獎勵已發放_互動獎勵是否有每日發放上限.md`），兩者宜併題處理。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 每日任務＝經驗值 20 ＋ 金幣 30（全部完成另加碼）；分享 / 發文＝金幣 10；按讚 / 留言＝金幣 2；並設每日發放上限 |
| B | 同 A 的數額，但按讚與留言**不給金幣**，僅計入互動成就的次數；分享與發文仍給 |
| C | 四種互動皆不給金幣，改給不可交易的道具或稱號，徹底切斷刷分與虛擬經濟的連結 |
| D | 同 A，但不設每日上限，改以「同一貼文只計一次」與「自己的貼文不計」兩條規則防刷 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響 5 個「⋯獎勵已發放」Event 的 Postcondition、金幣的產出端量級、
師徒功能解鎖條件（需集滿關注 / 發文 / 按讚 / 留言 / 分享五個 Event 各一次）的取得難度、
互動成就的門檻合理性（累計 1 / 5 / 15 / 50 / 100 / 250 / 500 / 750 / 1000 次）、
以及取消按讚與刪除留言時的獎勵回收規則。

相依：`rule/發文獎勵已發放_互動獎勵是否有每日發放上限.md`（同一組決策，宜併題）、
`rule/按讚獎勵已發放_取消按讚或刪除留言時獎勵與成就是否回收.md`。
前置：`aggregate/獎勵定義_第一批_訓練與簽到類的獎勵初始值為何.md`（本批數額需對照第一批的量級）。

# 延後（2026-08-03，第五輪第 21 題）

**本項目延後，待使用者重跑 `/es-discovery` 後再回答。**

## 延後理由

本項目的前置為**金幣對法幣比率**，而該比率於本輪確認**不可由獎勵數額或商品價格反推**。

正確的設定順序為：

```
1. 儲值 SKU（花多少錢買多少金幣）→ 決定比率
2. 虛擬道具標價（以儲值為基準）
3. 免費獎勵（設為一筆小額儲值的一小部分）
```

模型現況為反向填入 —— 先有第一批獎勵數額與補簽券售價，比率反而未定。
在比率與儲值 SKU 定案前，本項目的數額無錨點可依循。

詳見 `00_全域規範.md`〈虛擬貨幣經濟的設定順序〉。

## 一併延後的項目

1. 儲值 SKU 面額與贈送規則
2. 金幣對法幣比率
3. 虛擬道具標價的重新校準（含補簽券 150 金幣）
4. 各獎勵來源的金幣數額（第一批複核、第二批、第三批）
5. 實體商品採金幣標價或里程碑兌換
6. **成就獎勵的發放路徑與數額**（獨立於三批之外的缺口）

# 解決結果（2026-08-09，虛擬貨幣群組第 8 題）

## 核心裁決：**社群互動不給金幣，每日任務給金幣**

| 來源 | 金幣 | 每月 |
|------|------|------|
| 每日簽到 | 10／日 | 300 |
| 訓練結算 | 30／次 | 360 |
| **每日任務** | **單項 2 ＋ 全完成加碼 4 ＝ 10／日** | **300** |
| **社群互動（發文 / 按讚 / 留言 / 分享）** | **0 —— 只給經驗值** | 0 |
| **免費月收入合計** | | **約 960** |

## 本題暴露的真正約束

助理原欲直接給數額，計算後發現：
**第 5 題已定「非會員每月約 5 次 AI、會員 20 次」，而免費月收入 660 剛好就是那 5 次。**
每日任務若給 10／項（每月 1,800），總額將達 2,460 →
**非會員每月可買 24 次，比會員的 20 次還多，訂閱直接失效。**

故本題的控制變數不是「給多少才慷慨」，而是
**「非會員與會員的 AI 次數差距要維持多少」**。

| 每日任務 | 免費月收入 | 可買 AI | vs 會員 20 次 |
|---------|-----------|---------|-------------|
| **10／日（採用）** | **960** | 約 9.6 次 | **2.1 倍** |
| 15／日 | 1,110 | 約 11 次 | 1.8 倍 |
| 20／日 | 1,260 | 約 12.6 次 | 1.6 倍 |

**2.1 倍為可接受的最低差距** —— 會員另有四項獨佔權益
（免費自動優化、無限自訂訓練、能力值成長軌跡、月報 AI 分析）。

## 社群互動不給金幣的理由（使用者裁定）

- **社群互動天生難以封頂**：按讚與留言可刷，掛金幣即供給失控，須不斷追加上限規則。
- **金幣來源須為可預測、有上限者**：簽到每日至多一次、訓練獎勵每日上限一次、
  每日任務固定 3 項。
- 各獎勵因此各有角色：**金幣買 AI 與道具、經驗值推階級**
  （階級解鎖自訂訓練名額、進階計畫，並掛第 9 類階級成就）。

**本裁決連帶解決 `rule/發文獎勵已發放_互動獎勵是否有每日發放上限.md`** ——
互動不給金幣，該題的金幣上限問題自然消失（僅餘經驗值是否設上限）。

## 三個不採方案

| 方案 | 為何不採 |
|------|---------|
| 降低簽到與訓練的金幣以挪出空間 | 該二者為最核心的養成迴圈，削減等同弱化平台最希望使用者做的事 |
| 提高 AI 售價以吸收多出的金幣 | AI 漲價將使非會員捨不得用，而「感受到 AI 有用」為付費轉化的前置 |
| 每日任務與社群一律不給金幣 | 使用者裁定每日任務須給 |

## 每日任務的完整獎勵配置

| | 內容 |
|---|------|
| 單項完成 | **2 金幣 ＋ 經驗值** |
| 三項全完成加碼 | **4 金幣 ＋ 經驗值 ＋ 偶爾補簽券** |

補簽券置於「全完成」而非單項：其持有上限 5 張，低頻發放即足，且能推動使用者做完三項。

## 第一批獎勵數額已校準確認

註冊 100、新手任務 100、簽到 10／日、訓練 30／次
—— 以 1 元 ＝ 5 金幣重新檢視後**數額不變**，原「無錨點」的註記已更新。
