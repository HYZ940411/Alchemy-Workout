# 釐清問題

「有氧的訓練量計算」（實際時長 × 每分鐘訓練量係數）原本的用途是餵給經驗值與個人排行榜分數兩處。但個人排行榜分數已於第九輪重寫為完成度制（固定分 × 完成度係數 × 課表來源係數），不再依訓練量計算。與此同時，模型另有一處明文寫著「能力值、經驗值、個人排行榜分數三者一律依實際訓練量計算」（`00_全域規範.md` 訓練獎勵金幣完成度差額一節），與排行榜分數改採完成度制的事實矛盾。這條係數與「訓練量」這個概念在經驗值計算中是否仍然被使用，需要複核。

# 定位

流程：訓練結算流程
元素：Aggregate「動作」的〈有氧的訓練量計算〉子節；Aggregate「訓練紀錄」總訓練量欄位；Rule「訓練獎勵金幣的完成度差額」
細節：`00_全域規範.md` 訓練紀錄 Aggregate 的不變條件仍將「每分鐘訓練量係數」用於計算「總訓練量」（一個仍被儲存、於訓練歷史呈現的欄位），故此係數並非完全失去用途；但「經驗值是否仍依訓練量計算」與排行榜分數已切換為固定值制的事實是否矛盾，需要覆核並給出係數數值。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 「總訓練量」欄位維持依實際訓練量計算（供訓練歷史呈現、動作趨勢統計），經驗值與排行榜分數皆已（或應）改為固定值制，「三者一律依訓練量計算」的舊敘述需訂正為僅指總訓練量欄位；每分鐘訓練量係數的數值另行給定（**推薦**：符合排行榜已改完成度制、經驗值訓練結算已是固定 30 的既有事實，只需訂正舊敘述並給一個係數數值供「總訓練量」呈現用） |
| B | 有氧不再計算「訓練量」這個概念，總訓練量欄位對有氧恆為 0 或不適用，僅重訓動作有總訓練量 |
| C | 經驗值計算亦一併改採完成度制或固定值制，此係數與訓練量概念自模型中整段移除 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響訓練紀錄 Aggregate 的「總訓練量」欄位定義、訓練歷史的呈現內容、`00_全域規範.md`〈訓練獎勵金幣的完成度差額〉一節中已與事實不符的敘述。

# 優先級

Medium

# 解決結果

**選項 A**：「總訓練量」降級為**純呈現用的統計數值**，不再餵給任何計分機制。

| 曾經的讀者 | 現況 |
|-----------|------|
| 能力值 | 已改採估算 1RM ＋ DOTS，不再讀取訓練量 |
| 個人排行榜分數 | 已改採完成度制，不再讀取訓練量 |
| 經驗值 | 訓練結算固定 30，本即未讀取訓練量 |
| 〈Read Model：訓練歷史〉訓練清單 | **唯一讀者** |

保留而不移除：使用者確實會想知道「今天練了多少量」，訓練歷史需要一個可跨時間縱向比較的
量化指標。但本欄位已無精度要求，不得再作為任何計分依據。

**每分鐘訓練量係數的數值另立一題處理**（使用者指示「有氧再問一題」）——
其相依已消失（不再需要與排行榜換算率校準），僅影響顯示數字。

# 本題連帶查出並訂正的兩處過期敘述

1. **`00_全域規範.md`〈獎勵定義〉規則區**：「訓練結算的能力值已提升⋯由能力值提升公式計算
   （本次該肌群訓練量 ÷ 該肌群基準訓練量 × 基準提升點數 × 遞減報酬係數）」——
   括號內為**已作廢的訓練量公式**，已訂正為現行的 Epley ＋ DOTS 路徑。
2. **`00_全域規範.md`〈訓練獎勵金幣的完成度差額〉**：「能力值、經驗值、個人排行榜分數
   三者一律依實際訓練量計算，**不受終止 Event 類型影響**」——
   該句於兩處與事實不符：① 能力值與排行榜分數皆已不讀訓練量；
   ② **個人排行榜分數恰恰受終止 Event 類型影響**（其計分式即含完成度係數 100/70/100/50），
   與原句所述完全相反。已改寫為四個指標與終止 Event 類型關係的對照表。
