# 釐清問題

補簽券 Aggregate 的取得來源、持有上限與有效期限為何？

# 定位

流程：補簽流程
元素：Aggregate：補簽券（由 Event「使用者已使用補簽券」推導，模型中尚未定義）
細節：隱含但未明確定義的 Aggregate（D1）、欄位定義（D2）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 僅能以虛擬貨幣在商城購買，無持有上限與有效期限 |
| B | 可由簽到成就、任務獎勵取得，持有上限 5 張，無有效期限 |
| C | 可由獎勵取得亦可購買，持有上限 5 張，取得後 30 天內有效 |
| D | 僅會員訂閱者每月配發固定張數，不可購買，當月未用作廢 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響是否需新增補簽券 Aggregate 與相關 Event（補簽券已取得 / 已到期）、虛擬商品購買流程的商品品項、會員權益內容、以及使用者已使用補簽券的 Precondition。

# 優先級

High

# 解決結果

B（含第 38 題之使用者更正） — 補簽券可由簽到成就、任務獎勵取得，**亦可以金幣購買**，
持有上限 5 張（購買亦受此上限限制），無有效期限，不新增「補簽券已到期」Event。

**更正紀錄**：本題原答為「不可購買」。使用者於第 38 題表示
「剛剛 37 我沒看到你說不能購買，但應該要可以用金幣購買」，故更正取得來源。

# 連帶影響

- 補簽券為獎勵內容之一，屬第 30 題「獎勵定義」Aggregate 的道具類資源。
- 補簽券為虛擬商品品項之一，可用金幣購買，與 `aggregate/虛擬貨幣`（金幣）直接關聯。
- `rule/使用者已使用補簽券_同一次中斷可否使用多張補簽券.md`：
  第 36 題已定「補簽券使用後中斷前連續天數清空為 0」，一次中斷只需一張券即完成回復，
  該題的實質空間已大幅收斂，提問時須帶入此前提。已於該項目加註。
