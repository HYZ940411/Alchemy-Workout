# 解決結果

**A**：本輪實算給定。**基準值 ＝ 27.6、映射係數 ＝ 23.6**（平台級可調參數）。

- DOTS 官方多項式係數經查證（非憑記憶）：男性 a=−0.0000010930、b=0.0007391293、
  c=−0.1918759221、d=24.0900756、e=−307.75076；DOTS 係數 ＝ 500 ÷ (a·bw⁴＋b·bw³＋c·bw²＋d·bw＋e)。
- 以 **80kg 男性、錨點動作槓鈴臥推（相對強度係數 1.0）** 為基準人，
  取 E 底（0.5× 體重 → 0 點）與 A 底（1.0× 體重 → 650 點）反解：
  基準值 ＝ 40 × 0.6895 ＝ 27.6；映射係數 ＝ 650 ÷ (55.16 − 27.58) ＝ 23.6。
- **六個錨點實算後全數落在正確的等級區間**（E 0 / D 130 / C 325 / B 487 / A 650 / S 975），
  〈為何需要基準值〉的主張至此由實數驗證。

**計算過程中另發現兩件事：**

1. `[已知缺口]` 999 於 **1.27× 體重**即觸頂，S 級三個小節點壓縮於 1.20×–1.27× 的窄帶；
   方向與既有裁決一致但比原先設想更早發生，列為上線後的觀察項目。
2. `[待釐清]` **體重倍數錨點不具跨體重與跨性別一致性**（同樣 1.0× 體重：男 60kg 543、
   男 80kg 650、男 100kg 801、女 60kg 917、女 80kg 頂至 999）——
   已另建釐清項目 `aggregate/能力值_錨點以體重倍數表達在DOTS下不具跨體重與跨性別一致性.md`。
