# 釐清問題

能力值提升公式的最後一步為「× 映射係數 → 0～999 的點數」，該係數的用途為「將 DOTS 分數的量級對齊六階門檻」，已定為平台級可調參數，但**數值從未給定**。沒有這個數值，整條計算鏈的前三步（Epley 估算 1RM → 相對強度係數 → DOTS 正規化）雖皆可運算，但最終算不出點數，六階等級判定亦無從成立。

# 定位

流程：訓練結算流程
元素：Aggregate「能力值」之〈能力值提升公式〉
細節：`00_全域規範.md`〈能力值提升公式〉的參數表僅寫「映射係數｜平台級可調參數；將 DOTS 分數的量級對齊六階門檻」，未給任何初始值；六階門檻（E 0–99 / D 100–249 / C 250–449 / B 450–649 / A 650–849 / S 850–999）已給定，故本係數的值等同決定「什麼樣的實力對應什麼等級」。

# 本項目的由來

2026-08-11 第 10 題後，使用者詢問「目前的能力值是怎麼計算的」，助理逐步說明計算鏈時發現本缺口。
**本項為第十輪 discovery 的漏網之魚**：該次掃描已將「相對強度係數初始值」與「六階門檻」
分別歸類為缺口與已給定，但未檢查映射係數，故未建為釐清項目。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 以一組典型使用者的實測資料反推：先設定「什麼樣的人應該落在哪一階」（如一般成年男性初學者落在 E～D、規律訓練 1 年者落在 C、健力比賽選手落在 S），再回推係數（**推薦**：六階門檻的設計意圖已明文為「E 為剛開始、D 與 C 為早期回饋、B 為中期、A 為長期、S 為最終目標」，映射係數的唯一職責就是讓真實的人落在符合該意圖的位置；由目標分佈反推是唯一能驗證這件事的方法） |
| B | 直接由 DOTS 分數的理論範圍線性對應至 0–999（如 DOTS 滿分約 600 → 係數約 1.67），不參考真實分佈 |
| C | 上線初期設一個暫定值，累積自家資料後以百分位校準（承既有裁決「初期由平台設定絕對門檻，累積自家資料後以百分位校準」） |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響能力值點數的實際數值、六階等級判定、能力值成就的解鎖時點（12 枚，門檻為 D 級與 B 級）、綜合能力等級、〈Read Model：六維能力值雷達圖〉與〈訓練結算頁〉的呈現。與 `resolved/aggregate/能力值_各動作相對強度係數初始值與各肌群錨點動作的指定.md`（2026-08-11 解決）同為「算法已定、參數未給」的同類缺口，建議一併校準。

# 解決結果

**選項 A（由目標分佈反推）＋ 兩項結構性修正。**

## 一、映射式由純比例改為仿射式（新增「基準值」參數）

**點數 ＝ min(999, (DOTS 正規化分數 − 基準值) × 映射係數)**

使用者追問「A 是什麼意思」時，助理實際試算後發現**原式在數學上做不到**：

純比例映射會等比例放大、**不改變兩人之間的倍數關係**，而

| | 倍數 |
|---|---|
| 未訓練者 vs 頂尖者的單項 1RM 差距 | 約 3～5 倍 |
| 六階門檻要求的點數差距（E 0–99 至 S 850–999） | 9 倍以上 |

5 倍的輸入撐不出 9 倍的輸出，兩邊必有一邊落空。加入基準值把起點平移至 0 附近後，
倍數關係即可撐開，**六階門檻與 18 個小節點皆不需改動**。
（不採「重新設計六階門檻」——門檻已被成就與多個 Read Model 引用，改動成本高於加一個參數。）

## 二、錨點分佈：這把尺為「持續訓練的一般人」而設

使用者給出產品理念：「**主要目的是讓使用者感覺到進步的回饋，進而培養內在運動習慣**」，
並兩度要求把錨點下調（先是「老手就可以算 S」，再是「規律練一年最好看到 A」）。

| 等級 | 錨點動作 1RM | 大致對應 |
|------|-------------|---------|
| E | 約 0.5× 體重 | 完全未訓練 |
| D | 約 0.6× | 練 1–2 個月 |
| C | 約 0.75× | 練 3–6 個月 |
| B | 約 0.875× | 練 8–10 個月 |
| **A** | **約 1.0×** | **規律訓練一年** |
| S | 約 1.25× 以上 | 一年半～兩年 |

以體重倍數表達（DOTS 已正規化體重與性別，故對男女與各體重皆適用）。
低階門檻密集恰好對上新手紅利期的快速進步，平均每 2–3 週即有一次小節點變化。

## 三、`[已知缺口]` 兩年後核心數值失去回饋作用（明示接受）

使用者反問「以產品理念來看，這樣的錨點是否會讓使用者逐漸獲得成就感與成長」，
助理據此推算完整時間軸，發現**前一年極佳、第二年變慢、兩年後完全失效**：

| 機制 | 耗盡時點 |
|------|---------|
| 階級（99 階） | 約 12 個月 |
| 成就（9 類） | 有限集合 |
| 能力值 | 約 24 個月頂到 999 |

兩年後仍運作的回饋只剩排行榜與連續訓練天數，與〈連續簽到的第 30 天斷崖〉為同型問題。

**使用者選甲：明示接受，不於本階段處理。**
不採「S 往上推延後斷崖」（犧牲前一年的回饋密度去照顧兩年後的少數人）、
不採「移除 999 硬截斷改開放區間」（推翻既有裁決）、
不採「另立長線機制」（範圍擴張）。
理由：現在為第 3 年的使用者設計會犧牲第 1 年的品質，而第 1 年才決定產品能否存活。
**本缺口列入上線後的觀察項目。**

## 仍未給定

**基準值與映射係數的實際數值**：須以真實的 DOTS 公式代入上表錨點反推。
