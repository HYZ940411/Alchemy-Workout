# 釐清問題

「教官聲望已變動」的計算公式為何？聲望是否可能下降？下降時帶徒上限是否隨之降低？

# 定位

流程：師徒互動流程
元素：Aggregate：教官聲望（模型中尚未定義）；Event：教官聲望已變動；Policy：聲望達門檻 → 提升帶徒上限
細節：隱含但未明確定義的 Aggregate（D1）；衍生欄位公式（D3）；單調遞增與可逆性（C4）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 聲望由學徒評分累計而成，可上升亦可下降；帶徒上限依當前聲望動態調整 |
| B | 聲望由學徒評分累計，可上升亦可下降；但帶徒上限一經提升不再降低（單調遞增） |
| C | 聲望僅累加不扣減（評分僅決定加多少），帶徒上限單調遞增 |
| D | 聲望為學徒評分的平均值，可升可降；帶徒上限依平均分與帶徒總數共同判定 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響教官聲望 Aggregate 的欄位與計算公式、教官聲望已變動的 Postcondition、教官帶徒上限已提升的 Precondition 與可逆性、以及是否需要「帶徒上限已降低」Event。

# 優先級

High

# 既有約束（來自已解決項目）

第 12 題（`resolved/event/使用者已成為教官_教官資格撤銷的Event缺失.md`，選項 A）已裁決：
教官資格僅由管理員因違規撤銷，**聲望低於門檻不觸發自動撤銷**。
故本題只需定義聲望的計算與可否下降，不需定義撤銷門檻。

# 解決結果

B-2 + 地板值（追問兩輪後收斂） —

| 學徒評分 | 聲望變動 |
|----------|----------|
| 1 星 | −2 |
| 2 星 | −1 |
| 3 星 | +1 |
| 4 星 | +2 |
| 5 星 | +3 |

- 聲望可升可降，由評分直接加減，不使用低分次數計數器
- 聲望點數地板值為 0，不為負值
- 帶徒上限單調遞增，聲望下降時不隨之降低
- 因上限不降，不需「帶徒上限已降低」Event，亦無既有師徒關係超出上限的情境

# 討論紀錄

使用者初次提出的公式為「1~5 星各給 1~5 點聲望；累計 3 次 1 星扣 5 分、
累計 3 次 2 星扣 3 分」，並主動詢問邏輯是否正確。經檢算指出三個問題：

1. 3 次 2 星淨值為 +3（+6 − 3），**差評反而加分**，該規則無懲罰效果。
2. 「累計 3 次」的計數器扣分後是否歸零未定義，不歸零則懲罰只生效一次。
3. 計數為永久累計或週期累計未定義，永久累計會使資深教官早年扣完後不再受罰。

使用者改採 B-2（直接加減分），免除計數器與重置規則。

**後續更正（第 47 題提問時）**：使用者將 3 星由 0 改為 **+1**，
即 3 星（中性評價）仍給予少量正向回饋，僅 1~2 星為扣分。

隨後使用者詢問「扣分讓教官不爽有什麼方法緩解」，經說明後選擇加上地板值，
並將顯示層做法記入 Read Model 項目待第 5 階段定案。
