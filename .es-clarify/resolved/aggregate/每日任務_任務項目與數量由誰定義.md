# 釐清問題

每日任務的項目內容與每日數量由誰定義？是全平台統一、管理員設定，還是依使用者狀態動態產生？

# 定位

流程：每日任務流程
元素：Aggregate：每日任務（模型中尚未定義）
細節：隱含但未明確定義的 Aggregate（D1）；欄位定義（D2）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 全平台統一固定任務組合，寫死於系統 |
| B | 由管理員在後台設定任務池，每日隨機抽取固定數量指派 |
| C | 依使用者的訓練計畫與社群活躍度動態產生個人化任務 |
| D | 固定任務組合，但會員訂閱者有額外任務可獲得更多獎勵 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響是否需新增每日任務 Aggregate 與管理員設定流程、每日任務進度已更新的 Postcondition、每日任務已完成的判定 Precondition、以及每日任務已重置的重新指派邏輯。

# 優先級

High

# 解決結果

B — 由管理員在後台設定任務池，每日隨機抽取固定數量指派。

- 每日任務池（平台級）：可抽取的任務項目清單，管理員可調整
- 每日任務（每使用者）：當日指派的任務與進度
- 任務池調整不改動任何使用者當日已指派的任務
- 全平台同一個任務池，不依使用者狀態或會員身分產生差異（未採 C、D）

新增 Event「管理員已設定每日任務池」，Actor 為管理員。

**Partial**：每日抽取的數量未給定。提問時已聲明未說明即記為 Partial，使用者僅回答選項代號。

# 結構一致性

與成就定義、獎勵定義、階級設定、新手任務範本採同一模式（平台級可調參數獨立）。
