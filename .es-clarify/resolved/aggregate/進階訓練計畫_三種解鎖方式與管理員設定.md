# 釐清問題

進階訓練計畫由什麼解鎖 —— 階級、會員身分，還是兩者？解鎖條件是否由管理員於後台維護？
以金幣購買時走哪一條購買路徑？

# 定位

流程：會員訂閱流程、訓練紀錄流程（選擇訓練課表）、虛擬商品購買流程
元素：訓練計畫 Aggregate 的解鎖條件；商品 Aggregate 的虛擬商品子類型
細節：模型內部矛盾裁決（`overview.md` §4.1）。
阻擋：`read-model/課表選擇頁_選擇訓練課表前需看到哪些資訊.md`、
`aggregate/會員權益_權益項目的初始清單為何.md` 的甲 / 乙 / 丙選項。

# 矛盾點

| 出處 | 說法 |
|------|------|
| `00_全域規範.md`〈訓練計畫 Aggregate〉 | 由**階級**解鎖，且明寫「進階計畫不另需會員訂閱即可使用」 |
| 第 66 題（會員權益已生效）的裁決 | 「權益失效，**進階計畫鎖定**但資料保留」→ 隱含由**會員身分**解鎖 |

# 多選題

| 選項 | 描述 |
|--------|-------------|
| 甲 | 訓練計畫新增「需會員」布林欄位，與所需階級各自獨立，可組合四種計畫 |
| 乙 | 會員專屬計畫另立一組，與階級解鎖的進階計畫互不重疊 |
| 丙 | 所有進階計畫一律改為需會員 |
| 丁 | 維持純階級解鎖，判定第 66 題那句為誤植並更正 |

# 影響範圍

影響訓練計畫 Aggregate 的欄位與規則、商品 Aggregate 的虛擬商品分類、
虛擬商品購買流程的發放語意、會員權益清單的候選項目、以及 Read Model「課表選擇頁」
呈現「已解鎖 / 未解鎖」與未解鎖原因的欄位設計。

# 優先級

High

# 解決結果

**使用者提出四選項以外的答案：三種解鎖方式並存（OR 關係）。**

| # | 解鎖方式 | 生效期間 | 判定依據 |
|---|----------|----------|----------|
| 1 | 階級達標 | **永久** | 使用者現階級 ≥ 該計畫的所需階級 |
| 2 | 金幣提前購買 | **永久** | 該計畫在使用者的已購買清單中 |
| 3 | 會員身分 | **續約生效**，權益失效即回退 | 會員權益生效中 |

- 方式 3 一次解鎖全部進階訓練計畫，不逐份指定。
- 方式 1 為推導值不另存（階級已定案單調遞增、永不下降）。
- 方式 2 須記錄已購買計畫清單，永久保存；不要求階級達標，用途正是提前解鎖。

## 矛盾的收斂結果

第 66 題「權益失效，進階計畫鎖定但資料保留」的**適用範圍收斂為「僅靠會員身分解鎖者」**，
非全部進階計畫。以階級或金幣取得者於權益失效後維持解鎖。

既有規則「進階計畫不另需會員訂閱即可使用」已刪除，由上表取代（方式 1、2 仍不需訂閱）。

## 管理員後台維護（使用者答「是」）

- 所需階級與解鎖金幣價格皆由管理員於後台維護，與既有的「各階級對應解鎖哪些計畫的清單」
  同屬平台級可調設定。
- 調整所需階級不影響已解鎖者（承快照脫鉤原則）。
- 調整解鎖金幣價格不追溯已購買訂單，不補差額亦不退款。
- 解鎖金幣價格設為空值者改為不可購買，已購買者不受影響。

## 金幣購買路徑（選項 A）

**複用既有〈虛擬商品購買流程〉**，將可購買的進階計畫建為虛擬商品。

- 理由：該流程已含「金幣不足時以現金補差額」，使進階計畫直接成為變現路徑；
  走獨立 Event（選項 B）則金幣不足須先跳出儲值，轉換率下降。
- 商品 Aggregate 新增「虛擬商品子類型」（消耗品 / 權限解鎖）與「解鎖標的」兩欄位。
- 權限解鎖類不適用庫存，不產生「商品已售完」。
- 「商品已發放」＝將解鎖標的寫入已購買計畫清單。
- Precondition：已以方式 1 或 2 永久取得者不得重複購買；僅以方式 3 取得者仍可購買。
- **已知代價（使用者已接受）**：管理員須於商品後台與訓練計畫後台兩處維護同一份計畫，
  以解鎖標的欄位綁定。
