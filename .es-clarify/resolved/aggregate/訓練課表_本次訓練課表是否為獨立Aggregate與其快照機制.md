# 釐清問題

「使用者已選擇訓練課表」所選定的「本次訓練課表」是否為獨立 Aggregate？AI 微調「僅本次訓練、不影響課表範本」的隔離，是以快照達成或以引用＋差異達成？

# 定位

流程：訓練紀錄流程、AI 訓練前調整流程、AI 訓練中調整流程、AI 自動優化訓練流程
元素：Aggregate（尚未定義）；Event「使用者已選擇訓練課表」「AI 已微調訓練強度」「AI 已調整訓練」
細節：Aggregate 識別與邊界（D1）；Aggregate 間關係（D4）；Event → Aggregate 一致性（E3）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 新增獨立「本次訓練課表」Aggregate：開始訓練時自訓練計畫 / 自訂訓練 / 空白課表複製快照，AI 微調僅改快照 |
| B | 不新增 Aggregate，本次課表為訓練紀錄 Aggregate 的一部分，AI 微調直接改訓練紀錄的計畫組數 |
| C | 不新增 Aggregate，以「引用來源課表 ID ＋ 本次差異清單」表達，不做完整複製 |
| D | AI 微調直接改來源課表（訓練計畫 / 自訂訓練），「僅本次訓練」的既有邊界描述作廢 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響三條 AI 流程的「作用範圍」邊界是否可驗收、訓練進度條的「總計畫組數」欄位歸屬、
「使用者已完成訓練」的判定依據、以及獨立 Aggregate 清單（`00_全域規範.md`）是否新增一項。
本項為新掃描發現，非承接 `pending-gaps.md`。與 `aggregate/訓練計畫_訓練計畫與自訂訓練的動作與組數結構為何.md` 宜併題處理。

# 解決結果

**選項 A**：新增獨立「本次訓練課表」Aggregate，開始訓練時自來源複製快照，AI 微調僅改快照。

| 欄位 | 型別 | 說明 |
|------|------|------|
| 來源類型 | 列舉 | 訓練計畫 / 自訂訓練 / 空白課表 |
| 來源課表 ID | ID / 空值 | 來源類型為空白課表時為空值 |
| 課表內容 | — | 自來源複製的動作與組數快照 |
| 總計畫組數 | int | ≥ 0，供訓練進度條計算分母 |

- 快照一經產生即與來源脫鉤，來源其後的改動不影響已產生的快照（保證歷史訓練可重現）。
- AI 訓練前 / 訓練中調整改快照；AI 自動優化改來源課表範本。
- 訓練進度條的總計畫組數取自本 Aggregate，不取自來源課表。
- 空白課表為合法初始狀態：總計畫組數 0、來源課表 ID 空值。
- 與訓練紀錄為一對一：前者為計畫、後者為實績，兩者不合併。
- 獨立 Aggregate 清單 33 → 34 項。

**維護性評估（使用者追問）**：A 以「便宜的儲存空間」換「昂貴的邏輯複雜度與可除錯性」。
資料重複量級約為訓練紀錄的一倍（皆為整數欄位），不構成問題；
唯一實質風險為「課表結構須同步兩處」，由下一題選擇共用結構消除。
選 C（引用＋差異）每次讀取需即時合併且來源被改動時語意即壞；選 B 混淆計畫與實績；選 D 推翻既有作用範圍邊界。

# 後續修正（2026-07-31，第 19 題）

快照的產生時點由「使用者已開始訓練」修正為「**使用者已選擇訓練課表**」。

**修正原因**：AI 訓練前調整流程發生於「使用者已選擇訓練課表」與「使用者已開始訓練」之間，
原時點會使「訓練課表已套用新強度〔作用範圍＝本次訓練〕」在快照尚未產生時發生，Postcondition 無法驗收。

詳見 `resolved/aggregate/本次訓練課表_快照應於哪一個時點產生.md`。
