# 釐清問題

會員權益的「生效狀態」欄位，00_全域規範定義為**二值**（已生效 / 已失效）並明文「不新增『寬限中』狀態值」，而 `會員訂閱流程.md` 定義為**四值**（未生效 / 生效中 / 已取消待到期 / 已失效）。何者為準？

# 定位

流程：會員訂閱流程
元素：Aggregate「會員權益」之生效狀態欄位
細節：D2 欄位定義、D5 狀態機、F2 術語衝突。00_全域規範〈會員權益 Aggregate〉欄位表與 `會員訂閱流程.md` 第 21 行直接牴觸；後者為第四輪「取消後於到期日失效」裁決時新增，前者未同步。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 以流程檔為準，四值：未生效 / 生效中 / 已取消待到期 / 已失效。00_全域規範同步改寫，並補上完整狀態轉換表 |
| B | 三值：生效中 / 已取消待到期 / 已失效。「未生效」不成立為狀態 —— 未訂閱者根本沒有會員權益實體 |
| C | 以 00_全域規範為準，二值：已生效 / 已失效。「已取消待到期」改以另一個布林欄位「自動續約已取消」表達，狀態欄位不因取消而改變 |

| Short | 提供其他簡短答案（<=5 字） |

# 解決結果

**選項 B** —— 收斂為**三值**：生效中 / 已取消待到期 / 已失效。

**移除「未生效」的理由**：會員權益 Aggregate 為每使用者層級，於「使用者已訂閱會員」時方才產生，
在此之前該實體不存在，沒有一筆資料處於未生效。此與模型既有做法一致 ——
訂單無「未成立」、師徒關係無「未建立」、貼文無「未發布」，
一律由第一個 Event 直接產生第一個有效狀態。

**保留「已取消待到期」的理由**（不採 C、D 的布林旗標）：承第四輪裁決
「若無此狀態，已取消者與正常訂閱者的狀態完全相同，使用者無從得知自己還剩幾天」；
且〈進階訓練計畫的三種解鎖方式〉方式 3 的解鎖判定以生效狀態為依據，
判定來源不宜分散於狀態欄位與旗標兩處。

## 本題連帶釐清的三件事

1. **「已失效」非終止狀態**：重新訂閱時沿用同一筆會員權益，狀態轉回生效中。
2. **「權益有效」的判定涵蓋兩個狀態值**（生效中、已取消待到期）：
   已取消待到期者仍享有全部權益至當期到期日，承「取消僅停止自動續約」的既有裁決。
   方式 3 的判準實為**生效狀態 ≠ 已失效**。
3. **「進階訓練計畫已鎖定」僅於狀態轉為已失效時觸發**，不於取消當下觸發。
