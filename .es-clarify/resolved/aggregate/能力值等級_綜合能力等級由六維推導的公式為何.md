# 釐清問題

綜合能力等級為六維彙總後的單一等級，其由六維點數推導的公式為何（取平均 / 取最高 / 加權 / 先算等級再彙總）？

# 定位

流程：跨流程（訓練結算、訓練中斷、回歸任務皆改動能力值）
元素：Aggregate「使用者」之綜合能力等級（衍生欄位）
細節：D3 衍生欄位的定義公式。00_全域規範〈能力值等級〉之 `[待決策 Partial]` 第 1 項：「上方門檻表為**維度能力等級**所用，綜合等級的推導方式仍未定」。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 六維點數取**算術平均**後，套用同一組門檻表（0-99 E / … / 850+ S）。全面均衡者才能拿到高等級 |
| B | 六維點數取**最高值**套用同一組門檻。反映「這個人最強的部位有多強」，專練單一部位者不被懲罰 |
| C | 六維點數取平均，但**最低維與最高維差距超過門檻時降一級**（懲罰嚴重失衡），使綜合等級同時表達強度與均衡度 |
| D | 不由點數推導，改由六個**維度等級**推導：取六個等級的中位數（或第二低者），使單一維度的極端值不主導結果 |
| Short | 提供其他簡短答案（<=5 字） |

註：本題不受 `aggregate/能力值_改採既有公開肌力標準取代自訂訓練量公式.md` 阻擋 —— 新算法改的是各維點數的算法，六維彙總為單一等級的方式與點數來源無關。

# 解決結果

**選項 A** —— 綜合點數 ＝（胸 ＋ 背 ＋ 腿 ＋ 肩 ＋ 手 ＋ 核心）÷ 6，
套用**與維度能力等級同一組門檻表**（E 0–99 / D 100–249 / C 250–449 / B 450–649 / A 650–849 / S 850＋）。

綜合點數為衍生值，不獨立儲存、不另立欄位、不另設專用門檻
（六維的基準訓練量已各自正規化，跨維度點數本即可比，平均值與單維點數落在同一尺度）。

**不採 B（取最高）**：綜合能力等級的既有職責為對外呈現與單一比較基準，取最高會系統性高估 ——
只練胸者綜合 S、六維均衡練到 B 者綜合 B，但後者整體實力明顯更強。

**不採 C（平均 ＋ 失衡降級）**：須另定差距門檻與降級幅度兩個參數，
而平均值本身已反映失衡（專項者其餘五維停在初始值 10），再降一級是罰兩次。

**不採 D（取維度等級中位數）**：對離散六階取中位數會產生鋸齒 ——
某一維由 B 升 A 而綜合不動、另一維剛跨門檻時綜合突然跳級交錯出現。

[已知代價] 專練單一部位者的綜合等級升得慢，為刻意取捨，符合「綜合＝整體實力」的定義。
