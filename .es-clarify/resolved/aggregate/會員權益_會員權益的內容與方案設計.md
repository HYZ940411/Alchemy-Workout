# 釐清問題

「會員權益已生效」的權益具體包含哪些內容？訂閱方案有幾種（月 / 季 / 年）？價格與權益差異為何？

# 定位

流程：會員訂閱流程
元素：Aggregate：會員權益 / 會員訂閱（模型中尚未定義）
細節：隱含但未明確定義的 Aggregate（D1）；欄位定義（D2）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 單一方案（月訂閱），權益為：AI 調整無次數限制 + 進階訓練計畫 + 每月補簽券 |
| B | 月 / 年兩種方案，權益相同僅價格不同 |
| C | 多層級方案（基礎 / 進階），權益依層級遞增，需要權益層級欄位 |
| D | 單一方案，權益內容由管理員後台可調整，需要「權益設定」Aggregate |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響會員權益 Aggregate 的欄位與方案結構、會員權益已生效的 Postcondition、各流程中會員相關 Precondition（AI 調整次數、補簽券配發、進階計畫存取）、以及虛擬商品購買流程的品項重疊。

# 優先級

High

# 解決結果

D + B（使用者原話：「D+B的兩種方案」） —

- 訂閱方案為**月繳與年繳兩種**，權益完全相同，僅價格與週期不同（B）
- 權益內容由管理員後台調整，新增「權益設定」Aggregate 與管理員 Command（D）
- 不設多層級方案（未採 C），故無層級欄位與升降級路徑
- 訂閱價格由 App Store 商品設定決定，不存於本模型

新增 Event「管理員已設定會員權益」，Actor 為管理員。
「使用者已訂閱會員」補上攜帶資訊：方案（月繳 / 年繳）。

**Partial**：權益的具體項目清單未給定。提問時已聲明未列舉即記為 Partial。

# 結構一致性

與成就定義、獎勵定義、階級設定、新手任務範本、每日任務池採同一模式
（平台級可調參數獨立於每使用者狀態之外），本題為第六個。

# 承接的既有裁決

第 19 題：訂閱走 App Store，支付與自動續約由其執行，本系統被動接收通知。
故價格不進模型，到期時點由 App Store 通知決定。
