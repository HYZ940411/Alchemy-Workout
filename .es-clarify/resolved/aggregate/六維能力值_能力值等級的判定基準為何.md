# 釐清問題

能力值等級的判定基準為何 —— 絕對點數門檻，還是全平台相對百分位？

# 定位

流程：訓練結算流程
元素：Aggregate「使用者」的維度能力等級推導規則
細節：D3 衍生欄位公式、C3 數值邊界。

前置：`resolved/aggregate/六維能力值_能力值是否分等級與分級對象為何.md`（第 22.1 題）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 絕對點數門檻，六維共用同一組門檻 |
| B | 絕對點數門檻，但六維各自一組門檻，依各肌群基準訓練量校準 |
| C | 全平台相對百分位（如前 5% 為 S） |
| D | 絕對門檻，但依健身經驗分級（新手 / 中階 / 進階）分別設定 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響能力值等級的推導規則、綜合能力等級的推導公式（22.3）是否有共同尺度、
能力值上限的可達性、以及成就是否可掛勾等級。

# 優先級

High

# 解決結果

**選項 A** —— 絕對點數門檻，六維共用同一組門檻。

使用者另裁決：**「可到達 1000，不必恆小於 1,000」**。

裁決要點：

1. 六維共用一組門檻，不依維度分設，亦不依健身經驗分級分設；不採相對百分位。
2. 跨肌群正規化已由〈能力值提升公式〉的獨立基準訓練量完成，故無須依維度分設門檻。
3. 「理論上限」更名為「**能力值上限**」，1,000 為**可達成**之值，S 級的頂點即 1,000。
4. 六個等級的具體點數門檻尚未給定，標為待決策。

## 推翻的既有共識

# 後續修正（2026-08-03，第五輪第 22 題）

本裁決的「**能力值上限 1,000 改為可達成**」一條由使用者**撤回**。

| 原裁決 | 現況 |
|--------|------|
| 判定基準採絕對點數門檻，六維共用 | **維持不變** |
| 能力值上限 1,000 為**可達成**之值，S 級頂點即 1,000 | **已撤回** —— 回復為漸近線、不可達成 |

## 撤回理由

使用者於第五輪第 22 題指出：

> 「其實使用者到 850 以上就可以了，他們想看到 S，不必一定要到滿分 1,000 分」

「可達成」的需求不存在，故遞減報酬公式不需調整，1,000 回復為漸近線。
**S 級門檻訂於 850，無上緣。**

此撤回同時消解了本裁決所產生的數學矛盾
（遞減係數趨近 0 導致 1,000 永不可達），該矛盾原記於
`resolved/aggregate/能力值_遞減報酬公式如何使上限1000可達成.md`。

## 一併定案

六階具體門檻已於同一題給定（E 0–99 / D 100–249 / C 250–449 / B 450–649 / A 650–849 / S 850 以上），
原「六個等級的具體點數門檻尚未給定」之待決事項已解決。
