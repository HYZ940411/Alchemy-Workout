# 釐清問題

「教官資格已初審通過」的初審由系統自動判定（依既有數據如階級、訓練次數）還是由管理員人工審核？初審條件為何？

# 定位

流程：教官申請流程
元素：Command：初審教官資格；Actor：未定義；Event：教官資格已初審通過
細節：Actor 識別與觸發源（B4、B5）；孤兒 Event（E1）；Precondition 完整性（C1）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 系統自動依門檻判定（如達指定階級 + 累積訓練次數），Actor 為系統 |
| B | 管理員人工審核申請資料，Actor 為管理員 |
| C | 系統自動初篩門檻，通過者再由管理員審核資料，需拆為兩個 Event |
| D | 無初審，申請即可直接作答測驗，應刪除此 Event |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響教官資格已初審通過的 Actor、Precondition 與初審門檻定義、教官申請流程的 Event 數量、以及使用者已作答教官測驗的前置條件。

# 優先級

High

# 解決結果

A — 初審由系統自動依門檻判定（指定階級 + 累積訓練次數），Actor 為系統，無人工介入。
不拆為兩個 Event，亦不刪除此 Event。

**Partial**：初審門檻的具體數值（階級、累積訓練次數）未給定，留待 rule 層量化。
提問時已明示未給定即記為 Partial，使用者未補充。
