# 釐清問題

使用者 Aggregate 的「持有器材明細」欄位於第六輪第 21 題新增，定為「於設定頁填寫」，但〈Command 清單〉中**完全沒有對應的 Command** —— 使用者如何設定它、設定是否產生 Event，模型從未定義。

# 定位

流程：無所屬流程（設定頁行為）
元素：〈Command 清單〉
細節：B1 Command 識別完整性、E1 Actor→Command→Event 串聯。
由助理於第七輪第 2 題回寫時發現。**為既有缺口，非本輪新增。**

# 背景

該欄位現有三條寫入路徑，皆無 Command：

| 路徑 | 出處 | 有無 Command |
|------|------|-------------|
| 設定頁填寫 | `00_全域規範.md`〈使用者端的器材〉 | **無** |
| 「本次訓練器材已解鎖」時勾選「套用至未來所有訓練」 | 第七輪第 2 題 | **無** |
| 註冊時的 3 級器材（不同欄位，僅作為退回值） | 註冊流程「使用者已選擇健身器材」 | 有 |

同類問題另見：「AI 自動優化已啟用」（第七輪第 9 題新增，同樣無 Command）、
「六維能力值對外可見」（已裁決不建模）、「單位偏好」等其餘設定頁欄位。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | **不建模**：設定頁欄位一律不進〈Command 清單〉，比照「六維能力值對外可見」的既有裁決 |
| B | **逐一建模**：為每個設定頁欄位各建一個 Command 與 Event |
| C | **統一一個 Command**：「變更個人設定」（攜帶欄位名與新值），不逐欄位拆分，亦不產生 Event |
| D | **依判準分流**：影響任何規則判定的欄位（持有器材明細、AI 自動優化已啟用）建模；純顯示偏好（單位偏好）不建模 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響〈Command 清單〉總條數、使用者 Aggregate 全部設定類欄位的處理方式，
以及「持有器材明細」是否需要變更歷史（AI 依其推導可練場所，設定錯誤會影響動作替換）。

**建議與 `aggregate/使用者_AI自動優化已啟用的關閉與啟用是否建模為Command與Event.md`
合併為同一題裁決** —— 兩者為同一個判準問題的兩個實例。

# 解決結果（2026-08-08，第八輪第 21 題，兩檔合併裁決）

**D —— 依判準分流。判準：該欄位是否被任何 Precondition 或 Policy 讀取。**

| 欄位 | 建模 | 被誰讀取 |
|------|------|---------|
| 持有器材明細 | ✅ | 訓練前的器材比對 Policy、AI 替換動作的調整依據 |
| AI 自動優化已啟用 | ✅ | 〈AI 自動優化訓練流程〉Policy 的 Precondition |
| 偏好訓練時段 | ✅（既有） | 訓練提醒的發送時段判定 |
| 六維能力值對外可見 | ❌ | 無任何規則讀取 |
| 單位偏好 | ❌ | 僅影響顯示 |

## 關鍵論據：模型早已在用這條判準

「偏好訓練時段」正是「**只影響自己、但被規則讀到**」的欄位，
其既有 Event「使用者已選擇偏好訓練時段」即依本判準成立。
本題僅將該判準明文化，非新增判準。

**選項 A（判準收窄為「是否影響他人」）會反過來推翻該既有 Event。**

## 被推翻的既有共識

`00_全域規範.md` 原規則：

> 本欄位（持有器材明細）**不建模為 Event**：比照「六維能力值對外可見」——
> 純設定、不影響任何規則判定、不作為任何 Precondition，只影響預設篩選與 AI 的輸入。

**該理由於寫下時即與事實不符**，且其後又新增兩處讀取點：
① 器材比對 Policy 以本欄位判定是否觸發「本次訓練器材已解鎖」；
② 「AI 已替換動作」以本欄位為調整依據。

## 兩個不採方案

- **不採逐一建模全部設定欄位**：單位偏好、雷達圖隱藏等純顯示欄位各給一個 Event，
  Event 總數膨脹而無任何讀者。
- **不採單一泛用 Command「變更個人設定」**：其攜帶任意欄位的任意值，
  Postcondition 只能寫成「該欄位變成新值」，等同無驗收標準 ——
  承〈平台級設定的軟體邊界〉否決「平台設定已變更」單一泛用 Event 的相同理由。

## 一併收斂的暗路

「持有器材明細」原有**三條寫入路徑、零個 Command**。現收斂為兩條路徑共用同一個 Command：
① 設定頁填寫；② 於「本次訓練器材已解鎖」時勾選「套用至未來所有訓練」。
（第三條為註冊時的 3 級器材，屬不同欄位，本即有自己的 Event。）
