# 釐清問題

「使用者已填入健身目標」與「使用者已選擇健身器材」的輸入是否可複選？各自的值域為何？

# 定位

流程：註冊流程
元素：Command：填入健身目標、選擇健身器材（對應 Event：使用者已填入健身目標、使用者已選擇健身器材）
細節：Command 的輸入參數、必填 / 選填、可否複選（B3）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 健身目標單選、健身器材複選 |
| B | 兩者皆複選，健身目標可設定主次優先序 |
| C | 兩者皆單選 |
| D | 健身目標複選但上限 2 項、健身器材複選無上限 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響使用者 Aggregate 中兩欄位的型別（單值或集合）、「依經驗/目標/器材從既有計畫中推薦」Policy 的比對邏輯、以及推薦結果的唯一性。

# 優先級

Medium

# 解決結果

D + D-3（追問後收斂） — 健身目標複選、上限 2 項；健身器材複選、無上限。

**健身目標**分兩類，合計最多 2 項：
- 動機類：選填，最多 1 項。使用者所舉：健康陪伴家人、堅持夢想
- 常見目標類：必填，1 項。使用者所舉：增肌、培養運動習慣、減重

**健身器材**值域（使用者原話）：健身房（全器材）、居家器材（彈力繩、小啞鈴等）、徒手

**Partial**：兩類健身目標的完整選項清單未給定（使用者以「之類的」列舉），
已確認項目照實記錄，未自行擴充。健身器材的三項值域為完整清單。

# 追問紀錄

初次回答為 D 並補充「健身目標分兩類」，但「上限 2 項」與「兩類」的關係有三種讀法
（每類各 1 項必填 / 任選 2 項 / 動機類選填＋常見目標必填）。
追問後使用者選 D-3：動機類選填、常見目標必填。

# 連帶影響

第 2 題已定「推薦為單向指派，使用者不可拒絕」。健身目標既可複選（最多 2 項），
註冊流程 Policy「依經驗 / 目標 / 器材從既有計畫中推薦」必須能由多目標組合產出**唯一**推薦結果。
該比對邏輯尚未定義，記錄於 `.es-clarify/pending-gaps.md` G16。
