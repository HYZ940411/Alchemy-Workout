# 釐清問題

「師徒關係已恢復」（解除後 3 天內可挽回）由哪一方執行 Command？是否需要對方同意？

# 定位

流程：師徒互動流程
元素：Command「恢復師徒關係」；Actor；Event「師徒關係已恢復」
細節：Actor 識別與權限（B4 / B5）；前置條件（C1）；狀態邊界 — 終止狀態下的再次操作（C3）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 任一方皆可單方面恢復，不需對方同意（與單方面解除對稱） |
| B | 任一方可提出，但須對方同意，須補「對方已同意恢復 / 已拒絕恢復」Event |
| C | 僅原解除方可恢復，不需對方同意 |
| D | 僅非解除方（被解除的一方）可恢復，不需對方同意 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響「師徒關係已恢復」的 Precondition 與 Actor 指派、3 天冷卻期規則與帶徒名額的重新佔用、
以及是否需新增同意 / 拒絕分支 Event。
本項為新掃描發現，非承接 `pending-gaps.md`。

# 解決結果

**選項 B**：任一方可提出恢復，但須對方同意。

**新增 3 個 Event**：使用者已提出恢復師徒關係、對方已同意恢復、對方已拒絕恢復。

- 「使用者已提出恢復師徒關係」Precondition：距「師徒關係已解除」未滿 3 天。
- 「師徒關係已恢復」Precondition：「對方已同意恢復」已發生，且教官的名額佔用數未達帶徒上限。
- 「師徒關係已恢復」Postcondition：3 天冷卻期解除、重新佔用教官的帶徒名額。
- 拒絕後該筆恢復提議失效，3 天內可再次提出。
- 解除為單方面、恢復需雙方同意，兩者**刻意不對稱**：建立關係在模型中一律需雙方同意（比照「對方已接受申請」），
  且單方面恢復會產生乒乓效應（一方可反覆解除又拉回，另一方無控制權）。
