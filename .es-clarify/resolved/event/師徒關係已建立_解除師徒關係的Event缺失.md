# 釐清問題

模型中缺少解除師徒關係的 Event，師徒關係可否終止？由誰發起？終止後未完成的師徒任務如何處理？

# 定位

流程：師徒互動流程
元素：Event：師徒關係已建立（缺少終止 Event）；Aggregate：師徒關係的狀態機
細節：隱含發生但未寫出的 Event（A1）；生命週期與終止狀態（D5）；可逆操作（C4）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 補上「師徒關係已解除」Event，雙方皆可單方面解除，未完成任務作廢 |
| B | 補上「師徒關係已解除」Event，需雙方同意或經冷靜期，未完成任務作廢 |
| C | 補上「學徒已出師」與「師徒關係已解除」兩個 Event，出師為正向終止 |
| D | 師徒關係一旦建立即永久有效，不可解除 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響師徒互動流程的 Event 清單、師徒關係 Aggregate 的狀態機與終止狀態、教官帶徒數量的釋放（影響帶徒上限判定）、以及未完成師徒任務的生命週期（D4）。

# 優先級

High

# 解決結果

A（含使用者補充）— 補上「師徒關係已解除」Event，教官與學徒任一方皆可單方面解除，不需對方同意，未完成的師徒任務作廢。

使用者補充的防誤觸機制：
- 解除需經多次確認。
- 解除後 3 天內，雙方皆不得與其他對象建立師徒關係。
- 解除後 3 天內可挽回，恢復原師徒關係 → 補上「師徒關係已恢復」Event。
