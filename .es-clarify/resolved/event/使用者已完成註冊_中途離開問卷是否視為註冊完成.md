# 釐清問題

使用者在填寫十項個人資料的過程中離開，是否仍視為「使用者已完成註冊」？未填完的資料如何處理？

# 定位

流程：註冊流程
元素：Event：使用者已完成註冊
細節：終點 Event 的判定條件（A1、A3 分支路徑）；未完成路徑目前沒有對應 Event。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 帳號建立即算註冊完成，個人資料可事後補填，不影響 Event |
| B | 必須填完全部十項才算完成，中途離開產生「註冊資料填寫已中斷」Event，下次登入續填 |
| C | 僅身體數據（身高/體重/性別/年齡）為必填，訓練偏好可略過，略過時以預設值帶入 |
| D | 中途離開視同放棄，資料清空並產生「註冊已放棄」Event |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響註冊流程的分支路徑 Event、使用者 Aggregate 的必填欄位定義、「訓練計畫已推薦」與「新手任務已指派」的 Precondition（是否需要完整資料才能推薦）。

# 優先級

High

# 解決結果

B — 必須填完全部 9 項個人資料才算註冊完成。中途離開產生「註冊資料填寫已中斷」Event，下次登入自未完成的欄位續填，已填資料不清空。

# 回寫位置

`Event-Storming_事件風暴/註冊流程.md` → 新增分支 Event「註冊資料填寫已中斷」、續填 [Policy]，並為「使用者已完成註冊」加上 Precondition
