# 釐清問題

師徒互動流程中「學徒已評分」出現兩次（一次在教官已回答之後、一次在師徒任務獎勵已發放之後），兩者是同一個 Event 還是不同的評分行為？

# 定位

流程：師徒互動流程
元素：Event：學徒已評分（於流程中出現兩次）
細節：兩個名稱相同實則需區分的 Event（A2）；Event 時序（A3）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 為兩種不同評分：對「單次問答」的評分與對「師徒任務」的評分，應分別命名 |
| B | 為同一個 Event，模型中重複列出屬筆誤，應刪除其一 |
| C | 為兩種不同評分，且第二次為對教官的整體評價，應命名為「學徒已評價教官」 |
| D | 為同一個 Event，可由問答與任務兩種情境觸發（多對一），僅需列出一次 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響師徒互動流程的 Event 清單與命名、評分 Aggregate 的類型欄位、教官聲望已變動的計算來源（哪些評分影響聲望）、以及師徒互動流程的時序正確性。

# 優先級

High

# 解決結果

A — 兩者為不同的評分行為，分別改名以消除同名歧義：
- 教官已回答之後 →「學徒已評分該次問答」
- 師徒任務獎勵已發放之後 →「學徒已評分該次師徒任務」

`Event-Storming_事件風暴/師徒互動流程.md` → 兩處「學徒已評分」分別改名
