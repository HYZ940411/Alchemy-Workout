# 釐清問題

回歸任務指派與訓練中斷流程的退步預告 / 能力值退步在時間上可能同時發生，兩條流程的 Event 交錯順序與通知如何協調？

# 定位

流程：回歸任務流程、訓練中斷流程
元素：Event：回歸任務已指派、退步預告已發送、能力值已退步
細節：可並行發生的 Event 交錯順序（A3）；組合邊界與規則衝突（C3）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 兩條流程完全獨立並行，各自發送通知，不做協調 |
| B | 回歸任務指派時抑制訓練中斷流程的退步預告通知，合併為單一通知 |
| C | 完成回歸任務可豁免能力值退步，兩流程需建立依賴關係 |
| D | 訓練中斷流程的能力值退步發生後才指派回歸任務，嚴格序列化 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響兩條流程的 Event 時序與依賴、能力值已退步的 Precondition 是否受回歸任務狀態影響、以及使用者收到的通知數量與體驗。

# 優先級

Medium

# 解決結果

D′（含追問修正） — 兩流程嚴格序列化，不並行：
「能力值已退步」發生後才「回歸任務已指派」。
完成回歸任務除發放獎勵外，另補上「能力值已部分回復」Event。

使用者原話：「D′，希望合理範圍內恢復一點點」。

**Partial**：回復幅度未量化，追問一次後仍為「一點點」，幅度留待
`rule/能力值已退步_退步是否可透過補救行為回復.md` 定案。

# 追問紀錄

初次回答為「C+D」，但 C（完成回歸任務豁免退步）與 D（退步後才指派）時序矛盾 ——
退步已發生則無從豁免。追問後使用者選 D′ 並要求加入部分回復，故以「回復」而非「豁免」建模。

# 連帶影響

- 新增 Event「能力值已部分回復」（回歸任務流程）。
- `rule/能力值已退步_退步是否可透過補救行為回復.md`：答案已定為「可回復」，僅剩幅度待量化，該題提問時須帶入此前提。
- `rule/使用者久未訓練達門檻_久未訓練的門檻值為何.md`：本題已約束該門檻不早於「能力值已退步」（即 120 小時未訓練之後），該題提問時須帶入此下界。
