# 釐清問題

「能力值已提升」出現在新手任務流程與訓練結算流程，與訓練中斷流程的「能力值已退步」互為反向，三者是否應統一為單一「能力值已變動」Event？

# 定位

流程：新手任務流程、訓練結算流程、訓練中斷流程
元素：Event：能力值已提升（兩處）、能力值已退步（一處）
細節：兩個名稱相同的 Event 是否為同一事實（A2）；可逆操作的 Event 定義（C4）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 提升與退步維持兩個獨立 Event，各自出現處為同一定義 |
| B | 統一為單一「能力值已變動」Event，變動方向與來源為其攜帶資訊 |
| C | 維持提升 / 退步兩個 Event，但需依來源拆分提升 Event（任務提升 vs 訓練提升） |
| D | 維持兩個 Event，並補上「能力值已回復」作為第三種變動 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響能力值相關 Event 的定義與數量、能力值 Aggregate 的變動紀錄結構、階級提升流程的連動判定、以及與「經驗值已提升」問題的處理一致性。

# 優先級

High

# 解決結果

A — 兩處為同一個 Event，統一定義一次。來源（新手任務 / 訓練結算）為其攜帶資訊，各來源的提升幅度由該來源流程的 Policy 決定。與「能力值已退步」維持為兩個獨立 Event，不合併為單一變動 Event。
