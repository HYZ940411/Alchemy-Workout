# 釐清問題

進階訓練計畫已定案有三種解鎖方式（階級達標 / 金幣提前購買 / 會員身分），但「進階訓練計畫已解鎖」目前僅掛在階級提升流程且 Precondition 為階級達標。金幣購買（商品已發放）與會員身分（會員權益已生效）兩條路徑是否也產生本 Event？權益失效時的回退是否需要對應的 Event？

# 定位

流程：階級提升流程、虛擬商品購買流程、會員訂閱流程
元素：Event「進階訓練計畫已解鎖」；Command「解鎖進階訓練計畫」（Actor：系統）
細節：A1 事件識別完整性、E3 Event→Aggregate 一致性。00_全域規範〈訓練計畫 Aggregate〉之〈進階訓練計畫的三種解鎖方式〉與〈會員權益失效時的回退〉皆已定案，但三條路徑僅有一個 Event，且回退無任何 Event。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 三條路徑共用「進階訓練計畫已解鎖」（改為多對一），攜帶「解鎖方式」欄位（階級達標 / 金幣購買 / 會員身分）；另新增「進階訓練計畫已鎖定」承接會員權益失效時的回退 |
| B | 同 A 的多對一，但不新增鎖定 Event：回退為「會員權益已失效」的 Postcondition，非獨立事實 |
| C | 維持單一 Event 僅供階級達標；金幣購買由「商品已發放」承接、會員身分由「會員權益已生效」承接，三者不合併 |
| D | 解鎖狀態全部改為衍生值（依三條件即時推導），取消「進階訓練計畫已解鎖」Event |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響 Event 清單（可能增列 1 個）、〈Command 清單〉階級提升流程與虛擬商品購買流程、〈Read Model：課表選擇頁〉的解鎖狀態來源、以及使用者的「已購買計畫清單」欄位歸屬。
相關已解決項目：`resolved/aggregate/進階訓練計畫_三種解鎖方式與管理員設定.md`、`resolved/aggregate/進階訓練計畫_解鎖的計畫內容與階級對應關係.md`。
相依：`aggregate/使用者_第五輪新增的五個欄位尚未納入欄位定義表.md`（已購買計畫清單）。

# 解決結果

**選項 A** —— 三條路徑共用「進階訓練計畫已解鎖」（改為多對一），攜帶「解鎖方式」欄位
（階級達標 / 金幣購買 / 會員身分）；**另新增 Event「進階訓練計畫已鎖定」**承接會員權益失效時的回退。

使用者追問「回退什麼」，已釐清並寫入模型：回退的是**使用權，不是資料** ——
僅以會員身分解鎖者鎖定、階級達標與金幣購買者維持解鎖；訓練紀錄與快照全數保留，續訂即回復原狀。
