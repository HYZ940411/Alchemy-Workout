# 釐清問題

團隊的「可見性」欄位於建立團隊時指定，隊長事後可否變更？若可，是否補立「隊長已變更團隊可見性」Event，且由公開改為私密時既有的待處理加入申請如何處理？

# 定位

流程：團隊組隊流程
元素：Aggregate「團隊」的可見性欄位；Event（尚未存在）
細節：A1 事件識別完整性、C4 可逆性。`00_全域規範.md`〈團隊 Aggregate〉規則「可見性於建立團隊時指定；變更可見性的 Event 本階段不建模」。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 可事後變更，補立「隊長已變更團隊可見性」Event；改為私密時既有待處理加入申請一律失效 |
| B | 可事後變更，補立 Event；改為私密時既有待處理申請保留，隊長仍可核准 |
| C | 不可變更，可見性於建立時一經指定即固定，維持現狀不建模 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響團隊組隊流程的 Event 清單與〈Command 清單〉、團隊 Aggregate 可見性欄位的不變條件、以及「使用者已申請加入團隊」的 Precondition（團隊可見性為公開）在變更後的效力。
來源：`pending-gaps-2.md` H5。

# 優先級

Low

# 解決結果

**選項 B** —— 可事後變更，補立「隊長已變更團隊可見性」Event；改為私密時既有待處理加入申請一律保留，隊長仍可核准或拒絕。
