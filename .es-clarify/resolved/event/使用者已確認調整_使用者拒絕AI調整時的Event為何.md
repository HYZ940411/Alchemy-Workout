# 釐清問題

使用者若不接受 AI 提出的調整方案，會發生什麼 Event？可否要求 AI 重新調整？

# 定位

流程：AI 訓練前調整流程、AI 訓練中調整流程（插入訓練紀錄流程循環）、AI 自動優化訓練流程
元素：Event：使用者已確認調整、使用者已確認使用新訓練強度
細節：分支路徑（接受 / 拒絕）是否都有對應 Event（A3）；失敗路徑（C5）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 補上「使用者已拒絕調整」Event，拒絕後維持原訓練內容，流程結束 |
| B | 補上「使用者已拒絕調整」Event，並可重新提出要求進入下一輪循環 |
| C | 補上「使用者已拒絕調整」與「使用者已手動修改調整方案」兩個 Event |
| D | 不可拒絕，AI 調整為單向套用，無需額外 Event |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響三條 AI 流程的分支 Event、訓練課表 Aggregate 是否保留調整前版本、以及 AI 自動優化流程中未確認時的預設行為（沿用舊強度或逾時自動套用）。

# 優先級

High

# 解決結果

A — 三條 AI 流程各補上「使用者已拒絕調整」Event。拒絕後維持原訓練內容（自動優化流程為維持原課表範本強度），流程結束，不可重新提出調整要求，亦不新增手動修改方案的 Event。
