# 釐清問題

「管理員已審核公開訓練」若審核未通過，會發生什麼 Event？

# 定位

流程：自訂訓練流程（循環 1：使用者已選擇動作 - 使用者已設定該動作的組數、循環 2：使用者已設定該組的重量 & 次數）
元素：Event：管理員已審核公開訓練（流程終點）
細節：分支路徑（通過 / 未通過）是否都有對應 Event（A3）；失敗路徑（C5）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 拆為「公開訓練已通過審核」與「公開訓練已退回」兩個 Event |
| B | 維持單一 Event，審核結果為其攜帶資訊，另補「公開訓練退回通知已發送」 |
| C | 拆為通過 / 退回兩個 Event，退回時需附退回原因且可重新申請 |
| D | 拆為通過 / 退回 / 永久拒絕三個 Event，永久拒絕者不可重新申請 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響自訂訓練流程的分支 Event、自訂訓練 Aggregate 的狀態機終止狀態、是否可重新申請的 Precondition、以及退回原因欄位的定義。

# 優先級

High

# 解決結果

A（含使用者補充）— 補上「公開訓練審核未通過」Event。

使用者補充：退回狀態為「使用者已發布自訂訓練」（而非原選項所述的「已儲存」）—— 該筆訓練自己仍可使用，但不對外公開。可修改後重新申請公開，不限次數。
