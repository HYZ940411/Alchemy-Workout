# 釐清問題

「訓練已結算」是在「使用者已結束訓練」後由系統自動觸發，還是需要使用者主動確認結算？

# 定位

流程：訓練結算流程
元素：Event：訓練已結算（流程起點）；上游 Event：使用者已結束訓練（訓練紀錄流程）
細節：系統自動觸發的 Command（B1）；觸發源（B5）；Event 因果順序（A3）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 結束訓練後由系統自動結算，Actor 為系統 |
| B | 需使用者在結算頁確認後才結算，Actor 為使用者，可先檢視並修正紀錄 |
| C | 自動結算，但保留 24 小時的申訴 / 修正窗口 |
| D | 訓練全部完成時自動結算；提前結束或中斷時需使用者確認 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響訓練已結算的 Actor 與觸發源、與使用者已結束訓練的時序、訓練紀錄 Aggregate 的凍結時點、以及後續所有獎勵發放 Event 的觸發鏈。

# 優先級

High

# 解決結果

A — 訓練結束後由系統自動結算，Actor 為系統。不需使用者確認，亦無申訴 / 修正窗口。三種終止路徑（已完成 / 已提前結束 / 已中斷）一律自動結算。
