# 釐清問題

模型中缺少刪除貼文、編輯貼文、取消按讚、刪除留言等 Event，這些操作是否存在？

# 定位

流程：發文與互動流程
元素：Event：發文者已發布貼文、互動者已按讚貼文、互動者已留言（缺少反向與修改操作）
細節：隱含發生但未寫出的 Event（A1）；可逆操作的 Event 定義（C4）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 補上「貼文已刪除」「按讚已取消」「留言已刪除」三個 Event，不支援編輯 |
| B | 補上上述三個，另加「貼文已編輯」與「留言已編輯」 |
| C | 僅補上「貼文已刪除」與「按讚已取消」，留言不可刪除 |
| D | 不支援任何刪除與編輯，貼文與互動一經發布即不可變更 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響發文與互動流程的 Event 清單、貼文 Aggregate 的狀態機、獎勵與成就的回收規則、以及管理員管理社群流程「管理員已下架違規內容」與使用者自行刪除的區分。

# 優先級

Medium

# 解決結果

B — 補上五個反向與修改操作 Event：
貼文已刪除、貼文已編輯、按讚已取消、留言已刪除、留言已編輯。
分享無反向操作 Event。

# 連帶影響

- `rule/按讚獎勵已發放_取消按讚或刪除留言時獎勵與成就是否回收.md`：本題確立反向操作存在，該題成立且必須回答。
- `rule/師徒功能解鎖條件_被刪除的社群行為是否計入解鎖條件.md`：貼文與留言可刪除，該題成立且必須回答。
