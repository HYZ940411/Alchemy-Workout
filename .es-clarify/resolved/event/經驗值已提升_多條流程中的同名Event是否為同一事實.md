# 釐清問題

「經驗值已提升」分別出現在新手任務流程、每日簽到流程、訓練結算流程，三處是否為同一個 Event？各自的提升幅度來源為何？

# 定位

流程：新手任務流程、每日簽到流程、訓練結算流程
元素：Event：經驗值已提升（跨三條流程重複出現）
細節：兩個名稱相同的 Event 是否為同一事實（A2）；跨流程串聯一致性（E1、E3）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 為同一個 Event，來源（新手任務 / 簽到 / 訓練）為其攜帶資訊，統一定義一次 |
| B | 應依來源拆為三個 Event，因為三者的計算規則與加成適用性不同 |
| C | 為同一 Event，且應獨立為「經驗值變動流程」，由各流程作為上游觸發 |
| D | 為同一 Event，但需補上「經驗值已減少」以支援中斷退步情境 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響經驗值已提升的 Event 定義與數量、經驗值 Aggregate 的來源明細是否需拆分、連續訓練獎勵加成的套用範圍、階級提升流程的判定資料來源，以及統一語言的一致性。

# 優先級

High

# 解決結果

A — 三處為同一個 Event，統一定義一次。來源（新手任務 / 每日簽到 / 訓練結算）為其攜帶資訊。不依來源拆分為三個 Event，亦不獨立為經驗值變動流程，不補「經驗值已減少」。
