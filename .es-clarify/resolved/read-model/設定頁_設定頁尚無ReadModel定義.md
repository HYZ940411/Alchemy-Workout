# 釐清問題

模型有多個於「設定頁」填寫或調整的欄位（持有器材明細、AI 自動優化開關、六維能力值與綜合能力等級的對外可見性、單位偏好、偏好訓練時段的補填），但〈Read Model 清單〉中沒有設定頁——其欄位為何？

# 定位

流程：跨流程（訓練紀錄流程、AI 自動優化訓練流程、新手任務流程）
元素：Read Model — 設定頁（尚未建立）
細節：檢查項 D6 與 E4。〈設定類欄位是否建模的判準〉已定兩個設定類 Command（設定持有器材明細、設定 AI 自動優化開關），其操作入口即設定頁

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 建立設定頁 Read Model：個人資料（身高體重生日性別）、單位偏好、持有器材明細、AI 自動優化開關、兩個對外可見性開關、偏好訓練時段、帳號刪除入口與訂閱管理入口 |
| B | 同 A，但拆為兩頁：個人資料頁與偏好設定頁 |
| C | 不建立：設定頁視為純介面、不成立為 Read Model（其欄位皆可直接自使用者 Aggregate 取得） |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

- Read Model 清單新增一頁；兩個設定類 Command 的操作入口
- App Store 要求的帳號刪除入口與訂閱管理入口（StoreKit `showManageSubscriptions`）之落點
- 相關已解決項目：`resolved/aggregate/使用者_AI自動優化已啟用的關閉與啟用是否建模為Command與Event.md`

# 解決結果

**A**：建立單一〈Read Model：設定頁〉。

- 服務的 Actor：使用者（本人）；支撐 6 個 Command（設定持有器材明細、設定 AI 自動優化開關、
  填入身高／體重、選擇偏好訓練時段的補填、申請刪除帳號、取消刪除帳號申請）。
- 欄位分五區：個人資料（含新增的電子郵件）、顯示偏好、訓練設定、隱私、帳號。
- **帳號刪除入口必須存在於本頁**：App Store 5.1.1(v) 要求 App 內提供帳號刪除，
  模型已建妥整條流程卻無入口落點，本頁補上；待刪除狀態者改呈現冷靜期剩餘天數與取消入口。
- **訂閱管理入口**：承既有裁決「平台無法代為取消訂閱，極限為叫出 Apple 原生面板
  （StoreKit `showManageSubscriptions`）」。
- **生日與性別唯讀**：兩者為能力值計算鏈的輸入（年齡係數、DOTS 係數），
  任意改動將使既有點數失去計算基準；更正屬客服範疇，留在系統邊界之外。
- **不採拆為兩頁**：拆頁屬介面編排，Read Model 的欄位清單為同一份。
- 本頁不呈現成長數值（歸個人檔案頁與成就頁）。
