# 解決結果

**選項 A** —— 三個子決策全部採開放做法：

| 子決策 | 裁決 |
|--------|------|
| ① 可回溯時間範圍 | **不設限**，全部訓練紀錄皆可回溯 |
| ② 動作趨勢圖表 | **含折線圖**（重量對時間），與列表並存 |
| ③ 動作名稱搜尋 | **提供**，涵蓋平台動作庫與自建動作 |

**明確不採選項 B（依會員身分區分回溯範圍）**，理由：

1. 訓練紀錄為使用者自身產生的資料，限制存取的性質是「贖回」而非「擴張」，
   與模型既有付費牆（自訂訓練額度、進階訓練計畫）性質不同。
2. 只擋得到已累積 3 個月以上歷史者 —— 恰為留存最久的一群，對新使用者零轉換貢獻。
3. 日常「該不該加重」的判斷只需最近幾次，3 個月的牆幾乎不會被撞到；
   真正會撞到的年度回顧一年僅數次，低頻渴望撐不起訂閱。
4. 資料本已永久保存，設限不省儲存成本。
