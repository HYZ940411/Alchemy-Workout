# 釐清問題

能力值以六角雷達圖呈現，且需表達成長與退步的動態。此 Read Model 應包含哪些欄位？

# 定位

流程：訓練結算流程、訓練紀錄流程、訓練中斷流程
元素：Read Model「六維能力值雷達圖」
細節：D6 Read Model 識別；E4 Read Model → Command 支撐。

服務的 Actor：使用者
支撐的 Command：選擇訓練課表、選擇動作（使用者依弱項與退步風險決定今天練哪個部位）
資料來源：使用者 Aggregate 的能力值 6 維欄位；「能力值已提升」「能力值已退步」
「能力值已部分回復」三個 Event 的歷史。

# 多選題

| 選項 | 描述 | 推薦 |
|--------|-------------|------|
| A | 現值 6 維 ＋ 與上次訓練結算的變化量（僅數字，無對比輪廓） | |
| B | 現值 6 維 ＋ 30 天前的輪廓疊層 ＋ 各維距下次退步的剩餘時數 | ★ 推薦 |
| C | 現值 6 維 ＋ 歷史最高輪廓疊層（可看出與個人最佳的落差） | |
| D | 僅現值 6 維，變化量交由 Event 通知呈現，不進雷達圖 | |
| Short | 提供其他簡短答案（<=5 字） | |

# 影響範圍

影響是否需保存能力值的歷史快照（B、C 皆需）、使用者 Aggregate 是否需新增
「各維歷史最高值」欄位（C 需）、以及此 Read Model 的即時性要求。

# 優先級

High

# 來源

第三輪第 3 題（`resolved/read-model/全流程ReadModel_各流程尚未定義任何Read Model.md`）
使用者於回答總綱時主動提出，依總綱原則 A 判定成立，故開立為正式項目。

# 解決結果

**選項 D ＋ 追問「每日快照」**

- 雷達圖一次僅呈現**單一輪廓**，不做疊層對比；改由圖表上方的**時間維度切換**表達成長與退步。
- 保存**能力值日快照**：每日日界保存當下六維值（使用者識別碼、快照日期、六維能力值）。
- 即時性：「現在」維度為即時（隨三個能力值 Event 立即反映）；歷史維度為日粒度。
- **不顯示各維距下次退步的剩餘時數**（使用者明確裁決）：
  退步提醒的職責已由「退步預告已發送」（該維滿 96 小時未訓練）承擔，不在雷達圖重複表達。

使用者裁決理由：圖表類資料本就可由使用者自行切換時間維度（如 3 個月前），
疊層是同一件事的重複表達。

不採每次訓練結算時快照：快照時點不規則，久未訓練者於該區間可能一筆資料都沒有。
不採月底快照：只能提供月粒度的切換。
