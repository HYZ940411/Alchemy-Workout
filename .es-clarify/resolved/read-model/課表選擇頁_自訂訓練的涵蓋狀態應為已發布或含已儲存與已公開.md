# 釐清問題

〈Read Model：課表選擇頁〉的「自訂訓練」入口現定義為「自訂訓練 Aggregate，狀態為已發布」。但自訂訓練已定案「停留在已儲存即可自己使用」，且另有「已公開」（他人的公開課表）狀態。本頁的自訂訓練應涵蓋哪些狀態？

# 定位

流程：訓練紀錄流程
元素：Read Model「課表選擇頁」之四類入口
細節：D6 Read Model 欄位與來源、E3 一致性。00_全域規範〈Read Model：課表選擇頁〉的來源定義與〈自訂訓練 Aggregate 狀態機〉「發布與申請公開皆為選用步驟，停留在已儲存即可自己使用」直接牴觸 —— 依現行定義，僅儲存未發布者將無法選用自己的課表。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 本人的自訂訓練涵蓋 已儲存 / 已發布 / 已申請公開 / 已公開（除草稿外全部）；**他人的課表不進入本頁**，另立入口 |
| B | A ＋ 增加第五類入口「他人的公開課表」（狀態為已公開者），使公開審核機制有實際的曝光點 |
| C | A ＋ 增加第五、六類入口：他人的公開課表、以及**我關注對象的已發布課表**（承「發布的可見對象為關注者」的既有裁決，否則發布狀態無任何曝光點） |
| D | 維持僅「已發布」，但改寫自訂訓練狀態機：已儲存改為不可直接選用，須先發布方可使用（推翻既有裁決） |
| Short | 提供其他簡短答案（<=5 字） |

# 前提已於第六輪第 6 題變更（2026-08-04）

本題原本的矛盾（課表選擇頁只列已發布，但狀態機說已儲存即可自用）**已消解** ——
使用者裁定以課表選擇頁的寫法為準：已儲存＝未啟用不可選用、已發布＝自己可用。
故「本人的自訂訓練涵蓋哪些狀態」已定案為**已發布、已申請公開、已公開**（不含已儲存）。

本題**仍待裁決的部分**收斂為：

1. **他人的已公開課表**是否進入本頁？（若否，公開審核機制無曝光點）
2. **關注對象的課表**（其「對關注者可見」欄位為真者）是否進入本頁？
   —— 該欄位為第 6 題新增，其唯一用途即為此。
3. 若兩者皆進入，是否需分區呈現（我的 / 關注 / 公開）？

原多選題的選項 A 與 D 已因前提變更而作廢，選項 B 與 C 的差異即為上列第 1、2 點。

# 解決結果（2026-08-08，第八輪第 27 題）

**A** —— 涵蓋 **已發布 / 已申請公開 / 已公開** 三個狀態，建立者為本人。
判準為「該狀態下自己可否選用」。

## 原寫法的實際缺陷

〈Read Model：課表選擇頁〉原寫「自訂訓練 Aggregate，**狀態為已發布**」。
而狀態機的路徑為 `已發布 → 已申請公開 → 已公開`——

**使用者將課表送審並通過後，它即不再是已發布狀態，
會從他自己的課表選擇頁上消失。** 公開給全平台使用的東西，作者反而不能用。

## 三個不涵蓋的狀態

| 狀態 | 不涵蓋的理由 |
|------|------------|
| 草稿 | 尚未存檔 |
| 已儲存 | 語意即為**未啟用、不可選用於訓練**（第六輪第 6 題所定） |
| —— | 不採「呈現已儲存但標示不可選」：等同在選課表頁塞入一批選不了的項目；啟用入口為〈自訂訓練管理頁〉的發布動作 |

## 範圍界線

本項處理的是**使用者自己的**自訂訓練。
他人的「已公開」課表屬另一個來源，與本項不混用。
