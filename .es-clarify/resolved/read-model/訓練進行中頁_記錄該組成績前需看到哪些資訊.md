# 釐清問題

使用者執行 Command「記錄該組成績」「完成該組」「提前結束訓練」「提出調整要求」前必須看到什麼？訓練進行中頁的欄位與即時性要求為何？

# 定位

流程：訓練紀錄流程、AI 訓練中調整流程
元素：Read Model（尚未定義）；支撐 Command「記錄該組成績」「完成該組」「結束組間休息」「提前結束訓練」「提出調整要求」
細節：D6 Read Model 識別、E4 Read Model → Command 支撐。
本頁為模型中互動最密集的畫面（訓練紀錄流程 12 個 Command 中有 6 個於此下達），卻無任何 Read Model 定義。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 欄位＝本次訓練課表的動作清單與各組目標重量次數（預帶值）、各組完成勾選狀態、訓練進度條、組間休息倒數、本次已累計訓練量；即時 |
| B | 同 A，另加「該動作上次的實際重量與次數」（供加重決策），來源為訓練紀錄 Aggregate |
| C | 同 B，另加「距逾時中斷判定的剩餘時間」（40 分鐘倒數），避免使用者無預警被判定中斷 |
| D | 同 C，另加各動作所屬肌群與該維目前能力值，供訓練中判斷是否加練 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響 Read Model 清單、本次訓練課表與訓練紀錄兩個 Aggregate 的查詢欄位、與 Read Model「訓練歷史」的職責界線（選項 B 使上次成績同時出現於兩處）、以及「逾時中斷判定」是否對使用者可見（現為系統靜默判定）。
相依：`aggregate/訓練紀錄_訓練紀錄的完整欄位與狀態機為何.md`（已完成組數與累計訓練量的來源）；`rule/使用者已開始訓練_空白課表如何新增動作與組數.md`（空白課表時本頁呈現什麼）。

# 優先級

High

# 解決結果

**選項 B ＋ 使用者三項修正**

| # | 裁決 |
|---|------|
| 1 | 採選項 B：欄位含「該動作上次的實際重量與次數」 |
| 2 | **修正 #3**：進度除「已完成組數 / 總計畫組數」外，另加**進度百分比** |
| 3 | **修正 #4**：組間休息倒數**不常駐於本頁**，改為休息期間獨立呈現、可跳過；跳過即觸發「組間休息已結束」 |
| 4 | **新增欄位**：訓練時長（現在時戳 − 開始時戳，含休息） |
| 5 | 防作弊 30 秒剩餘阻擋秒數：**納入** |

**未納入**：

- 距逾時中斷判定的剩餘時間（選項 C）—— 逾時判定基準為「40 分鐘內未完成任何一組」而非總時長，維持後端靜默判定
- 各動作所屬肌群與該維能力值（選項 D）—— 能力值訓練中為舊值，且已由雷達圖 Read Model 承載

即時性：全欄位即時。
