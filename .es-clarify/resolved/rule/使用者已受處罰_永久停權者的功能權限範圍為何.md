# 釐清問題

永久停權的使用者是否仍可繼續訓練？若可，哪些累積（階級、能力值、
個人排行榜分數、成就、金幣）應停止？各處罰級距可用與不可用的功能清單為何？

# 定位

流程：管理員管理社群流程
元素：Rule：Event「使用者已受處罰」的 Postcondition
細節：C3 狀態邊界、B5 Actor 權限。

**來源**：第 56 題，使用者裁決「僅帳號停權與永久停權暫停計時」後主動提出：
「我不知道讓永久停權使用者也能繼續訓練，但不能累積階級、能力值等，是否可以？」

**與既有裁決的張力**：第 56 題已定案「帳號停權期間暫停所有計時」，
其理由為「使用者根本無法登入」。若永久停權者仍可訓練，
則該前提對永久停權不成立，第 56 題的規則需依處罰種類再細分。

**四級處罰現況**：警告 / 社群功能停權（限期）/ 帳號停權（限期）/ 永久停權。
模型目前僅定義處罰狀態欄位，未定義任一級距的具體功能限制清單。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 永久停權者無法登入，比照帳號停權；模型不提供「可訓練但不累積」的狀態 |
| B | 永久停權者可登入並訓練，但階級、能力值、個人排行榜分數、成就、金幣一律不累積；社群功能全面關閉 |
| C | 同 B，但能力值仍可累積（能力值為身體能力的紀錄，非平台獎勵） |
| D | 永久停權者可登入但僅可讀取自身歷史資料，不可訓練亦不可互動 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響「使用者已受處罰」的 Postcondition、四級處罰各自的功能限制清單、
第 56 題「帳號停權暫停計時」規則是否需依級距再細分、
永久停權者的訓練紀錄是否進入 AI 訓練品質評分與排行榜、
以及帳號生命週期（永久停權與帳號刪除為兩個不同的終止狀態）。

相依：`resolved/rule/使用者已受處罰_停權期間的訓練與能力值退步與連續天數如何處理.md`（第 56 題）。

# 解決結果

**使用者提出四選項以外的答案：重構整個處罰階梯。**

## 一、新的處罰階梯（門檻制）

| 累計違規次數 | 處罰 | 時長 |
|-------------|------|------|
| 1 – 2 | 警告 | — |
| 3 – 4 | 社群功能停權 | 7 天 |
| 5 – 6 | 社群功能停權 | 30 天 |
| 7 起 | **永久停權** | 無到期，僅可經申訴撤銷 |

- 級距為**門檻**而非單次，故每一級涵蓋兩次違規，階梯連續不留空（經使用者確認）。
- **「帳號停權」級距整級移除**，其位置由 30 天的社群功能停權取代。
- 處罰狀態值域由五值改為**四值**：無 / 警告 / 社群功能停權 / 永久停權。
- **警告不做任何功能處置，僅記次。**

## 二、永久停權 ＝ 所有功能皆不可用，僅可申訴

**使用者否決助理推薦的選項 C**（可訓練、能力值仍累積），裁定全面關閉。

| 功能 | 警告 | 社群功能停權 | 永久停權 |
|------|------|-------------|---------|
| 登入 / 訓練與記錄 | ✅ | ✅ | ❌ |
| 能力值 / 階級 / 排行分數 / 成就 / 金幣 | ✅ | ✅ | ❌ |
| 發文 / 留言 / 按讚 / 私訊 / 關注 / 團隊 / 師徒 | ✅ | ❌ | ❌ |
| 商城購買 / 會員訂閱 | ✅ | ✅ | ❌ |
| **申訴** | ✅ | ✅ | **✅（唯一可用）** |

## 三、教官資格撤銷改為分級

原規則無分級（任何處罰皆撤銷）。改為**社群功能停權以上（累計違規 3 次起）方撤銷，警告不撤銷**。

理由：教官資格須階級 20 ＋ 累積訓練 50 次 ＋ 通過測驗方能取得，以一次警告沒收，級距明顯不對稱。

## 四、AI 訓練品質評分的問題自動消失

助理原詢問「永久停權者的訓練紀錄要不要進 AI 訓練品質評分」。
永久停權者無法訓練，無新紀錄可供評分，**該問題不成立**。

# 連帶修正第 56 題

第 56 題定案「**帳號停權**期間暫停所有計時」，理由為「使用者無法登入」。
帳號停權級距已移除，該規則**改掛永久停權**，理由完全沿用。

社群功能停權（7 天與 30 天）計時一律照常，因其可正常訓練。

# [已知限制] App Store 訂閱無法由平台終止（已查證）

**開發者無法以程式取消使用者的自動續訂**，此為 Apple 平台規定，非實作難度問題。

| 誰能取消訂閱 | 可否 |
|-------------|------|
| 使用者自己（App Store 設定、或 App 內 `showManageSubscriptions`） | ✅ |
| Apple 客服 | ✅ |
| **開發者（本平台）** | **❌ 無任何 API** |

**後果：帳號永久停權後，訂閱仍會持續扣款，直到使用者自行取消。**

處理方式：

- 平台於永久停權時將權益標記為失效。
- **必須於停權通知中告知「訂閱不會自動取消，請自行至 App Store 取消」**，並提供直達入口。
- 退款由使用者向 Apple 申請，平台不受理亦無權處理。
- 當期權益不另行處理：使用者無法登入，權益本即無法使用。

[已知風險] 被永久停權而持續遭扣款者將向 Apple 申訴，該類申訴累積可能引來 App Review 關注。

來源：[Apple Developer — Auto-renewable Subscriptions](https://developer.apple.com/app-store/subscriptions/)
