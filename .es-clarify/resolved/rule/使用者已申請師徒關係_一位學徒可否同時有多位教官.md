# 釐清問題

一位學徒可否同時擁有多位教官？一位教官可同時帶多位學徒（受帶徒上限限制），但學徒端是否也有上限？

# 定位

流程：師徒互動流程
元素：Rule：師徒關係已建立的 Precondition；Aggregate：師徒關係的關聯關係
細節：Precondition 數量限制（C1）；Aggregate 關聯關係（D4）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 學徒同時僅能有一位教官，教官可帶多位學徒（一對多） |
| B | 學徒可有多位教官（上限如 3 位），教官可帶多位學徒（多對多） |
| C | 學徒同時僅能有一位教官，且解除後需冷卻期才可另拜他人 |
| D | 多對多且雙方皆無上限，僅受教官帶徒上限限制 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響師徒關係 Aggregate 的關聯關係（一對多或多對多）、師徒關係已建立的 Precondition、教官已指派師徒任務的作用對象、以及師徒任務獎勵的發放對象。

# 優先級

Medium

# 既有約束（來自已解決項目）

第 52 題（`resolved/aggregate/教官帶徒上限_帶徒上限的初始值與提升幅度.md`）已裁決：
**教官端**的帶徒上限為初始 1 人、每達聲望門檻 +1、最大 5 人，
且申請中的申請即佔用名額。

本題問的是**學徒端**：一位學徒可否同時有多位教官，以及是否有數量上限。
兩者為不同方向的限制，本題仍須獨立回答。

# 解決結果

**選項 A** —— 學徒同時僅能有一位教官，教官可帶多位學徒（一對多）。學徒端不另設冷卻期，既有「解除後 3 天」規則已涵蓋。
