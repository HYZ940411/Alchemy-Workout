# 釐清問題

「隊長已邀請成員」與「使用者已申請加入團隊」若無人回應，是否逾期失效？待回應的邀請 / 申請是否佔用團隊 5 人名額？

# 定位

流程：團隊組隊流程
元素：Rule：Event「隊長已邀請成員」「使用者已申請加入團隊」的後續路徑與 Precondition
細節：C3 時間邊界、C1 名額佔用的前置條件。
不對稱處：師徒申請有「接受 / 拒絕 / **逾期**」三分支且已定案 168 小時時限並佔用帶徒名額；團隊的兩條路徑只有接受與拒絕兩分支，亦未定義名額佔用。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 比照師徒申請：時限 168 小時（7 天），逾期補立「團隊邀請已逾期」「加入申請已逾期」兩個 Event，且待回應期間佔用 5 人名額 |
| B | 設時限並補 Event，但**不佔用名額**：名額僅由已加入的成員計算，超收由核准當下的 Precondition 擋下 |
| C | 不設時限、不補 Event：邀請與申請永久有效，直到被接受、拒絕，或團隊滿員時由 Precondition 自動擋下 |
| D | 不設時限，但團隊滿員時既有的待回應邀請與申請一律自動失效 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響團隊組隊流程的 Event 清單與〈Command 清單〉、「使用者已加入團隊」的 Precondition（團隊人數未達上限 5 人）之計算口徑、以及同一使用者可否同時對多個團隊送出申請。
相關待釐清項目：`rule/使用者已建立團隊_一位使用者可否同時加入多個團隊.md`、`rule/使用者已退出團隊_隊長退出前是否須先轉讓隊長.md`、`rule/團隊已解散_解散時既有團隊分數與排行榜名次如何處理.md` — 同屬團隊生命週期組，宜併題處理。
相關已解決項目：`resolved/command/使用者已加入團隊_加入團隊的觸發方式為邀請或申請.md`、`resolved/rule/師徒申請已逾期_逾期的時限長度為何.md`。

# 解決結果

**選項 B** —— 邀請與加入申請皆設 168 小時（7 天）時限，逾期補立「團隊邀請已逾期」與「加入申請已逾期」兩個 Event；**待回應狀態不佔用 5 人名額**。
