# 釐清問題

團隊日常分數定義為「全體成員個人排行榜月累計分數的加總」，但另有兩條規則要求它不包含某些分數（重新分隊期 2 天內不累加、中途加入者僅貢獻加入後產生的分數）——加總的定義與這兩條扣除規則如何並存？

# 定位

流程：團隊任務流程
元素：Aggregate — 團隊分數（團隊日常分數）；Rule — 團隊日常分數的計算方式
細節：`02_Aggregate定義.md`〈團隊分數 Aggregate〉「直接沿用成員的個人排行榜月累計分數，不另定一套計分規則」 vs 同檔〈重新分隊期〉「團隊日常分數不累加、個人排行榜分數照常累積」 vs `團隊任務流程.md`「中途加入者僅能貢獻加入後產生的分數」

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 改為增量累加：團隊日常分數為獨立計數器，成員每次「個人排行榜分數已增加」時，若當下不在重新分隊期且該成員已在隊中，即同額累加至團隊；不再定義為「加總」 |
| B | 維持加總定義，改為「加總各成員自加入時點起、且不在重新分隊期內產生的分數」，須為每位成員記錄一個「本隊已貢獻分數」欄位 |
| C | 取消重新分隊期的「不累加」規則，改為僅限制換隊（期間可換隊但分數照算），使加總定義成立 |
| Short | 提供其他簡短答案（<=5 字） |

# 解決結果

**A**：改為**增量累加**，不再定義為「加總」。

- 團隊日常分數為團隊自有的計數器，於成員每次「個人排行榜分數已增加」時同額累加。
- Precondition：該成員於得分當下為本團隊成員，且該時點不在重新分隊期內。
- 累加量與該次個人得分同額，不另定一套計分規則（計分方式相同、計入時機不同）。
- **須記錄各成員的「本隊已貢獻分數」**：僅看成員的個人月累計分數無法還原其對本隊的貢獻。
- 兩條防漏洞規則因此成立：中途加入者不帶入舊分數（防輪流加入灌分）、
  重新分隊期不計分（防月初跳槽套利）。
- **不採維持「加總」措辭**（B）：該數字實際上不是加總，沿用該詞會使後續閱讀者再次誤會。
- **不採取消重新分隊期的不累加規則**（C）：該機制仍有作用。
- 個人排行榜分數不受影響，照常累積。

**被推翻的既有共識**：「團隊日常分數 ＝ 全體成員個人排行榜月累計分數加總，不另定一套計分規則」。
