# 釐清問題

「排行榜已重置」時分數是歸零還是保留？歷史排名紀錄是否保存？個人排行榜分數與經驗值是否一併歸零？

# 定位

流程：排行榜週期結算流程
元素：Rule：排行榜已重置的 Postcondition；Aggregate：個人排行榜分數、團隊日常分數、團隊限時分數
細節：Postcondition 原子化與涵蓋所有被改變的欄位（C2）；狀態邊界（C3）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 三種排行榜分數全部歸零，保存歷史週期排名快照，經驗值不受影響 |
| B | 分數全部歸零，不保存歷史，經驗值不受影響 |
| C | 分數衰減 50% 而非歸零（軟重置），保存歷史排名 |
| D | 僅團隊限時分數歸零，個人與團隊日常分數累計不歸零 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響排行榜已重置的 Postcondition、三個分數 Aggregate 的生命週期、是否需要「歷史排名」Aggregate、以及排行榜 Read Model 的資料來源。

# 前置裁決（2026-08-01 第三輪第 17 題）

排行榜週期已定案為四個榜：個人週榜（週一 04:00）、個人月榜（每月 1 日 04:00）、
團隊日常排行榜與團隊限時排行榜（皆同個人月榜）。

本項目作答時須分別考慮週榜與月榜，且三個相關 Event 皆攜帶榜別。
