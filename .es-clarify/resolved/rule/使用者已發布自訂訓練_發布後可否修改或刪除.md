# 釐清問題

自訂訓練已發布或已通過公開審核後，原作者可否修改或刪除？已有他人使用中的課表如何處理？

# 定位

流程：自訂訓練流程（循環 1：使用者已選擇動作 - 使用者已設定該動作的組數、循環 2：使用者已設定該組的重量 & 次數）
元素：Rule：使用者已發布自訂訓練的可逆性；Aggregate：自訂訓練與訓練紀錄的關聯
細節：可逆操作是否已定義對應 Event（C4）；關聯的生命週期（D4）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 可隨時修改與刪除，使用中的他人課表沿用刪除前的快照版本 |
| B | 可修改但需重新審核；刪除則僅下架，既有使用者仍可繼續使用 |
| C | 已公開者不可修改不可刪除，只能下架並發布新版本 |
| D | 可自由修改，他人使用中的課表即時同步變更 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響是否需新增「自訂訓練已修改 / 已下架」Event、自訂訓練 Aggregate 是否需要版本欄位、訓練紀錄 Aggregate 與自訂訓練的關聯生命週期、以及重新審核的 Precondition。

# 優先級

# 既有約束（來自已解決項目）

第 40 題（`resolved/aggregate/自訂訓練_已儲存與已發布與已申請公開三個狀態的狀態機.md`，選項 B）已裁決：
自訂訓練有五個狀態，已發布可經「使用者已取消發布自訂訓練」退回已儲存（私人）。
故「發布後可否**取消發布**」已定案為可以；本題僅剩「發布後可否**修改內容**與**刪除**」待確認。

# 解決結果

**選項 B，範圍限縮在「已公開」狀態**

| 狀態 | 修改 | 刪除 |
|------|------|------|
| 已儲存 | 自由 | 自由 |
| 已發布（僅關注者可見、未經審核） | **自由，不需審核** | 自由 |
| 已公開（管理員審核通過） | **須重新審核** | 僅下架，不硬刪除 |

- `已公開` 修改須重新審核的理由：防「送審時放正常課表 → 過審後改為危險內容」的規避漏洞，
  與〈貼文 Aggregate〉保留編輯歷史所防範者為同一類。
- 下架後他人無法再選用，但進行中的訓練不受影響（快照脫鉤原則）。
- **不採 D**（他人使用中即時同步變更）：本次訓練課表快照使即時同步在架構上不成立。

# 助理推導（非使用者裁決）

- `已公開` 修改後轉回 `已申請公開`，重新審核期間暫時退出公開清單。
  未採版本化做法（保留舊版、審核通過才取代），成本高於效益。
- 新增兩個狀態轉換，連帶新增兩個 Event：
  「使用者已修改自訂訓練」「使用者已下架自訂訓練」。
