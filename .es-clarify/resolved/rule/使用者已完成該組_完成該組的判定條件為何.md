# 釐清問題

「使用者已完成該組」的判定條件為何？必須同時記錄重量與次數才算完成嗎？

# 定位

流程：訓練紀錄流程（循環：使用者已記錄重量 > 組間休息已結束）
元素：Rule：使用者已完成該組的 Precondition
細節：Precondition 原子化與可驗證性（C1）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 同時記錄重量與次數即自動視為完成，無需額外操作 |
| B | 記錄重量與次數後，仍需使用者主動點擊「完成該組」才成立 |
| C | 記錄次數即完成（重量可留空，視為自身體重） |
| D | 記錄重量與次數後，組間休息開始即視為該組完成 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響使用者已完成該組的 Precondition、與記錄重量 / 次數兩個 Event 的因果關係、訓練進度條已增加的觸發時點、以及逾時中斷判定的計時歸零時點。

# 優先級

High

# 解決結果

**選項 B（使用者自訂：checkbox）＋ 追問選項 A**

- Precondition：使用者於該組列**最左側的完成 checkbox 勾選**，方可發生「使用者已完成該組」。
- 勾選 checkbox **同時成立**「使用者已記錄該組成績」與「使用者已完成該組」，
  兩者為同一次操作的兩個事實。
- 未修改預帶值即勾選者，以**快照帶入的目標重量與次數**作為實績寫入。
- 不以「記錄重量與次數」本身作為完成判定；未勾選者該組不計入已完成組數。

理由：每一組皆須落一筆實績 —— 訓練量為「重量 × 次數 × 組數逐組累加」，
無實績的組對六維能力值的貢獻為零。

不採「實際次數達目標次數才算完成」：力竭做不滿為訓練常態，該組同為有效訓練。
不採「組間休息開始即視為前一組完成」：最後一組之後沒有休息，將永遠無法完成。
