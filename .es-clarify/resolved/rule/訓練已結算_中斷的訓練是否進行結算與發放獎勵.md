# 釐清問題

因逾時而「使用者訓練已中斷」的訓練，是否仍進行結算並發放訓練獎勵？是否計入連續訓練天數？

# 定位

流程：訓練結算流程、訓練紀錄流程（循環：使用者已記錄重量 > 組間休息已結束）
元素：Rule：訓練已結算的 Precondition
細節：狀態邊界與例外路徑（C3、C5）；跨流程串聯一致性（E1）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 中斷的訓練不結算、不發獎、不計入連續訓練天數 |
| B | 中斷的訓練照常結算並依已完成組數按比例發獎，計入連續訓練天數 |
| C | 中斷的訓練結算並發獎，但不計入連續訓練天數與成就門檻 |
| D | 達到最低完成門檻（如 50% 進度）才結算發獎，否則作廢 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響訓練已結算的 Precondition、連續訓練已紀錄的判定、訓練獎勵已發放與能力值 / 經驗值提升的條件、以及訓練中斷流程連續訓練中斷判定的計時是否重設。

# 優先級

High

# 解決結果

**選項 B｜照常結算、依已完成組數發獎、計入連續訓練天數**

- 三種終止 Event（已完成訓練 / 已提前結束訓練 / 單次訓練已逾時中斷）的**結算待遇相同**。
- 依已完成組數計算能力值、經驗值與個人排行榜分數。
- **計入連續訓練天數**。
- 使用者補充：「單次訓練已逾時中斷」的結算結果於**使用者下次開啟 App 時以結算畫面呈現**。

理由：能力值、經驗值、排行榜分數皆按實際訓練量逐組累加，未完成的組本就不產生訓練量，
無須再設門檻罰一次；逾時中斷最常見的原因為練畢未按結束而非未訓練，
扣除連續天數等於懲罰確實有訓練者。

不採 A：與既有裁決「已中斷的訓練仍進入訓練結算流程」直接衝突。
不採 C：擋錯對象，未完成的部分本就不產生訓練量。
不採 D：50% 門檻會製造新的邊界問題（49% 與 51% 的差別、空白課表如何算百分比）。
