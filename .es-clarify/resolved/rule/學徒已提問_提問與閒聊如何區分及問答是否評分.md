# 釐清問題

學徒的訊息如何被判定為「提問」而非閒聊？「學徒已提問」由什麼觸發？
師徒問答是否應逐次評分並連動教官聲望？

# 定位

流程：師徒互動流程、聊天私訊流程
元素：Event「學徒已提問」的觸發來源；師徒問答與私訊兩個 Aggregate 的邊界；教官聲望的來源
細節：本項目非由 discovery 掃描產出，為**使用者於第五輪第 16 題進行中主動提出**。

現況缺口：模型有「學徒已提問」Event 與師徒問答 Aggregate，
但**無任何規則說明它由什麼觸發**；私訊 Aggregate 獨立存在，兩者無關聯。
因每次問答皆可評分且直接加減教官聲望，若閒聊亦視為問答，聲望將成為聊天頻率的函數。

# 多選題（提問與閒聊的區分）

| 選項 | 描述 |
|--------|-------------|
| A | 提問為獨立 Command，學徒明確發起；閒聊走既有私訊 |
| B | 同一對話介面，學徒發訊時自行勾選「這是提問」 |
| C | 教官將某則私訊標記為問答後才成立 |
| D | 師徒之間所有私訊皆視為問答 |

# 優先級

High

# 解決結果

## 一、提問與閒聊的區分：選項 A

**提問為獨立 Command，師徒問答維持獨立 Aggregate**，呈現上內嵌於師徒對話串
（單一入口、兩種動作：直接打字為閒聊，點「提問」產生問答）。

- **不採 C**：教官控制哪些算問答，等同可藉「不標記」規避差評。
- **不採 B**：私訊 Aggregate 須掛師徒問答 ID，兩個 Aggregate 的邊界被打穿。
- **不採 D**：閒聊亦計為問答時，聲望成為互動次數的函數而非指導品質的函數。

### 助理撤回的提案

助理曾提議「教官可建議轉換某則私訊為提問、須學徒確認」。
使用者質疑後**由助理主動撤回** —— 該機制解決的是假想問題（學徒搞不清入口），
代價卻是新增 2 個 Event、1 個 Command 與跨 Aggregate 關聯。
承「能不加就不加」原則，待實際出現困擾再議。

## 二、問答是否評分：選項乙（推翻既有裁決）

**問答不評分。** 移除師徒問答的學徒評分欄位與「學徒已評分該次問答」Event。

推翻的理由：

- 逐次問答評分的尺度過於敏感：初始聲望 15、第一門檻 30、5 星 +3、1 星 −2，
  約 5 次好評即升級、約 8 次差評即歸零。
- 實際評分者多為特別滿意與特別不滿的兩端，中間沉默 ——
  聲望反映的將是情緒樣本而非指導品質。

**被推翻的既有共識**：
`resolved/aggregate/教官已指派師徒任務_師徒任務與問答的Aggregate歸屬與欄位.md`（選項 A）
的「問答需獨立 ID 以承接評分」與「評分連動教官聲望」兩條。
該檔的 Aggregate 分立結論**不受影響**，仍然成立。

## 三、新增「每週互動評分」（使用者提出）

| 項目 | 內容 |
|------|------|
| 評分對象 | 師徒關係 Aggregate |
| 頻率 | 每位學徒每週最多一次 |
| 週期基準 | 統一每週一 04:00 |
| Precondition | 該週內雙方有互動（問答、師徒任務進度、或私訊往來）方可評分 |
| 未評分 | 聲望無變動，不視為差評 |

Precondition 為必要：無此條件時掛著不動的師徒關係亦可每週刷聲望。

新增 Event「學徒已評分該週互動」、Command「評分該週互動」（Actor：學徒）、
師徒關係 Aggregate 新增欄位「最近一次評分所屬週」。

## 四、兩張換算表（使用者指定數值）

| 學徒評分 | 師徒任務評分 | 每週互動評分 |
|----------|-------------|-------------|
| 1 星 | −1 | −2 |
| 2 星 | 0 | 0 |
| 3 星 | +1 | +4 |
| 4 星 | +2 | +8 |
| 5 星 | +3 | +12 |

初始聲望 15 與四個門檻 30 / 75 / 150 / 300 **維持不變**。

## 五、師徒任務評分的每週計分上限（選項 A ＋ 使用者改為 2 次）

**每位學徒每週最多 2 次任務評分計入聲望。** 超出者仍可完成、仍發放學徒獎勵，僅不計入聲望。

- 漏洞：指派無上限 ＋ 每個完成任務皆可評分 → 教官狂指派瑣碎任務即可無限刷聲望；
  學徒完成任務亦有獎勵，雙方皆有動機配合，屬合謀型漏洞。
- **不限制指派次數本身**：教官為教學需要多指派屬正當行為，該擋的是計分而非行為。
- 不採「每週聲望增益總上限」：須新增跨來源計數器，且該數值於每次調整換算表後皆須重算。
- 不採「任務評分完全不給聲望」：與選擇乙時「師徒任務有實際成果可評」的理由相衝。
