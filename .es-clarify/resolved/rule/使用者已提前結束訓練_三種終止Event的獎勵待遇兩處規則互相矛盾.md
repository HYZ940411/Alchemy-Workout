# 釐清問題

訓練紀錄流程寫「使用者已完成訓練與使用者已提前結束訓練兩者皆進入訓練結算流程，但**獎勵不同**」，訓練結算流程卻寫「三種終止 Event 的結算待遇**相同**」。兩條規則互相矛盾，何者為準？若獎勵確有差異，差異為何？

# 定位

流程：訓練紀錄流程、訓練結算流程
元素：Rule：Event「使用者已完成訓練」「使用者已提前結束訓練」「單次訓練已逾時中斷」的 Postcondition
細節：C2 後置條件完整性、C3 組合邊界。
矛盾出處：訓練紀錄流程檔第 59 行「[Rule] Postcondition：兩者皆進入訓練結算流程，但獎勵不同」；訓練結算流程檔第 5 行「[Rule] 三種終止 Event 的結算待遇相同：中斷的訓練照常結算，依已完成組數計算能力值、經驗值與個人排行榜分數」。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 以訓練結算流程為準：三者待遇完全相同，一律依實際訓練量計算；刪除訓練紀錄流程檔「但獎勵不同」一句 |
| B | 以訓練紀錄流程為準：能力值 / 經驗值 / 排行榜分數依訓練量計算（三者相同），但「訓練獎勵已發放」的金幣與道具依完成度給予差額（如完成給全額、提前結束與中斷給比例額） |
| C | 三者分級：已完成給全額、已提前結束給比例額、逾時中斷給最低額 |
| D | 以完成率（已完成組數 / 總計畫組數）為單一計算基準，不依終止 Event 類型分級；空白課表視為完成率 100% |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響三個終止 Event 的 Postcondition、獎勵定義 Aggregate 是否需依終止類型分列內容、以及「不採由使用者自述完成或提前結束（無人會選擇較低獎勵的選項）」此一既有決策的前提是否仍成立 —— 若採選項 A，該決策的理由即失效，須一併修訂。
相關已解決項目：`resolved/rule/訓練已結算_中斷的訓練是否進行結算與發放獎勵.md`、`resolved/event/使用者已結束訓練_提前結束與全部完成是否為同一Event.md`。

# 解決結果

**選項 B ＋ 使用者補充：逾時中斷但全部完成時給 100%**

矛盾的解法為「兩者皆部分成立」：

| 項目 | 待遇 |
|------|------|
| 能力值、經驗值、個人排行榜分數 | **三種終止 Event 相同**，一律依實際訓練量計算 |
| 訓練獎勵的金幣 | **依完成度給差額** |

**金幣差額表**（基準 30）

| 終止 Event | 條件 | 係數 | 實得 |
|------------|------|------|------|
| 使用者已完成訓練 | — | 100% | 30 |
| 使用者已提前結束訓練 | — | 70% | 21 |
| 單次訓練已逾時中斷 | 已完成組數 ＝ 總計畫組數 | 100% | 30 |
| 單次訓練已逾時中斷 | 已完成組數 < 總計畫組數 | 50% | 15 |

- 〔推導〕空白課表（總計畫組數為 0）不適用完成度比較，逾時中斷一律套用 50%
- 完成度係數與連續訓練獎勵加成皆為乘法，**套用順序不影響結果**
  （30 × 0.7 × 1.3 ＝ 30 × 1.3 × 0.7），不需另訂順序，
  故不會出現能力值那種套用順序爭議（I11）

「逾時中斷但全部完成給 100%」為使用者主動補充，其依據為既有裁決
「逾時中斷最常見的原因為**練畢未按結束**而非未訓練」—— 該情形實質等同完成，不應罰。

# 既有裁決的影響確認

既有決策「不採由使用者自述完成或提前結束（無人會選擇較低獎勵的選項）」**維持不變**：
本裁決下較低獎勵確實存在（提前結束 70%），該決策的理由仍然成立。
（若當初採選項 A「三者完全相同」，此理由將失效，故本結果較 A 更少連帶修訂。）
