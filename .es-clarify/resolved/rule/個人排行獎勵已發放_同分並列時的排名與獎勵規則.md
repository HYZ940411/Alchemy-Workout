# 釐清問題

排行榜結算時若出現同分並列，排名與獎勵如何決定？

# 定位

流程：排行榜週期結算流程
元素：Rule：個人排行獎勵已發放 / 團隊日常排行獎勵已發放 / 團隊限時排行獎勵已發放的 Precondition
細節：數值邊界與臨界值（C3）；規則套用順序（C3）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 同分並列同名次，皆發放該名次獎勵，下一名次順延跳號 |
| B | 同分時以達到該分數的時間先後決定排名，不並列 |
| C | 同分時以訓練總量等次要指標決定排名，不並列 |
| D | 同分並列同名次，獎勵由該名次與後續名次的獎勵平均分配 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響三種排行獎勵已發放的 Precondition 與計算、排行榜 Aggregate 是否需記錄達成時戳、以及排行榜 Read Model 的排序規則。

# 優先級

Medium

# 前置裁決（2026-08-01 第三輪第 5 題）

個人排行榜已定案為**階級區間分組**（每 10 階一組，共 10 組），排名與獎勵**僅於組內比較**，
顯示為「自己上下各 10 名」的視窗，即時性為延遲更新。
本項目作答時，所有「名次」「前 N 名」一律指**組內名次**，不再是全平台名次。

*來源：`resolved/read-model/排行榜_排行榜的顯示範圍排序與即時性要求.md`*

# 前置裁決（2026-08-01 第三輪第 17 題）

排行榜週期已定案為四個榜：個人週榜（週一 04:00）、個人月榜（每月 1 日 04:00）、
團隊日常排行榜與團隊限時排行榜（皆同個人月榜）。
同一次得分同時累加至週累計與月累計兩個獨立計數器，各自歸零。
本項目作答時須分別考慮週榜與月榜，且三個相關 Event 皆攜帶榜別。

*來源：`resolved/rule/排行榜週期已結算_排行榜週期的長度與起訖時點為何.md`*

# 解決結果

**選項 A** —— 同分並列同名次，皆發放該名次獎勵，下一名次順延跳號。
