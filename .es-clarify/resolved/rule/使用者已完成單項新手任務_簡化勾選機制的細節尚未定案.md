# 解決結果

**選項 A**：確認現行規則即為定案，本題實為「答案已存在、僅未移除待決策標記」。

| 子問題 | 裁決 |
|--------|------|
| 是否記錄實際次數 | **不記錄**。獎勵固定，做幾下不影響任何結果，記錄的數值無任何下游消費者；未達目標次數仍可勾選，系統不驗證執行量 |
| 可否取消勾選 | **可取消**。取消後該組回到未完成，「使用者已完成新手任務」隨之不可發生 |
| 連帶的請求識別碼 | 使用者 ID ＋ 任務項目 ID ＋ **勾選序號**，同一項目可重複發生 |
