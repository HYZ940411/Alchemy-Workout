# 釐清問題

「週期開始 指派管理員設定的限時任務」與排行榜週期結算流程的「每週期結束」中，「週期」的長度與起訖時點為何？兩者是否為同一週期？

# 定位

流程：團隊組隊任務流程、排行榜週期結算流程
元素：Rule / Policy：週期開始指派管理員設定的限時任務；每週期結束 → 依排名發放排行獎勵
細節：模糊描述未量化（F4）；時間邊界與跨時區（C3）；跨流程術語一致性（F1）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 一週為一週期，每週一當地時間 04:00 起算，個人 / 團隊日常 / 團隊限時共用同一週期 |
| B | 一週為一週期，統一使用 UTC+8 週一 00:00 起算，三種排行榜共用 |
| C | 個人與團隊日常排行榜為週週期，團隊限時任務為獨立自訂週期，由管理員設定 |
| D | 一個月為一週期，每月 1 日起算 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響團隊已指派限時任務與排行榜週期已結算的觸發時點、排行榜 Aggregate 的週期欄位定義、與每日任務 04:00 重置的時區一致性、以及三種排行榜是否需獨立週期欄位。
