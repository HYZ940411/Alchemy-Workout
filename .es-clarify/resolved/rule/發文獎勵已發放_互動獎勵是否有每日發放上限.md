# 釐清問題

分享 / 發文 / 按讚 / 留言四種互動獎勵是否有每日發放次數上限？是否有防刷規則（如自己貼文按讚不計）？

# 定位

流程：發文與互動流程
元素：Rule：四種互動獎勵已發放的 Precondition
細節：數值邊界與數量限制（C1、C3）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 四種行為各有每日獎勵上限次數，超過仍可操作但不發獎，且自己的貼文互動不計 |
| B | 無每日上限，但同一貼文的同一種互動僅計一次獎勵 |
| C | 有每日上限且自己的貼文不計，另外新帳號需完成新手任務才可獲得互動獎勵 |
| D | 無任何上限與防刷規則 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響四種獎勵已發放的 Precondition、累計互動成就門檻的計數基準、每日任務流程中社群互動累計進度的計算、以及團隊日常分數的來源。

# 延後（2026-08-03，第五輪第 21 題）

**本項目延後，待使用者重跑 `/es-discovery` 後再回答。**

## 延後理由

本項目的前置為**金幣對法幣比率**，而該比率於本輪確認**不可由獎勵數額或商品價格反推**。

正確的設定順序為：

```
1. 儲值 SKU（花多少錢買多少金幣）→ 決定比率
2. 虛擬道具標價（以儲值為基準）
3. 免費獎勵（設為一筆小額儲值的一小部分）
```

模型現況為反向填入 —— 先有第一批獎勵數額與補簽券售價，比率反而未定。
在比率與儲值 SKU 定案前，本項目的數額無錨點可依循。

詳見 `00_全域規範.md`〈虛擬貨幣經濟的設定順序〉。

## 一併延後的項目

1. 儲值 SKU 面額與贈送規則
2. 金幣對法幣比率
3. 虛擬道具標價的重新校準（含補簽券 150 金幣）
4. 各獎勵來源的金幣數額（第一批複核、第二批、第三批）
5. 實體商品採金幣標價或里程碑兌換
6. **成就獎勵的發放路徑與數額**（獨立於三批之外的缺口）

# 解決結果（2026-08-09，虛擬貨幣群組第 9 題）

**A** —— 四種行為各有每日獎勵發放上限，且自己的貼文不計。

| 行為 | 每日上限 |
|------|---------|
| 發文 | **1** |
| 分享 | **3** |
| 按讚 | **10** |
| 留言 | **5** |

（數值由使用者給定，較助理建議的 3 / 3 / 20 / 10 更嚴。）

## 本題的金幣部分已於第 8 題自動解消

第 8 題定案**社群互動不給金幣，只給經驗值**，故原題的「金幣每日上限」問題消失。

## 但經驗值上限仍為必要 —— 且比原本更必要

**互動獎勵的經驗值推動階級，而階級在近兩輪變得值錢得多**：

| 階級解鎖 | 何時新增 |
|---------|---------|
| 進階訓練計畫（10 / 25 / 45 / 70） | 既有 |
| **自訂訓練名額 2 → 5**（25 / 45 / 70） | 本輪第 6 題 |
| **第 9 類階級成就** | 第八輪第 24 題 |
| 教官初審門檻（階級 ≥ 20） | 既有 |

**無上限則按讚數百次即可繞過上述四者。**

## 附帶規則

- **超過上限仍可正常操作，僅不再發放經驗值** —— 不擋行為本身。
  擋住按讚與留言會使社群變冷清，而社群活躍本身即為平台所欲。
- **自己的貼文不計**：否則自己發文、自己按讚留言，一人即可循環刷。
- 上限以當地 04:00 換日，沿用模型唯一的換日時點。
- 四項上限皆為平台級可調參數。

## 兩個不採方案

| 方案 | 為何不採 |
|------|---------|
| 「同一貼文的同一種互動只計一次」作為唯一防線 | 僅防重複按同一篇，而動態牆的貼文數無上限，滑一小時按數百篇仍可拿滿 |
| 新帳號須完成新手任務方可取得互動獎勵 | 新手任務為三選一、做一次即完成，擋不住有心刷者，卻使正常新使用者前幾天的互動拿不到獎勵；且模型已有「社群互動功能需解鎖」機制 |

## 本題留下的已知風險

`[已知風險]` **成就計數不受每日上限約束**（成就計的是行為次數，與獎勵發放與否無關），
故互動成就仍可被快速刷開。其總量有界（每個門檻終身僅解鎖一次），
但**成就獎勵的數額須將此納入考量** → 已併入
`aggregate/成就獎勵_發放路徑與數額尚未建模.md`。
