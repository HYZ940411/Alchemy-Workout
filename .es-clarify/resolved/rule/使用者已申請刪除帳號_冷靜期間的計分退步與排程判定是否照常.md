# 釐清問題

帳號刪除的 30 天冷靜期內「帳號停用、資料保留」，但期間各排程判定是否照常執行未定：能力值每 240 小時退步、連續訓練天數 36 小時歸零、連續簽到中斷、每日任務重置、排行榜週期結算是否仍將該使用者納入計算。30 天足以使能力值退步 3 次（約 −14%），若使用者於第 29 天取消刪除申請，回來時可能發現能力值已大幅下降。

# 定位

流程：註冊流程、訓練中斷流程、每日簽到流程、排行榜週期結算流程
元素：各排程 Event（能力值已退步、簽到連續天數已中斷、連續訓練天數已歸零）的 Precondition
細節：待刪除狀態是否暫停所有計時，比照既有規則〈永久停權期間暫停所有計時〉的處理方向。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 比照永久停權的既有規則：待刪除期間暫停所有計時（能力值退步、連續訓練、連續簽到），取消刪除申請時以取消時點重設所有計時基準，連續天數與獎勵加成保留（**推薦**：模型已有現成判例〈停權期間的計時處理〉，理由完全相通——以「未使用」處罰一個被系統擋在門外的人不合理，待刪除期間帳號同樣停用無法使用） |
| B | 冷靜期間計時照常進行，不特殊處理；使用者取消刪除申請時承擔期間累積的退步與中斷 |
| C | 待刪除期間自排行榜與團隊分數排除計算，但能力值退步等計時維持照常 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響帳號刪除冷靜期的實際體驗、與〈使用者已受處罰_停權期間的訓練與能力值退步與連續天數如何處理〉為同一組決策，建議併同處理。

# 解決結果

**選項 B**：冷靜期間所有計時與排程判定一律照常，取消刪除申請後不補償、不回捲。

**助理原推薦 A（比照停權暫停計時），經使用者追問「為什麼不推薦 B」後推薦反轉。**

助理原推薦的唯一理由是「模型已有〈停權期間的計時處理〉的判例可套用」，但未檢查該判例的
**理由**是否可轉移。停權那條規則的原話為「以『未訓練』處罰一個**被系統擋在門外**的人，
等於拿他做不到的事罰他」——停權係平台單方施加，使用者想練也練不了；
而申請刪除為使用者自願，其未訓練是自己的選擇，該理由於此根本不成立。
**此為「看到形狀相似即套用判例、未檢查判例理由是否適用」的錯誤形態。**

選 B 的兩個實質理由（皆為 A 所無）：

1. **能力值退步不是懲罰，是量測**：承模型否決「相對百分位」時的既有理由——
   「等級會在使用者沒有訓練時變動，與『能力值代表身體能力』的定義衝突」。
   30 天未訓練肌力確實下降，暫停計時反使能力值不再反映身體實況。
2. **回歸任務即為本情境的既有解方**：能力值退步會觸發回歸任務指派，
   而「申請刪除又取消」者恰為全模型最該被召回的對象。暫停計時等於關掉唯一為其設計的
   召回機制；照常計時則其一回來即有回歸任務，完成後另可部分回復 50% 的累積退步量。
