# 釐清問題

可對哪些對象發送私訊？是否需要互相關注、師徒關係或其他前置條件？

# 定位

流程：聊天私訊流程
元素：Rule：使用者已建立對話 / 使用者已發送私訊的 Precondition
細節：Precondition 完整性與權限檢核（C1）；誰不能執行此 Command（B5）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 任何人皆可對任何人發送私訊，無限制 |
| B | 需互相關注才可發送私訊 |
| C | 需互相關注或具師徒關係或同團隊成員才可發送 |
| D | 任何人皆可發送，但收訊方可設定僅接收互相關注者的訊息 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響建立對話與發送私訊 Command 的 Precondition、使用者 Aggregate 是否需要私訊偏好設定欄位、與關注流程 / 師徒互動流程 / 團隊流程的依賴關係、以及騷擾防範設計。

# 優先級

High

# 解決結果

**選項 C ＋ 陌生訊息** —— 互相關注 / 師徒關係 / 同團隊三者滿足其一可直接發送；不符者仍可發送，但訊息歸類為**陌生訊息**，於對話清單分區呈現。

私訊 Aggregate 新增「訊息分類」欄位（一般訊息 / 陌生訊息），於發送當下依雙方關係判定並固定，其後關係變化不回溯改寫。
