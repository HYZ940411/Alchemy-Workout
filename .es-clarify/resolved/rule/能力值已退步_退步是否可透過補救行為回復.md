# 釐清問題

「能力值已退步」之後，使用者是否可透過恢復訓練將能力值補回？回復速度與退步速度是否對稱？

# 定位

流程：訓練中斷流程
元素：Rule：能力值已退步的 Postcondition；可逆性
細節：單調遞增與可逆性（C4）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 不可直接補回，只能透過正常訓練重新累積能力值 |
| B | 回歸任務完成後一次性補回退步的能力值，需補上對應 Event |
| C | 恢復連續訓練 N 天後自動補回，需補上「能力值已回復」Event |
| D | 退步不可逆，且不影響歷史最高能力值紀錄 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響能力值 Aggregate 是否需記錄歷史最高值、是否需新增「能力值已回復」Event、與回歸任務流程「回歸任務獎勵已發放」的內容關係、以及階級提升流程的階級穩定性。

# 既有約束（來自已解決項目）

第 6 題（`resolved/event/回歸任務已指派_與訓練中斷流程同時觸發時如何協調.md`，選項 D′）已裁決：
能力值退步**可**透過完成回歸任務部分回復，對應 Event 為「能力值已部分回復」。
本題僅剩「回復幅度」待量化（使用者表述為「合理範圍內回復一點點」），
「可否回復」不再重新討論。

# 解決結果

**選項 A｜各維回復「本次中斷累積退步量」的 50%**

- 該維回復點數 ＝ 該維本次中斷累積退步量 × 50%（回復比例為平台級可調參數）。
- 六維各自獨立回復，**不論該維是否於回歸任務中被訓練**。
- 使用者 Aggregate 新增欄位「本次中斷各維累積退步量」（6 維 int，≥ 0），
  每次退步時累加，該維恢復訓練時歸零。
- 回復比例 < 100%，自然保證「不回復至退步前水準」。

不採 B（抵銷一次退步）：幅度與停練長度脫鉤，停練半年（−60%）只補 2.5%，形同無感。
不採 C（固定點數）：對高能力值者是零頭、對低能力值者可能一次補滿，跨使用者不對稱。
不採 D（僅回復已訓練維度）：該維訓練本身已產生「能力值已提升」，會重複計酬。
