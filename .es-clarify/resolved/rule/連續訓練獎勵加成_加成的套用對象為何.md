# 釐清問題

「連續訓練獎勵加成 每連續一天 +1%，上限 30%」的加成，套用對象是哪些數值？

# 定位

流程：訓練結算流程
元素：Rule / Policy：連續訓練獎勵加成（每連續一天 +1%，上限 30%）；Event：使用者已獲得獎勵加成
細節：Postcondition 涵蓋所有被改變的欄位（C2）；數值邊界（C3）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 僅套用於經驗值 |
| B | 套用於經驗值與能力值 |
| C | 套用於經驗值、能力值與個人排行榜分數 |
| D | 套用於經驗值、能力值、個人排行榜分數與虛擬貨幣等所有訓練獎勵 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響使用者已獲得獎勵加成的 Postcondition、能力值已提升 / 經驗值已提升 / 個人排行榜分數已增加三個 Event 的計算基數、以及排行榜公平性設計。

# 優先級

High

# 既有約束（來自已解決項目）

第 43 題（`resolved/aggregate/個人排行榜分數_分數的計算公式為何.md`，選項 A）已裁決：
個人排行榜分數的訓練結算來源依訓練量換算，但**未預設**連續訓練加成是否套用於分數。
本題須明確回答加成的套用對象是否包含個人排行榜分數。

# 解決結果

**選項 A｜僅套用於訓練獎勵（虛擬貨幣與道具）**

- 加成不套用於經驗值、能力值、個人排行榜分數。

理由：
- **能力值**為實力指標且有對稱的退步機制，加成後六維反映的將是出勤而非實力，
  而出勤已由連續訓練天數自行記錄。
- **個人排行榜分數**為跨使用者競爭，加成為複利式優勢，
  會使「連續 30 天隨意練」贏過「每週 3 練但紮實」，落後者永遠追不上，
  與第 5 題階級分組排行的公平性設計方向相反。
- **經驗值**直接決定階級，而階級為教官初審門檻（階級 ≥ 20）與進階計畫解鎖的依據，
  加成會使這些門檻的實際難度因人而異。
