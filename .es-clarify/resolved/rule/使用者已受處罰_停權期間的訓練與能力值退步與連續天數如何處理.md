# 釐清問題

「帳號停權」（限期 30 天）與「永久停權」期間，使用者無法使用 App。此期間的能力值退步、連續訓練天數歸零、連續簽到中斷、回歸任務指派是否照常發生？停權解除後如何回復？

# 定位

流程：管理員管理社群流程、訓練中斷流程、每日簽到流程、回歸任務流程
元素：Rule：Event「使用者已受處罰」的 Postcondition；訓練中斷與連簽中斷的排程判定 Precondition
細節：C3 狀態邊界（在特殊狀態下執行的邊界情況）、C5 例外路徑。
現況：訓練中斷流程的四個門檻（24 / 36 / 96 / 120 小時）與連簽中斷的三個門檻（24 / 36 / 48 小時）皆為系統排程判定，未排除受處罰者；停權 30 天者解除後，能力值將已退步 6 次（約 −14%），且連續天數歸零、回歸任務可能已逾期。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 停權期間**暫停**所有計時：中斷與退步判定停止，解除停權時以解除時點重設所有計時基準；連續天數與加成保留 |
| B | 照常發生：停權為處罰的一部分，連帶損失即為嚇阻力；解除後與一般久未訓練者相同，由回歸任務挽回 |
| C | 折衷：能力值退步暫停（實力非行為，不應因停權而損耗），但連續訓練天數與連續簽到照常中斷 |
| D | 僅「帳號停權」與「永久停權」暫停計時；「社群功能停權」不影響訓練，計時照常 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響「使用者已受處罰」與「處罰已到期解除」「處罰已撤銷」三個 Event 的 Postcondition、訓練中斷與連簽中斷排程的 Precondition、連續訓練與連續簽到 Aggregate 的計時基準欄位、回歸任務的指派與逾期判定，以及申訴成立（處罰已撤銷）時是否須回捲停權期間發生的退步。

# 解決結果

**選項 D** —— 依處罰種類分別認定：社群功能停權不影響訓練，計時照常；帳號停權暫停所有計時，解除時重設計時基準，連續天數與加成保留。
