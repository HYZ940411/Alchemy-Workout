# 釐清問題

現行規則為「退步下限 ＝ 註冊初始值 10 點」，六維共用、人人一樣
（`訓練中斷流程.md`、`03_能力值.md:36`、`02_Aggregate定義.md:3962` 三處記載一致）。
其後果為：練到 A 級的使用者只要停練夠久，六維會一路退回 10 點（E 級基本段），
與從未訓練者無異。

使用者於 2026-08-21 提出改制：**退步下限改為「該維歷史最高等級往下兩個主階」**，
小節點保留（例：最高 B → 下限 D；最高 A+ → 下限 C+；最高 S++ → 下限 A++），
並先以等級表達、再換算為點數門檻。

本項為能力值核心機制之改動，使用者裁定**需重新釐清、排在本輪最後處理**。

# 定位

流程：訓練中斷流程、回歸任務流程
元素：Rule（不變條件與 Precondition）；Aggregate：能力值（`03_能力值.md`）
細節：D2 欄位定義（須新增「各維歷史最高點數」欄位）、D3 不變條件、C3 狀態邊界

# 影響範圍

- **能力值 Aggregate**：不變條件「各維點數 ≥ 該維初始值」須改為「≥ 該維動態退步下限」；
  可能新增六個「歷史最高點數」欄位。
- **平台級可調參數**：現行「六維註冊初始值 ＝ 退步下限」一條將拆為兩個獨立參數。

  `resolved/rule/能力值已退步_點數已在退步下限時是否仍重複產生本Event.md`（選項 C，

# 解決結果（2026-08-22）

**採用**：退步下限改為「本次中斷前點數所處節點的**主階降 2 階、小節點保留**之下緣，
且不低於該維初始值」。**推翻**既有共識「六維註冊初始值即退步下限」（2026-08-08 定案）。

| 子問題 | 答案 |
|--------|------|
| 3. 「往下兩階」的定義 | 主階減 2、小節點保留（A+ → C+、B → D、A++ → C++） |
| 1. 退不滿兩階者的下限 | 一律取該維初始值 10（新手任務後腿與核心 30） |
| 2. 「歷史最高」指點數或實測值 | **指點數**——實測值系統從未給出、使用者亦看不到；且採實測值會使首次封頂形同虛設 |
| 2b. 退步後「破紀錄」的比較基準 | **跟著降**，以當前點數為基準；PR 訓練紀錄本身不變、永久保留於訓練歷史 |
| 4. 逼近下限時的最後一次退步 | **截斷至下限**；否則永遠碰不到下限，計時器永不停止 |
| 6. 回歸任務的回復是否受單次上限限制 | **不受限**，一次回復到位 |
| 5. 現行各處記載的改寫 | 見〈回寫位置〉 |

**關鍵設計**：「本次中斷前點數」**不新增欄位**，由既有兩欄推導 ——
`本次中斷前點數 ＝ 各維點數 ＋ 本次中斷各維累積退步量`。
該值於中斷期間恆定，故下限不隨退步一路下滑（若下限跟著降，保底機制會自我抵銷）。

**實際效果**：A+ 750 者停練約 5.7 個月觸及 C+ 315；B 480 者約 10 個月觸及 D 100。
改制前兩者皆需 2 年以上才退回 10 點（E 級），與從未訓練者無異。

**曲線不改**：使用者裁定維持 5% ／ 240 小時。查證確認現行退步本即複利遞減曲線
（每次退當前點數的 5%，越低掉得越慢），非線性下降。
