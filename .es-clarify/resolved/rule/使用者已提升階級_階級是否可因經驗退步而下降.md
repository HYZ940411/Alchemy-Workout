# 釐清問題

階級是否只能提升不能下降？訓練中斷流程的「能力值已退步」是否會連帶造成經驗值下降與降階？

# 定位

流程：階級提升流程、訓練中斷流程
元素：Rule：使用者已提升階級的 Postcondition；單調遞增限制
細節：單調遞增與不可逆性（C4）；跨流程一致性（E3）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 階級單調遞增，永不下降；能力值退步不影響經驗值與階級 |
| B | 經驗值可因中斷而下降，階級隨之下降，需補上「使用者已降低階級」Event |
| C | 經驗值可下降但階級不下降（階級記錄歷史最高），僅顯示當前經驗值 |
| D | 階級不下降，但已解鎖的進階訓練計畫在經驗值低於門檻時暫時鎖定 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響階級 Aggregate 的單調遞增不變條件、是否需新增降階 Event、能力值與經驗值是否為獨立數值、以及進階訓練計畫已解鎖的可逆性。

# 優先級

High

# 既有約束（來自已解決項目）

第 39 題（`resolved/aggregate/能力值_能力值退步的計算公式與下限.md`，選項 A）已裁決：
**能力值**會因久未訓練而退步，下限為註冊初始值。

但階級由**經驗值**門檻決定（第 31 題），經驗值與能力值為兩個不同的成長數值。
模型中目前**沒有任何「經驗值已減少」Event** —— 本題須先確認經驗值是否會退步，
再談階級可否因此下降。

# 解決結果

**選項 A｜階級單調遞增，永不下降**

- 經驗值已定案為單調遞增、永不減少（`00_全域規範.md`〈三個成長數值的區別〉），故無因經驗值下降而降階的路徑。
- **不另設**獨立於經驗值的降階機制（如久未訓練降階）。
- 不新增「使用者已降階」Event。

理由：經驗值管年資、能力值管實力，退步的職能已由能力值完整承擔
（退步、退步預告、回歸任務為一整套機制）；階級同時下降等於同一件事罰兩次。
降階亦會連帶影響以階級為門檻的進階訓練計畫解鎖與教官初審資格，
須處理「解鎖後又失去資格」的連動，複雜度與價值不成比例。

不採 C（經驗值改為可退步）：會推翻既有裁決，並連帶影響階級設定、教官資格、進階計畫解鎖三處。
