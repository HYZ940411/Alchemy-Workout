# 釐清問題

同一次連簽中斷若跨越多個未簽到日，可否一次使用多張補簽券全部補回？

# 定位

流程：補簽流程
元素：Rule：使用者已使用補簽券的 Precondition
細節：數值邊界與組合邊界（C3）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 一張補簽券補一天，可連續使用多張補回多天 |
| B | 一次中斷僅能使用一張補簽券，僅補回一天，超過一天的中斷無法完全恢復 |
| C | 一張補簽券即可補回整段中斷，不論中斷幾天 |
| D | 可使用多張，但單次中斷最多補回 3 天 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響使用者已使用補簽券的 Precondition、補簽券 Aggregate 的扣減數量計算、連續簽到已恢復的 Postcondition，並與「可回補的時間範圍」問題有依賴關係（需先確定時間窗才能定義張數規則）。

# 優先級

Medium

# 既有約束（來自已解決項目）

第 36 題（`resolved/aggregate/連續簽到_連續天數與累計天數的定義與型別.md`，選項 D′）已裁決：
補簽券使用後，「中斷前連續天數」清空為 0 —— 一次中斷使用一張券即完成回復，
再使用第二張已無可回復的資料。

第 37 題（`resolved/aggregate/補簽券_補簽券的取得來源與持有上限.md`，選項 B）已裁決：
持有上限 5 張，無有效期限。

本題實質剩下的是：是否明文禁止同一次中斷重複使用，以及誤用時的處理。

# 解決結果

**選項 A** —— 一張補一天，可連續使用多張補回多天；天數上限由第 30 題定案的 7 天回補範圍界定，不另設張數上限。
