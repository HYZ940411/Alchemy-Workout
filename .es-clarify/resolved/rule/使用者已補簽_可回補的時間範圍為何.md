# 釐清問題

「使用者已補簽」可以回補多久之前的簽到？是否有時間窗限制與次數限制？

# 定位

流程：補簽流程
元素：Rule：使用者已補簽的 Precondition
細節：時間邊界與時間窗（C3）；與連簽中斷判定 48 小時發送補簽提醒的關係。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 僅可回補最近一次中斷，且需在中斷後 48 小時內使用 |
| B | 可回補最近 7 天內任一未簽到日，不限次數，只要有補簽券 |
| C | 可回補最近 3 天內未簽到日，每月最多補簽 3 次 |
| D | 僅可回補「昨日」，逾期不可補 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響使用者已補簽的 Precondition、補簽券 Aggregate 的使用限制、連續簽到已恢復的計算範圍、以及與簽到連續天數已中斷 Event 的時序關係。

# 優先級

High

# 解決結果

**選項 B** —— 可回補最近 7 天內任一未簽到日，不限次數，只要持有補簽券。7 天為平台級可調參數。
