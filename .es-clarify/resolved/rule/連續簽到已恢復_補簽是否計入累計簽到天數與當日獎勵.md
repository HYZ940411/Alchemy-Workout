# 釐清問題

補簽成功後，該日是否計入累計簽到天數？是否補發當日的簽到獎勵與經驗值？

# 定位

流程：補簽流程
元素：Rule：連續簽到已恢復的 Postcondition
細節：Postcondition 原子化與涵蓋所有被改變的欄位（C2）；連帶產生哪些 Event（C2）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 連續天數恢復，累計天數加一，補發當日簽到獎勵與經驗值 |
| B | 僅恢復連續天數，不計入累計天數，不補發獎勵 |
| C | 連續天數恢復且累計天數加一，但不補發獎勵（獎勵已隨中斷失效） |
| D | 連續天數恢復、累計天數加一、補發獎勵但不補發經驗值 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響連續簽到已恢復的 Postcondition、連續簽到 Aggregate 的兩個天數欄位、是否連帶產生「簽到獎勵已發放」與「經驗值已提升」Event、以及補簽流程中連簽成就已解鎖的判定基礎。

# 優先級

High

# 解決結果

**選項 A ＋ 使用者補充** —— 連續天數恢復、累計天數 +1、補發當日簽到獎勵；但獎勵**補發至獎勵信箱**，不直接入帳。

使用者另裁決補簽券金幣售價為 **150 金幣**，基準為「四天份簽到金幣（4×10）＋ 四天份訓練金幣（4×30）」。

新增不變條件：補簽券售價須高於單日簽到獎勵的金幣數，否則形成套利迴圈。
