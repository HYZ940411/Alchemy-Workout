# 釐清問題

連簽成就與累簽成就的同一門檻在中斷後再次達成時，是否重複解鎖並重複發放獎勵？

# 定位

流程：每日簽到流程
元素：Rule：連簽成就已解鎖的 Precondition；Policy：簽到成就門檻（連續 1/3/5/7/10/15/20/25/30 天）
細節：狀態邊界：重複執行（C3）；冪等性（A3）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 每個門檻終身僅解鎖一次，重複達成不再發放（成就單調遞增） |
| B | 連簽成就每次中斷後重新計算，可重複解鎖並重複發放 |
| C | 連簽成就可重複解鎖但獎勵遞減，累簽成就終身一次 |
| D | 連簽成就可重複解鎖且獎勵相同，累簽成就終身一次 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響連簽成就已解鎖 / 累簽成就已解鎖的 Precondition、成就 Aggregate 的解鎖紀錄結構（是否需記錄解鎖次數）、以及補簽流程中連簽成就的補發判定。

# 優先級

Medium

# 解決結果

**選項 A** —— 每個成就門檻終身僅解鎖一次，重複達成不再發放。及於全部 7 類成就。不影響每日簽到獎勵與連簽獎勵加成。
