# 釐清問題

教官資格初審的「指定階級」與「累積訓練次數」門檻數值各為何？兩者為 AND 或 OR 關係？

# 定位

流程：教官申請流程
元素：Rule：Event「教官資格已初審通過」的 Precondition
細節：前置條件完整性（C1）；數值邊界（C3）；待決事項（F3）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 兩者皆須滿足（AND）：達中段階級 ＋ 累積訓練 50 次 |
| B | 兩者皆須滿足（AND）：達中段階級 ＋ 累積訓練 100 次 |
| C | 擇一滿足（OR）即可通過初審 |
| D | 兩者為平台級可調參數，由管理員於後台設定，本階段僅定義 AND 關係 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響「教官資格已初審通過」與「教官資格已駁回（初審階段）」的 Precondition 驗收、以及使用者 Aggregate 是否需新增「累積訓練次數」欄位。
承接 G14。**相依**：階級門檻須待 `aggregate/階級設定_階級總數與各階門檻初始值為何.md` 定案後，才有可指涉的具體階級名稱。
相關已解決項目：`resolved/command/教官資格已初審通過_初審由系統或管理員執行.md`（選項 A）。

# 優先級

High

# 解決結果

**選項 A｜階級 ≥ 20 且累積訓練次數 ≥ 50 次**

- 兩條件須**同時成立**，由系統自動判定（初審無人工介入）。
- 兩項門檻皆為平台級可調參數。

理由：兩個條件各擋一種不適任者，缺一不可 ——
階級可經每日簽到累積，只看階級會使從未訓練者取得教官資格；累積訓練次數正是為擋此漏洞。
階級 20 約需 2 個月（依已定案公式 C(20) ＝ 313），50 次以每週 3 練計約 4 個月。
初審之後尚有教官測驗，門檻只需擋掉明顯不適任者。

不採 B（階級 10 / 30 次）：資歷太淺，教官帶人會傷到學徒。
不採 C（階級 30 / 100 次）：約需 8 個月，初期平台幾乎不會有教官，師徒功能空轉。
不採 D（僅階級門檻）：簽到即可升階，漏洞未擋。

# 後續修正（2026-08-01，同輪第 16 題補充）

使用者於本題定案後追加需求：初審應由 **AI 分析使用者的歷史訓練**，
判斷有無明顯的造假或偷懶嫌疑，並訂定評分標準；訓練質量佳者可加分。

**選項 A｜三維評分**

| 維度 | 抓的問題 | 可用訊號 |
|------|----------|----------|
| 訓練完成率 | 偷懶 | 已完成組數 / 計畫組數、提前結束的比例、逾時中斷的比例 |
| 訓練規律性 | 是否真的長期在練 | 每週訓練次數的穩定度、連續訓練天數、訓練間隔的離散程度 |
| 紀錄合理性 | 造假 | 每組耗時是否過短、重量是否超出人體合理範圍或突然暴增、多次訓練的數字是否完全雷同、是否一路直接勾選預帶值 |

- 三維各 0–100 分後加權平均。
- Actor 為 AI（產出評分與疑慮標記），系統依門檻判定，AI 不直接裁決。
- 階級 ≥ 20 且累積訓練次數 ≥ 50 次的原門檻**維持不變**，AI 評分為額外增列的 Precondition。

不採單一維（僅紀錄合理性）：只抓造假不評品質，無法實現「質量不錯可加分」。
不採不定義維度：評分無法驗收，亦無法向被駁回者說明理由。

*評分如何影響判定（通過門檻、可否折抵硬門檻、疑似造假是否轉人工）於下一題定案。*

# 後續修正之二（2026-08-01，評分如何影響判定）

**選項 A｜品質分設門檻 ＋ 高分折抵次數 ＋ 造假一票否決**

- 品質分 ≥ 60 為通過門檻。
- 品質分 ≥ 80 者，累積訓練次數門檻由 50 次降為 **30 次**；**階級門檻不折抵**。
- **紀錄合理性單項 < 40 者一票否決**，不論其他維度分數與加權平均為何。
- 60 / 80 / 40 三個數值與三維權重皆為平台級可調參數。

折抵對象取訓練次數而非階級：次數可由品質換取（30 次紮實優於 50 次半途而廢），
階級代表平台資歷長度，為時間所換，品質無法替代。

紀錄合理性採一票否決：造假與練得好是兩回事，
若僅看加權平均，完成率與規律性皆高的造假者反而最容易通過。

不採總分制：與教官測驗「不採總分制」的既有裁決一致，總分制下階級高者可以資歷淹掉品質分。
不採疑似造假轉人工審核：會使「初審無人工介入」的設計破功，且訓練紀錄難以人工判讀。
