# 釐清問題

週期中途註冊的使用者或中途建立的團隊，是否參與該週期的排行榜結算？是否有最低參與門檻？

# 定位

流程：排行榜週期結算流程
元素：Rule：排行榜週期已結算的 Precondition
細節：類別邊界與特殊值（C3）；Precondition 完整性（C1）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 一律參與，無門檻，分數為 0 者不列入排名 |
| B | 需達最低分數門檻才列入排名並具領獎資格 |
| C | 需在週期開始前即已註冊 / 建立才參與，中途加入者從下一週期起算 |
| D | 一律參與，且分數為 0 者仍列入排名末位 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響排行榜週期已結算的 Precondition、三種獎勵發放的資格判定、排行榜 Read Model 的篩選規則、以及新使用者的體驗設計。

# 優先級

Medium

# 前置裁決（2026-08-01 第三輪第 5 題）

個人排行榜已定案為**階級區間分組**（每 10 階一組，共 10 組），排名與獎勵**僅於組內比較**，
顯示為「自己上下各 10 名」的視窗，即時性為延遲更新。
本項目作答時，所有「名次」「前 N 名」一律指**組內名次**，不再是全平台名次。

*來源：`resolved/read-model/排行榜_排行榜的顯示範圍排序與即時性要求.md`*

# 前置裁決（2026-08-01 第三輪第 17 題）

排行榜週期已定案為四個榜：個人週榜（週一 04:00）、個人月榜（每月 1 日 04:00）、
團隊日常排行榜與團隊限時排行榜（皆同個人月榜）。
同一次得分同時累加至週累計與月累計兩個獨立計數器，各自歸零。
本項目作答時須分別考慮週榜與月榜，且三個相關 Event 皆攜帶榜別。

*來源：`resolved/rule/排行榜週期已結算_排行榜週期的長度與起訖時點為何.md`*

# 解決結果

**選項 A** —— 週期中新加入者本週期即有參賽資格；所屬組別於**首次計分時**鎖定當下階級，非於週期起點鎖定。此為第 21 題「分組於週期起點鎖定」的必要補充分支：週期起點時該使用者尚未存在。
