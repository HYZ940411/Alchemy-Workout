# 釐清問題

「團隊已解散」發生時，該團隊本週期的日常分數與限時分數如何處理？已產生的排行榜名次與待發放的排行獎勵如何處理？

# 定位

流程：團隊組隊流程、團隊任務流程、排行榜週期結算流程
元素：Rule：Event「團隊已解散」的 Postcondition
細節：後置條件完整性（C2）；Aggregate 關聯的生命週期（D4）。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 分數作廢、退出兩個排行榜，本週期不發放任何團隊排行獎勵給原成員 |
| B | 分數保留至本週期結算，結算時仍計入排名並發放獎勵給解散時的成員 |
| C | 分數作廢並退出排行榜，但成員的個人排行榜分數不受影響 |
| D | 團隊改為「已解散」狀態不實體刪除，分數凍結於解散當下，不再累加亦不參與排名 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響團隊 Aggregate 是否有終止狀態、兩個團隊分數的生命週期、排行榜週期結算的參與資格判定，以及成員資料的清理。
本項為新掃描發現，非承接 `pending-gaps.md`。
與 `rule/團隊日常分數已增加_成員中途加入或退出時分數如何計算.md` 及 `rule/排行榜週期已結算_週期中新加入使用者的參與資格.md` 宜併題處理。

# 解決結果

**選項 D** —— 團隊改為「已解散」狀態不實體刪除，分數凍結於解散當下，不再累加亦不參與排名。成員的個人排行榜分數不受影響（此條於所有選項下皆成立，已寫為獨立規則）。
