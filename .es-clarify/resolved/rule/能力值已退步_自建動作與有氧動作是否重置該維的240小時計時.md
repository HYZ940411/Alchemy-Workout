# 釐清問題

自建動作與有氧動作皆已定案「不計入能力值、不觸發能力值已提升」。使用者若以自建動作或有氧動作訓練某個肌群，該維的 240 小時退步計時是否重置？

# 定位

流程：訓練中斷流程、訓練結算流程
元素：Rule：Event「能力值已退步」的 Precondition（該維自最後一次訓練日的日界起滿 240 小時）
細節：C3 邊界條件（類別邊界）、C1 前置條件原子化。「該維最後一次訓練日」的定義未界定是否限於計入能力值的動作；有氧動作的所屬肌群為空值，更無維度可歸屬。

# 多選題

| 選項 | 描述 |
|--------|-------------|
| A | 自建動作**重置**該維計時（有練就是有練，退步衡量的是「有沒有在練這個部位」，非「有沒有拿到點數」）；有氧因所屬肌群為空值，不重置任何維度 |
| B | 自建動作**不重置**（與不計入能力值一致，否則使用者可建一個自建動作每 10 天點一次即永不退步 —— 該路徑完全免費且不需真的訓練）；有氧同樣不重置 |
| C | 自建動作重置、有氧重置**核心與腿**兩維（多數有氧涉及下肢） |
| D | 一律以「訓練紀錄是否存在該肌群的組紀錄」判定，不論動作來源與類型；有氧無肌群故不影響 |
| Short | 提供其他簡短答案（<=5 字） |

# 影響範圍

影響「能力值已退步」的 Precondition 可驗收性、連續訓練 Aggregate 的「上次訓練日期」與能力值六維各自計時的關係、回歸任務的觸發條件（其 Precondition 綁在「能力值已退步」上），以及自建動作是否成為退步機制的規避路徑。

# 解決結果

**選項 B —— 重置。** 只要練了該肌群，不論動作是否為自建，該維計時歸零。

| 動作類型 | 計入能力值 | 重設該維 240 小時計時 |
|---------|-----------|---------------------|
| 平台重訓動作 | 是 | 是 |
| 自建動作 | 否 | **是**（依其所屬肌群，該欄位為必填） |
| 有氧動作 | 否 | **否**（所屬肌群為空值，不對應任何維度） |

判準：
1. 不重置（A）會使連續練 10 天自建動作者收到「能力值退步」通知。
   退步機制的目的為**召回流失使用者**，而該使用者並未流失。
2. A 同時打開一條反向誘因：使用者發現練自建動作會掉能力值後，理性反應是不再建自建動作。
3. **「不加分」與「不扣分」為兩件事**：自建動作未經平台驗證動作定義，故不得用於加分；
   但它是使用者確實訓練過該肌群的證據，足以證明其未中斷。
4. 不採分開處理（C）：C 需在退步判定中另維護一組動作分類；而有氧的排除
   已由「所屬肌群為空值」自然達成，不需額外規則。
